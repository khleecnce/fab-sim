# 지식 감사 → 엔진 적용 우선순위 (2026-09-13)

`_knowledge_audit/` 5축 조사에서 나온 갭을 **엔진 정확도에 미치는 영향** 순으로
분류한다. 문헌 미확보(내 통제 밖)와 구현 갭(내 통제 안)을 섞지 않는다.

판정 기준 — 물질명이 아니라 구조로:
- **P0**: 현재 예측을 틀리게 만들고 있음 (계약 위반·부호 오류·이중 계상)
- **P1**: 지배 인자인데 모델에 통로 자체가 없음 (구조적 공백)
- **P2**: 있으나 형태가 부정확 (근사·분해능 손실)
- **P3**: 정밀도 개선 (지금 틀리지 않음)
- **BLOCKED**: 문헌 미확보가 병목 — 노력으로 못 당김

## P3 — 정밀도

- Preston 성립레짐 런타임 판정 부재 (mech)
- 유체 분담항 P_f 미구현 → 무유체 극한 발산 가능 (planar)
- SFQR 등 SEMI site 지표 미구현 (planar)
- 입체 반발(AdG) 미구현, 분산제 농도축 없음 (colloid)
- HHF 이종 상호작용 미구현 (colloid)

## BLOCKED — 문헌 미확보가 병목 (노력으로 못 당김)

| 항목 | 왜 막혔나 | 영향 |
|---|---|---|
| **반응 표면층 유효경도 H_s** | 어느 문헌에도 절대값 없음 | 단일입자 H^(-3/2) 모델 전체의 최대 병목 |
| 유효 냉각 유량 판정 | 공급 전량 vs 웨이퍼 하부 도달량(η 2~22%) | **최대 5~50배 편차** — 열축 최대 미해결 |
| θ→MRR, K'(pH)→MRR 변환식 | 문헌에 폐형식 없음 | 억제제·킬레이터 공통 장벽 |
| 산화제 단봉 폐형식 | 문헌에 없음 | 현 구현은 저장소 자체 현상론 |
| Preston 1927 원문 | DOI 자체가 없음(Crossref 미등록) | 2차 인용 유지 |
| GW 1966 / Archard 1953 / Luo-Dornfeld 2001 | 유료 + 미러 사이트 미러 전부 실패 | 식은 독립 유도로 재현됨 |
| SEMI M1/M59/M20/MF1390 | Cloudflare 차단 | 평탄도 정의 정본 미확보 |
| ζ(pH) 곡선 | 미확보 | 부호 판정은 되나 크기 판정 불가 |

## 식별 불가능성 (실험 설계가 필요한 것)

데이터를 더 모아도 **분리되지 않는** 쌍 — 독립 측정이 필요하다:

| 쌍 | 상관 | 분리 방법 |
|---|---|---|
| (K_ads, k_inhib) | +0.929, 동등해 994개 | 흡착 등온선 독립 측정 |
| (H_eff, F, 절삭효율) | 3중 축퇴 | 나노압입으로 H 직접 측정 |

이건 모델 결함이 아니라 **구조적 성질**이다. 피팅으로 풀려고 하면 안 된다.

## 작업 순서

1. **P0 전부** — 지금 틀린 것부터. 특히 P0-1, P0-2는 held-out ρ에 직접 영향
2. **P1-1, P1-2** — χ와 g. 이 둘이 들어가면 입경/농도 지수 논쟁이 구조적으로 닫힌다
3. **P1-5** — SFR 축. 사용자가 만지는 주요 슬라이더인데 결과가 안 변함
4. 나머지 P1 → P2 순

BLOCKED 항목은 회차를 소모하지 않는다. 대신 그 사실을 `notes`에 명시해
"모름"과 "효과 없음"을 구분한다.
