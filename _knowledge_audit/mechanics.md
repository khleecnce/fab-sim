## 1. Preston 식

### 1.1 모델식과 기호표

```
ḣ = K_p · P · V
```

| 기호 | 의미 | SI 단위 | 비고 |
|---|---|---|---|
| ḣ | 선형 제거율(두께/시간) | m·s⁻¹ | 실무는 nm/min |
| P | 명목(겉보기) 압력 = W/A_n | Pa | 웨이퍼 뒷면 가압 |
| V | 패드-웨이퍼 상대속도 | m·s⁻¹ | 회전운동학의 v_R(r,θ) |
| K_p | Preston 계수 | m²·N⁻¹ (= Pa⁻¹) | lumped 상수 |

### 1.2 차원 검사

[K_p][P][V] = (m²·N⁻¹)(N·m⁻²)(m·s⁻¹) = m·s⁻¹ ✓ (§7 코드 OK)

### 1.3 유도 가정과 깨지는 조건

Preston 식은 "에너지 유입률 ∝ 제거량"이라는 **비례 가정 1개**로 요약된다:
단위면적당 마찰일률 = μPV이므로, 제거 부피가 소산에너지에 비례하면 ḣ ∝ PV.

| 가정 | 깨지는 조건 |
|---|---|
| (a) 제거는 기계적 마찰일에 선형 비례 | 화학 반응층 생성이 율속(reaction-limited)일 때 — 이때 ḣ는 P,V에 포화하거나 무관해진다 |
| (b) 문턱압력 없음(P→0에서 ḣ→0 연속) | 문턱압 P_th가 존재하는 계 — ḣ ∝ (P^{2/3}−P_th^{2/3})V 형 (Zhao & Shi류, 2차 인용) |
| (c) K_p가 P, V와 무관 | 접촉레짐이 압력에 따라 바뀌면(고체접촉↔부분유막) K_p(P) — Stribeck 좌측→최소점 이동 |
| (d) 실접촉 통계가 공정 중 불변 | 패드 마모/컨디셔닝으로 η, σ_z, R가 시간에 따라 변함 → K_p(t) |
| (e) 완전 고체접촉(경계윤활) | So(§4.5 무차원수)가 커져 유막이 접촉을 분리하면 ḣ 급감, PV 선형성 붕괴 |

### 1.4 K_p의 물리적 분해 (세 갈래, 상호 배타 아님)

1. **Archard 경로**: 마모깊이식 k·P·L/H와 구조가 동일(L=V·t) ⇒ **K_p ≈ k/H**.
   경도 H는 벌크가 아니라 **화학이 만든 표면층의 유효경도 H_s**여야 실제 값에 근접한다.
2. **GW 접촉통계 경로**: MRR = α·n(P)·V 이고 GW에서 n ∝ P(지수분포 특수해) ⇒
   **K_p = α·(dn/dP)**. α는 접촉점 1개가 단위속도당 깎는 부피율(화학·입자 lump).
3. **단일입자 경로**(§5): K_p ∝ C_particle · H_s^{-3/2} · (기하항) · P^{-1/2}
   — 이 경로는 K_p가 P에 남는 의존성을 갖는다(=Preston이 정확히 선형이 아닌 이유의 한 설명).

세 경로는 "K_p 안에 (접촉통계) × (입자당 제거효율) × (표면층 물성)이 곱으로 들어있다"는
같은 그림의 다른 절단면이다.

### 1.5 극한 거동

| 극한 | 식의 예측 | 물리적 타당성 |
|---|---|---|
| P→0 | ḣ→0 | 타당하나 **문턱압 계에서는 과대예측**(실제는 0이 되는 압력이 유한) |
| P→∞ | ḣ→∞ (무한) | **비타당** — 실제는 패드 붕괴/입자 파쇄/스크래치 모드 전이. 상한 없음이 모델 한계 |
| V→0 | ḣ→0 | 타당(마찰일 없음). 단 정지상태 화학식각 ḣ_chem>0은 누락 |
| V→∞ | ḣ→∞ | **비타당** — 유체동역학 부양(유막 형성)으로 실제는 감소로 반전 |

### 1.6 무차원수

Preston 자체는 무차원수를 갖지 않는다(완전 차원식). 성립 판정에 쓰이는 무차원수는 외부에서 온다:
- **Sommerfeld 수** So = ηV/(P·δ_eff): So≪1이면 경계윤활 ⇒ Preston 성립 영역.
  So가 커지면 고체접촉분율이 떨어져 K_p가 상수가 아니게 된다.
- **Damköhler 수** Da = (기계 제거 시간척도)/(화학 반응 시간척도): Da≫1(기계율속)이면 Preston 선형,
  Da≪1(화학율속)이면 ḣ는 P,V에 포화. *FabSim에 이 판정 수는 아직 없다.*

### 1.8 파라미터 분류

| 파라미터 | 분류 | 근거 |
|---|---|---|
| P | **독립 측정 가능** | 가압 제어값 |
| V | **독립 측정 가능** | 회전수·기하에서 계산(운동학) |
| K_p | **피팅 필요** | 물성 조합·화학에 종속. 1차원리 예측 불가 |

### 1.9 FabSim 현 구현과의 차이

- `tier1_empirical/preston.py`가 ḣ=K_p·P·V를 그대로 구현. K_p는 상수 하드코딩/팩 주입.
- **차이 1**: 문턱압, K_p(P), K_p(t)(패드 마모) 중 어느 것도 Tier1 경로에 들어있지 않다.
- **차이 2**: K_p의 물리적 분해는 `gw_preston_link.py`에 **검증 스크립트로만** 존재하고
  메인 MRR 경로에 연결돼 있지 않다(모듈 docstring이 그렇게 명시).
- **차이 3**: Preston 성립 레짐 판정(So, Da)이 런타임에 없다 — 어떤 조건에서도 Preston을 적용한다.

## 2. Hertz 단일 접촉

### 2.1 모델식과 기호표

구(반경 R)가 탄성 반무한체를 δ만큼 압입할 때(무마찰·무점착):

```
a  = √(R·δ)                         (접촉반경 - 압입깊이 관계, δ≪R)
F  = (4/3)·E*·√R·δ^{3/2}            (힘 - 압입깊이)
a  = (3FR / 4E*)^{1/3}
δ  = (9F² / (16 E*² R))^{1/3}
p_max = 3F/(2πa²) = (6F E*² / (π³R²))^{1/3}
p_avg = F/(πa²) = (2/3)·p_max
1/E* = (1−ν₁²)/E₁ + (1−ν₂²)/E₂      (재료조합 등가탄성률)
k_c = dF/dδ = 2E*·a                  (접촉강성)
```

| 기호 | 의미 | SI 단위 |
|---|---|---|
| δ | 압입깊이 | m |
| a | 접촉원 반경 | m |
| R | 등가 곡률반경 (1/R = 1/R₁+1/R₂) | m |
| F | 수직 접촉력 | N |
| E*, E₁, E₂ | 등가/개별 탄성률 | Pa |
| ν₁, ν₂ | 포아송비 | – |
| p_max, p_avg | 최대/평균 접촉압력 | Pa |
| k_c | 접촉강성 | N·m⁻¹ |

### 2.2 차원 검사

- [E*][R]^{1/2}[δ]^{3/2} = Pa·m^{1/2}·m^{3/2} = Pa·m² = N ✓
- [(3FR/4E*)]^{1/3} = (N·m/Pa)^{1/3} = (m³)^{1/3} = m ✓
- [(9F²/16E*²R)]^{1/3} = (N²/(Pa²·m))^{1/3} = (m³)^{1/3} = m ✓
- [3F/2πa²] = N/m² = Pa ✓  (§7 코드 4건 모두 OK)

### 2.3 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 소변형: a ≪ R, δ ≪ R | 고하중에서 a/R ≳ 0.3이면 반무한체 근사 붕괴, 오차 급증 |
| 반무한체(접촉체 두께 ≫ a) | 얇은 층·박막 기판, 또는 다공성 패드의 셀 벽 두께 ~ a일 때 |
| 선형탄성·등방성 | 패드는 **점탄성**(§6) — E*가 하중 속도/주파수에 의존. 다공성 탓 등방성도 근사 |
| 무마찰 계면(전단응력 0) | 실제 CMP는 마찰계수가 유한 — 접촉영역에 접선응력 존재 |
| 무점착(adhesionless) | 입자 스케일(d_p ~ 수십 nm)에서 표면에너지가 유의미 ⇒ JKR/DMT 보정 필요 |
| 완전 탄성(항복 없음) | p_max가 재료 항복을 넘으면 소성 개시 — 판정은 §3.5 ψ 또는 Tabor 기준 |

**소성 개시 조건(고전 결과, 2차 인용)**: p_max ≈ 1.6·Y(항복강도)에서 표면하 항복 시작,
완전소성이면 평균압력 p ≈ H ≈ 3Y로 포화. 이것이 §5 단일입자 모델이 "접촉압력 = H"를 쓰는 근거다.

### 2.4 무차원수

- **δ/R** (또는 a/R): 소변형 가정 지표. δ/R ≪ 1일 때만 위 식 유효.
  δ/R ≳ 0.1이면 접촉반경 식의 고차항이 무시 못할 크기가 된다.
- **p_max/H**: 탄성/소성 판정. ≲0.4면 탄성, →1이면 완전소성.
- **점착 파라미터(Tabor 수) μ_T** = (R·Δγ²/(E*²·z₀³))^{1/3}: μ_T≪1 → DMT, ≫1 → JKR, ~1 → 중간.
  **FabSim은 μ_T를 계산하지 않는다** — 입자 스케일에서 점착 무시가 정당한지 미판정.

### 2.5 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| δ→0 | F→0, a→0, k_c→0 | ✓ 접촉 개시의 연속성 |
| δ→∞ | F→∞ | ✗ 실제는 소성/파괴. 탄성해의 형식적 발산 |
| R→∞ (평면) | 주어진 δ에서 F→∞ | 형식적으로 타당(평면-평면 접촉은 Hertz 정식화 밖) |
| R→0 (뾰족) | F→0 | ✗ 실제는 응력집중으로 즉시 소성 — 예리 압입자는 Hertz 적용 불가 |
| E*→0 (무한연질) | F→0, a→∞ | ✓ 극연질 패드는 힘을 못 받음 |
| E*→∞ (강체) | 주어진 F에서 δ→0 | ✓ |

### 2.8 FabSim 현 구현과의 차이

- `gw_contact.py`: `hertz_force`(F=(4/3)E*√R δ^{3/2}), `hertz_contact_area`(πRδ) 구현. 정확.
- **차이 1**: E*를 **상수**로 받는다 — 점탄성(주파수/온도 의존, §6)이 연결돼 있지 않다.
  `pad_viscoelastic_temperature.py`가 E'(T)를 주지만 GW 경로에 주입되지 않는다.
- **차이 2**: δ/R 소변형 유효성 검사나 소성 전이 가드가 코드에 없다 — δ가 아무리 커도 탄성식으로 계산.
- **차이 3**: 점착(JKR/DMT) 항 없음. asperity 스케일에서는 정당할 수 있으나 **판정 근거가 문서화돼 있지 않다**.

## 3. Greenwood-Williamson 통계 접촉

### 3.1 모델식과 기호표

거친 면(구형 asperity 집합, 높이확률밀도 φ(z)) vs 평탄 강체, 평균면 간 분리거리 d:

```
접촉점수     n   = η·A_n · ∫_d^∞ φ(z) dz
실접촉면적   A_r = π·R·η·A_n · ∫_d^∞ (z−d)·φ(z) dz
전체 하중    W   = (4/3)·E*·√R·η·A_n · ∫_d^∞ (z−d)^{3/2}·φ(z) dz
평균 실접촉압력 p_r = W / A_r
소성지수     ψ   = (E*/H)·√(σ_z/R)
```

| 기호 | 의미 | SI 단위 |
|---|---|---|
| η | 단위 명목면적당 asperity 밀도 | m⁻² |
| A_n | 명목 접촉면적 | m² |
| φ(z) | asperity 높이 확률밀도 | m⁻¹ |
| d | 평균면-대향면 분리거리 | m |
| σ_z | asperity 높이 표준편차 | m |
| R | asperity 정상부 곡률반경 | m |
| n | 접촉 asperity 개수 | – |
| A_r | 실접촉면적 | m² |
| W | 총 수직하중 | N |
| H | 연질재 경도 | Pa |
| ψ | 소성지수 | – |

### 3.2 지수분포 특수해 (폐형식)

φ(z)=β·e^{−βz}, β=1/σ_z 일 때 memoryless 성질로:

```
∫φ dz = e^{−βd},  ∫(z−d)φ dz = (1/β)e^{−βd},  ∫(z−d)^{3/2}φ dz = Γ(5/2)·β^{−3/2}·e^{−βd}
⇒ A_r/W = 3π·√(R·β) / (4·E*·Γ(5/2))   ← **d에 무관한 상수**
```

즉 **A_r ∝ W(정확히 선형), p_r = W/A_r = 상수**. 명목압력을 올려도 국소 실접촉압력은 변하지 않고
**접촉점 수 n이 늘어난다**. 이것이 Preston의 P-선형성을 미시적으로 설명하는 가장 깔끔한 고리다.
(FabSim `gw_contact.py`가 수치적분으로 이 폐형식을 재현하고, 과거 노트의 잘못된 계수
`3π/(4E*)√(R/β)`를 코드로 반증·정정한 이력이 있다 — 상대오차 100% vs 3e-6.)

### 3.3 차원 검사

- n: m⁻²·m²·(무차원) = 무차원 ✓
- A_r: m·m⁻²·m²·m = m² ✓
- W: Pa·m^{1/2}·m⁻²·m²·m^{3/2} = Pa·m² = N ✓
- ψ: (Pa/Pa)·√(m/m) = 무차원 ✓ (§7 코드 OK)

### 3.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| (a) 모든 asperity 곡률반경 R 동일 | 실제 R은 분포를 가짐(로그정규 등) — 평균 R 대입은 W를 편향 |
| (b) asperity 간 상호작용 없음(독립 Hertz) | A_r/A_n이 커질 때(≳5–10%) 이웃 변형이 겹쳐 하중 과소예측 |
| (c) 대향면은 완전 평탄한 강체 | 양면이 거친 경우 — Greenwood-Tripp(1970)이 **등가 거친면**(σ²=σ₁²+σ₂², 1/R=1/R₁+1/R₂)으로 확장 |
| (d) 전 접촉이 탄성 | ψ≳1이면 소성 지배 — 탄소성 모델 필요 |
| (e) 높이분포 φ가 공정 중 불변 | 마모·컨디셔닝으로 η, σ_z, R가 시간에 따라 변함 ⇒ **동적 GW** 필요 |
| (f) 벌크 변형(전체 압축) 무시 | 다공성 패드는 asperity 변형 외에 **벌크 압축**이 동시 진행 |
| (g) asperity 높이 기준면이 잘 정의됨 | 측정 스케일에 따라 σ_z, R, η가 모두 변하는 **스케일 의존성**(프랙탈 비판) |

가정 (g)는 GW의 구조적 약점이다: η·σ_z·R 세 값이 측정 해상도에 의존하는데, 무차원 조합
**η·R·σ_z**(≈접촉밀도 지표)와 **R/σ_z**는 상대적으로 안정한 편이라고 알려져 있다(2차 인용, 미검증).

### 3.5 무차원수와 항 무시 판단

| 무차원수 | 정의 | 크기에 따른 판단 |
|---|---|---|
| **소성지수 ψ** | (E*/H)√(σ_z/R) | ψ<0.6: 탄성 지배 → 탄성 GW로 충분. 0.6≲ψ≲1: 혼재. ψ>1: 소성 지배 → 탄성항 버리고 A_r≈W/H 사용. **경계값 0.6/1.0은 교과서 관례(2차 인용, confidence: unverified)** |
| **무차원 분리거리 h = d/σ_z** | – | h≳3이면 접촉점 수가 분포 꼬리에만 의존 → 분포 형태(가우시안 vs 지수)에 결과가 민감 |
| **실접촉면적비 A_r/A_n** | – | ≪0.05: asperity 독립 가정 안전. ≳0.1: 상호작용 보정 필요(가정 b 붕괴) |
| **벌크/asperity 강성비** | (E_bulk/t)/(n·k_c) | ≪1이면 벌크 압축이 지배 → asperity만의 GW는 하중분배를 틀리게 예측 |

### 3.6 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| d→∞ | n,A_r,W → 0 | ✓ 분리 |
| d→−∞ (깊은 압입) | W→∞, A_r→A_n 초과 가능 | ✗ **A_r이 A_n을 넘을 수 있는 것이 모델 결함** — 상한 clamp 없음 |
| η→0 | W→0 (같은 d에서) | ✓. 단 하중 일정 조건에서는 d가 음수로 밀려 소수 asperity에 응력집중 |
| η→∞ | A_r→A_n, p_r→P | ✓ 매끈한 면의 연속체 접촉으로 수렴(정성적) |
| σ_z→0 (완전 평탄) | 모든 asperity가 동시에 접촉, W가 d에 계단형 | 형식적으로 타당하나 수치적으로 특이 |
| E*→0 | 같은 하중에서 A_r→A_n | ✓ |

### 3.9 FabSim 현 구현과의 차이

- `gw_contact.py`: 지수분포 GW의 n/A_r/W 수치적분 + 폐형식 대조 + `plasticity_index` 구현.
- `gw_pressure_solve.py`: P → d 역문제(Brent), p_r·n·A_r/A_n 산출. **"P를 올려도 p_r 불변,
  n만 선형 증가"를 수치로 확인**(코드 self-test에 있음).
- **차이 1**: 분포가 **지수분포로 고정**되어 있다. 원 GW는 가우시안이며, 두 선택은 꼬리 거동이
  달라 h=d/σ_z가 클 때 n이 크게 갈린다. 분포 선택의 민감도 분석이 없다.
- **차이 2**: R, η, σ_z가 **시간 불변**(정적 GW). 마모/컨디셔닝에 의한 동적 갱신 경로가
  `conditioner_*`/`pad_wear_*` 모듈에 따로 있으나 GW 상태와 한 루프로 묶여 있지 않다.
- **차이 3**: A_r ≤ A_n 물리 제약 clamp가 없다. 고압/저 E* 조합에서 A_r/A_n>1이 나올 수 있다.
- **차이 4**: `plasticity_index`의 판정 경계(0.6/1.0)는 docstring에 **미검증으로 정직히 표기돼 있고**,
  코드는 지수를 계산만 할 뿐 **탄성/소성 분기를 하지 않는다** — ψ>1이어도 탄성 GW를 계속 쓴다.
- **차이 5**: 양면 거칠기(Greenwood-Tripp 등가면 환산)가 미구현 — 웨이퍼 면은 완전 평탄 강체로 가정.
- **차이 6**: `disk_preston_contact_decomposition.py`의 `K_p ∝ η_c/A_f`는 모듈 docstring이
  스스로 **PROVISIONAL(비례상수·지수 미회귀)**이라 명시 — 정량 예측 금지 상태 그대로 둘 것.

## 4. Archard 마모식

### 4.1 모델식과 기호표

```
마모부피   V_w = k · W · L / H
마모깊이   V_w/A = k · P · L / H          (P = W/A)
마모율     dV_w/dL = k·W/H                 (=일정, 거리 무관)
차원적 마모계수  k_d = k/H   [Pa⁻¹ = m²/N]
```

| 기호 | 의미 | SI 단위 |
|---|---|---|
| V_w | 마모 debris 부피 | m³ |
| W | 수직하중 | N |
| L | 미끄럼거리 | m |
| H | 연질재 경도 | Pa |
| k | 무차원 마모계수 | – |
| k_d | 차원 마모계수 | m²·N⁻¹ |

### 4.2 차원 검사

[k·W·L/H] = N·m/Pa = N·m·m²/N = m³ ✓
[k·P·L/H] = (Pa·m)/Pa = m ✓ (§7 코드 OK)

### 4.3 유도 가정과 깨지는 조건

**유도 골자**: 각 소성 접합부(면적 πa²)가 하중 δW = H·πa²를 지지. 접합부 하나가 미끄럼거리 2a
동안 반구형 조각(부피 (2/3)πa³)을 확률 k로 떼어냄 ⇒ dV_w/dL = k·W/(3H), 3을 k에 흡수하면 위 식.

| 가정 | 깨지는 조건 |
|---|---|
| 접촉이 완전 소성(A_r = W/H) | 탄성 접촉 지배(ψ<0.6)면 A_r ∝ W는 여전히 성립하나 비례상수가 H⁻¹이 아님 |
| 마모 확률 k가 하중·속도·거리에 무관 | 레짐 전이(mild↔severe wear)에서 k가 오더로 점프 |
| 2체 마모(접촉 두 면만) | **CMP는 3체 마모** — 자유 입자가 하중을 매개. W가 곧바로 접합부 하중이 아님 |
| 경도 H가 일정 | 화학 반응층이 H를 시간·위치에 따라 바꾸는 계 — H는 상수가 아님 |
| 부착(adhesive) 마모가 지배 | 연마(abrasive)·부식(corrosive) 마모가 지배하면 지수 자체가 달라짐 |
| 마모 debris가 계에서 제거됨 | 재부착/3체 전이로 debris가 다시 연마재로 작동 |

### 4.4 CMP 적용 한계 (핵심)

1. **k는 1차원리로 예측 불가능한 fitting 상수**다. Preston의 K_p를 k/H로 바꿔 써도
   **설명력이 늘지 않는다** — 이름만 옮긴 것(K_p ≈ k/H는 구조적 대응이지 예측이 아님).
2. **3체성**: CMP에서 하중은 입자를 통해 전달된다. Archard의 W는 "두 면 사이 하중"이라
   입자 농도·크기분포가 만드는 **하중 분배**를 전혀 표현하지 못한다(그 역할은 §5 모델).
3. **화학 결합**: CMP 제거율의 강한 화학 의존성은 H를 "반응층 유효경도 H_s"로 바꿔야만 표현되는데,
   H_s는 벌크 경도와 오더가 다를 수 있고 **측정이 어렵다**(FabSim 내 미확보).
4. **속도 무관성**: Archard는 V에 명시적 의존이 없다(L=V·t를 통해서만 들어감).
   속도가 화학 반응 시간(체류시간)을 바꾸는 CMP에서는 이것이 틀린 예측을 낳는다.
5. **유효한 쓰임**: Archard는 오히려 **패드 마모/컨디셔닝 소모** 같은 순수 기계적 마모 축에서 더 안전하다.

### 4.5 무차원수

- **k 자체가 무차원수**(마모 심각도). 금속-금속 비윤활 10⁻²–10⁻⁴, 윤활 10⁻⁶–10⁻⁸ 오더
  (**2차 인용·오더만, confidence: unverified**).
- **Sommerfeld 수** So = ηV/(P·δ_eff) (무차원): So≪1 경계윤활에서만 Archard형 고체마모 항이 지배.
  So가 커지면 고체접촉 항을 줄이고 점성 전단 항으로 옮겨야 한다.
- **무차원 막두께 λ = h_min/σ**: λ<1 경계, 1–3 혼합, >3 완전유막. λ>3이면 마모항 무시 가능.

### 4.6 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| W→0 | V_w→0 | ✓ |
| W→∞ | V_w→∞ 선형 | ✗ 실제는 severe wear 전이로 k가 점프(선형성 붕괴) |
| H→0 | V_w→∞ | ✗ 발산. 실제는 재료가 유동/도말되어 다른 메커니즘 |
| H→∞ | V_w→0 | ✓ |
| L→∞ | V_w 무한 선형 증가 | 부분적으로 ✓ (러닝인 구간 제외). 표면이 정상상태에 도달하면 성립 |

## 5. 입자-표면 단일입자 제거 모델

### 5.1 모델식과 기호표

강체 구형 입자(직경 d_p)가 접촉압력 P_c 하에서 경도 H인 표면층에 소성 압입되어
상대속도 V로 홈을 파낼 때, **입자 1개당 부피 제거율**:

```
입자 1개에 걸리는 힘        F_1 = (π/4)·d_p²·P_c
소성 압입깊이               δ   = F_1/(π·d_p·H) = d_p·P_c/(4H)
접촉반경                    a   = √(d_p·δ) = (d_p/2)·√(P_c/H)
홈 단면적                   A_g = c_g · a · δ          (c_g = O(1) 형상계수)
입자당 제거율               V̇_1 = A_g · V = c_g'·d_p²·(P_c/H)^{3/2}·V
전체 MRR                    ḣ   = N_a · V̇_1 / A_n      (N_a = 활성 입자 수)
```

문헌 폐형식(선행계수 √2/4):  **V̇_1 = (√2/4)·d_p²·(P_c/H)^{3/2}·V**

| 기호 | 의미 | SI 단위 |
|---|---|---|
| d_p | 활성 입자 직경 | m |
| P_c | 입자-표면 접촉압력 | Pa |
| H | 표면층 유효경도 | Pa |
| δ | 소성 압입깊이 | m |
| a | 압입 접촉반경 | m |
| A_g | 홈 단면적 | m² |
| V̇_1 | 입자당 부피 제거율 | m³·s⁻¹ |
| N_a | 활성 입자 개수 | – |
| c_g, c_g' | 홈 형상계수 | – |

### 5.2 MRR ∝ H^{-3/2} 유도

1. 소성 압입 가정(Tabor): 접촉면 평균압력 = H ⇒ `π a² H = F_1`.
2. 구 기하 소변형: `a² = d_p·δ` ⇒ `δ = F_1/(π d_p H) ∝ H⁻¹`.
3. `a = √(d_p δ) ∝ H^{-1/2}`.
4. 홈 단면적 `A_g ∝ a·δ ∝ H^{-1/2}·H^{-1} = H^{-3/2}`.
5. `V̇_1 = A_g·V ∝ H^{-3/2}`. **3/2는 "면적 폭(½) + 깊이(1)"의 합이다.**

같은 방식으로 F_1 ∝ d_p²P_c를 대입하면 `V̇_1 ∝ d_p²·(P_c/H)^{3/2}·V`.
**수치 재현(§7)**: d_p 2배 → 4배(지수 2), P_c 4배 → 8배(지수 3/2), H 2배 → 0.354배(=2^{-3/2}),
V 3배 → 3배. 위 1–5단계 유도로 얻은 폐형식과 문헌 폐형식은 **지수가 완전히 일치**하고
**선행계수만 1/(2√2)≈0.354배 차이**(= 홈 형상계수 c_g의 정의 차이). 지수가 모델의 본질이고
선행계수는 c_g에 흡수되는 자유도임을 이 대조가 보여준다.

Preston 형태로의 환원: N_a가 압력에 따라 늘고 P_c가 GW에 의해 P와 무관한 상수(§3.2)라면
ḣ ∝ N_a(P)·V가 되어 **Preston의 P-선형성**이 나온다. 반대로 P_c가 P에 따라 오르는
가정(활성입자 수가 고정)이면 ḣ ∝ P^{3/2}V, 입도분포 꼬리에서 활성입자가 선택되는 가정이면
문헌은 **ḣ ∝ C·H^{-3/2}·[(d̄+3σ_d)²/d̄³]·P^{1/2}·V** 형태를 얻는다(P 지수 1/2).
⇒ **압력 지수는 모델 가정에 따라 1/2 ~ 3/2를 오간다. 실측 지수는 어느 가정이 맞는지의 판별자다.**

### 5.3 차원 검사

[d_p²·(P_c/H)^{3/2}·V] = m²·(무차원)·m·s⁻¹ = m³·s⁻¹ ✓ (입자당 부피 제거**율**, 부피가 아님)
[N_a·V̇_1/A_n] = m³·s⁻¹/m² = m·s⁻¹ ✓

### 5.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 입자가 표면보다 훨씬 단단(강체 인덴터) | **입자 경도 ≲ 표면 경도**인 조합 — 이때 입자가 먼저 변형/파쇄되어 모델이 무효. 이 조건은 화학종이 아니라 **경도비 H_particle/H_surface**로만 판정해야 한다 |

| 활성 입자 수 N_a가 잘 정의됨 | N_a는 입도분포 꼬리·접촉면적·농도의 합성 — **직접 측정 불가**, 사실상 피팅 파라미터 |

| 단일 균질 표면층 | 반응층/벌크 이중층이면 H가 하나가 아님(H_layer ≪ H_bulk) |

## 6. 패드 점탄성

### 6.1 모델식과 기호표

**Maxwell 모델**(스프링 E와 대시팟 η_v 직렬, 이완시간 τ = η_v/E), 정현파 가진 ω:

```
E'(ω)  = E · (τω)² / (1 + (τω)²)        [저장탄성률]
E''(ω) = E · (τω)  / (1 + (τω)²)        [손실탄성률]
tan δ  = E''/E' = 1/(τω)
E''는 ω = 1/τ 에서 최대, 최댓값 E/2
```

**Kelvin-Voigt 모델**(병렬):

```
E'(ω) = E                (주파수 무관)
E''(ω) = η_v·ω           (선형 증가)
tan δ = η_v·ω/E
```

**시간-온도 중첩 (WLF)**:

```
log₁₀ a_T = −C₁(T − T_r) / (C₂ + (T − T_r))
E'(ω, T) = E'(a_T·ω, T_r)          [환산 주파수 원리]
기준온도 이동 재매개화: (C₁', C₂') = (C₁C₂/(C₂+ΔT), C₂+ΔT)
```

| 기호 | 의미 | SI 단위 |
|---|---|---|
| E', E'' | 저장/손실 탄성률 | Pa |
| E | 스프링 탄성률 | Pa |
| η_v | 점성계수 | Pa·s |
| τ | 이완시간 = η_v/E | s |
| ω | 각주파수 | rad·s⁻¹ |
| tan δ | 손실계수 | – |
| a_T | 이동인자 | – |
| C₁ | WLF 상수 1 | – |
| C₂ | WLF 상수 2 | K |
| T_r | 기준온도 | K |

### 6.2 차원 검사

- E'(ω): Pa·(무차원)/(무차원) = Pa ✓ ((τω) = s·s⁻¹ = 무차원)
- E''(Voigt): Pa·s·s⁻¹ = Pa ✓
- log a_T: K/K = 무차원 ✓ (§7 코드 OK)

### 6.3 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 선형 점탄성(중첩원리 성립) | 변형률이 크면(대략 >1–2%) 비선형 — asperity 접촉은 국소 변형률이 클 수 있다 |
| 단일 이완시간 τ | 실제 폴리머는 **이완시간 스펙트럼**을 가짐 ⇒ 단일 Maxwell은 전이폭을 과소하게 좁게 예측. Prony 급수/일반화 Maxwell 필요 |
| Maxwell: ω→0에서 E'→0 (액체) | 가교된 탄성체는 평형 탄성률 E_∞>0 ⇒ **Maxwell 단독은 부적합**, Zener(SLS) 필요 |

| WLF 적용 범위: T_g ≲ T ≲ T_g+100 K | T<T_g는 Arrhenius형이 맞음. 범위 밖 외삽 금지 |
| 압축 vs 인장 모드 동등 | DMA는 흔히 인장 모드, 접촉 하중은 압축 — 다공성 재료에서 두 모드 값이 다를 수 있다 |
| 건조 상태 물성 | 액체 흡수에 의한 가소화(plasticization)로 T_g·E' 이동 — 습윤 상태 DMA가 아니면 미보정 |

### 6.4 무차원수와 항 무시 판단

| 무차원수 | 정의 | 판단 |
|---|---|---|
| **Deborah 수 De = τ/t_c** | 이완시간 / 하중 특성시간 | De≪1: 완전 이완 → 점성 지배, 탄성 저장 무시 가능. De≫1: 유리질 탄성, 손실항 무시 가능. De~1: **양쪽 다 필요**, tan δ 최대 |
| **τω** | Maxwell 무차원 주파수 | = De. τω≫1이면 E'≈E, E''≈E/(τω)→0. τω≪1이면 E'≈E(τω)², E''≈E·τω |
| **tan δ** | E''/E' | ≪1: 탄성 근사로 충분(Hertz/GW에 E'만 대입 가능). ≳0.3: 점성 소산이 유의, 접촉 이력(hysteresis)이 마찰에 기여 |
| **T−T_g 규격화** | (T−T_r)/C₂ | ≪1이면 a_T ≈ 10^{−C₁(T−T_r)/C₂}(지수 근사) |

**CMP 접촉 특성시간의 추정**: asperity 하나가 대향면 아래를 지나는 시간 t_c ≈ (asperity 접촉폭)/V.
접촉폭 ~ 2a, V ~ O(1 m/s)이면 t_c는 μs 오더가 되어 **ω = 2π/t_c가 DMA 상용 주파수(~1 Hz)보다
4–6자리 높다**. 즉 **DMA 표에서 읽은 E'를 접촉역학에 그대로 대입하는 것은 TTS 없이는 정당화되지 않는다.**
(이 결론은 수치 오더 추정에 의존하므로 confidence: unverified — a와 V 실측으로 재확인 필요.)

- Kelvin-Voigt 모델: **1차 출처 미확보**(19세기 Kelvin/Voigt 원저 식별자 확인 못 함) — 2차 인용.
- 온도별 E' 실측 앵커: 리포지토리에 특허 **US20170087688A1** Table 1B(1 Hz, 인장 DMA) 기반 데이터가 있다.
  **특허는 1차 출처로 유효**하나, (i) 1 Hz·인장 모드 값이고 (ii) 제품별 표라 일반화에 주의.
  본 문서는 그 절대값을 옮기지 않는다(추상화 수준 유지) — 존재 사실과 조건만 기록.

### 6.7 파라미터 분류

| 파라미터 | 분류 | 비고 |
|---|---|---|
| E'(ω,T), E''(ω,T) | **독립 측정 가능** | DMA. **측정 주파수·모드·습윤상태를 반드시 함께 기록** |
| τ (이완시간) | **피팅 필요** | E''(ω) 피크 위치에서 추출 가능하나 스펙트럼이면 단일값 무의미 |
| C₁, C₂ | **피팅 필요** (현재 **문헌값 차용**) | 보편상수 차용 중 — 대상 재료 피팅값 아님 |
| T_g | **독립 측정 가능** | DSC/DMA |
| T (공정 중 계면 온도) | **독립 측정 가능(어려움)** | 계면 실측은 난이도 높음, 열모델 추정치가 흔함 |

### 6.8 FabSim 현 구현과의 차이

- `viscoelastic_maxwell.py`: 단일 Maxwell E'(ω), E''(ω), tan δ. 극한·피크(E/2 @ ω=1/τ) 자체검증 통과.
- `pad_viscoelastic_temperature.py`: E'(T) **로그-선형 구간보간**(앵커점만 사용, 새 피팅상수 생성 회피 —
  좋은 판단), `wlf_log_aT`, `wlf_reparametrize`.
- **차이 1**: **단일 Maxwell만 있고 일반화 Maxwell/Prony·Zener(SLS)가 없다.**
  Maxwell 단독은 ω→0에서 E'→0(액체)을 예측하는데, 가교 패드는 평형 탄성률 E_∞>0이다 —
  **저주파 거동이 구조적으로 틀린다.**
- **차이 2**: E'(T)와 GW/Hertz의 E*가 **연결돼 있지 않다**(모듈 docstring이 스스로 "엔진에 등록하지
  않는다"고 명시, 레시피에 온도 필드 부재가 이유). 즉 온도가 접촉역학을 통해 MRR에 영향을 주는
  경로가 런타임에 존재하지 않는다.
- **차이 3**: **TTS가 실제 적용되지 않는다.** WLF 함수는 있으나, 1 Hz DMA 값을 접촉 주파수
  (§6.4 추정 10⁴–10⁶ Hz 오더)로 환산해 E*에 넣는 경로가 없다. 이것이 이 축의 가장 큰 미결 고리다.
- **차이 4**: C₁, C₂가 보편상수 차용임을 코드가 정직히 표기하고 있다 — 유지할 것.
- **차이 5**: WLF의 T−T_r → −C₂ 특이점 가드, T_g 미만 적용 금지 가드가 함수 레벨에 없다(주석 경고만).

import math

def vol_rate(d_p,P,H,V):
    F1 = math.pi/4*d_p**2*P          # 입자 1개 하중
    delta = F1/(math.pi*d_p*H)       # 소성 압입: pi a^2 H = F1, a^2 = d_p*delta
    a = math.sqrt(d_p*delta)
    return (a*delta)*V               # 홈 단면적 x 속도 (형상계수 c_g=1)

b=dict(d_p=100e-9,P=1e6,H=1e10,V=1.0); r0=vol_rate(**b)
