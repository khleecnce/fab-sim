## 1. Reynolds 윤활 방정식 — CMP 축약형과 유효막두께

### 1.1 모델식

**(1a) 일반 3-D Reynolds 방정식 (패드 다공성·처짐 포함, Thakurta 2001 Eq.13)**

```
(1/12μ)·∇·[(h−s)³ ∇P_f] + (1/2)∇·[(h−s)(u₁+u₂)] + (1/2)(∇h+∇s)·(u₂−u₁) + w₂ − w₁ = 0
    s  = −c·P_f        (패드 처짐, Hooke 가정)
    w₂ = −k·P_f        (패드 다공성 누설, Darcy형)
    경계조건: P_f = 0 (웨이퍼 가장자리)
    폐합조건: ∬P_f dA = p·A_w,  두 방향 모멘트 = 0  (3 미지수 h₀, S_x, S_y)
```

**(1b) 2-D 정상·강체·비다공성 축약형 (Sundararajan 1999 Eq.2 = P1)**

```
d/dx [ h³ · dP/dx ] = 6 μ V dh/dx
    P(0)=0, P(L)=0
    (1/L)∫₀^L P dx = p            (하중 평형)
    ∫₀^L P x dx / ∫₀^L P dx = L/2 (모멘트 0)
```

**(1c) 유효막두께 정의 — 두 개가 서로 다른 물리량이다(혼동 주의)**

```
δ_eff = α·Ra + (1−α)·d_g        ... (반응기 부피용 "슬러리 보유 두께", P4 Eq.4)
h_min = min_x h(x)               ... (윤활용 "최소 유체 간극", P1/Thakurta)
```
`δ_eff`는 그루브 부피를 포함한 **저류 높이**이고, `h_min`은 land 위에서 실제로 하중을 지지하는
**간극**이다. 레짐 판별에 써야 하는 것은 `h_min`이며, `δ_eff`를 레짐 판별에 쓰면 그루브 깊이
(~10²µm)가 들어가 So를 2~3오더 과소평가한다.

| L | 웨이퍼 특성길이(직경) | m | L |

### 1.3 차원 검사

(1b) 좌변 `d/dx[h³ dP/dx]` → L³·(M L⁻¹T⁻²/L)/L = **M T⁻²**.
우변 `6μV dh/dx` → (M L⁻¹T⁻¹)(L T⁻¹)(1) = **M T⁻²**. ✅ 일치.

(1a) 첫 항 `(1/12μ)∇·[(h−s)³∇P_f]` → (M⁻¹LT)·L⁻¹·L³·(M L⁻¹T⁻²/L) = **L T⁻¹**(속도).
둘째 항 `∇·[(h−s)(u₁+u₂)]` → L⁻¹·L·LT⁻¹ = **L T⁻¹**. 넷째 항 `w₂−w₁` → **L T⁻¹**. ✅ 모두 속도 차원.
`w₂ = −kP_f` 의 k는 m/(Pa·s)여야 속도가 나온다 — 즉 k는 무차원 기공률(%P)이 **아니다**.
(FabSim `slurry_film_lubrication.h_min_scaling(k_porosity=…)`은 k를 무차원 감쇠인자로 쓰므로
차원상 원 논문의 k와 다른 양이다. §1.8 참조.)

### 1.4 유도 가정과 각각이 깨지는 조건

| # | 가정 | 깨지는 조건 |
|---|---|---|
| A1 | 얇은막(h ≪ L), 압력이 두께방향 일정(∂P/∂z=0) | h/L이 10⁻²를 넘을 때 — CMP에서는 h~10⁻⁵m, L~10⁻¹m라 h/L~10⁻⁴, 안전 |
| A2 | 관성 무시(환산 Re* ≪ 1) | Re* = (ρVL/μ)(h̄/L)² 가 O(1)에 접근할 때. P1은 Re*<10⁻⁵로 계산. 고점도·저속에서는 더 안전, **초고속 회전이나 그루브 내부 박리 유동에는 부적용** |
| A3 | 뉴턴 유체, 점도가 공간적으로 일정 | 전단증점/전단박화 슬러리(고고형분·고이온강도). CMP 전단속도 10³~10⁵ s⁻¹ 구간 안에서 증점 개시가 보고된 계가 존재 → 단일 스칼라 μ 금지 |
| A4 | 패드·웨이퍼 강체, 표면 매끈 | 거칠기가 h와 같은 오더일 때. **CMP에서는 실제로 깨진다**(§1.6) — 이것이 이 축의 가장 중요한 한계 |
| A5 | 측면 유출(z방향) 무시 (2-D 한정) | 웨이퍼 회전을 명시적으로 넣어야 할 때. Thakurta 자신이 3-D h_min이 2-D 예측의 절반 미만이라고 보고 → **2-D는 막두께를 과대예측한다** |
| A6 | 간극이 슬러리로 완전히 채워짐(연속상) | 기포 혼입, 그루브 이탈 구간, 슬러리 기아 |
| A7 | 정상상태 | 웨이퍼 진입/이탈, 압력 스텝, 컨디셔너 스윕 주기 |

### 1.5 무차원수와 항 무시 판단

```
Re* = (ρ V L / μ)·(h̄/L)²        환산 레이놀즈수 → 관성항 무시 여부
```
전형 CMP 값(P1 자체 계산): Re* < 10⁻⁵. 따라서 Navier–Stokes 대류항은 Reynolds 방정식 대비
5오더 작다 → **완전히 무시 가능**. 이것이 "CMP에 NS 전체를 풀 필요가 없다"의 정량 근거다.

다공성·압축성 항의 상대 크기는 Thakurta 무차원군으로 판정한다:
```
k·p/z₀  (다공성 누설/드래그 유입 비),  c·p/z₀  (처짐/막두께 비)
z₀ = sqrt(2 μ ω₂ R₁ R₂ / p)        (Thakurta Eq.19, 길이 스케일)
```
두 군이 ≪1이면 (1a)는 (1b)로 축약된다. **z₀와 P1의 스케일은 동일한 군이다**: 이번 감사에서
`z₀ = √2·√(μ U R₁/p)` (U=ω₂R₂ 대입 시 수치적으로 정확히 일치, 아래 재현) — 즉 두 논문이 독립적으로
같은 스케일을 쓴다는 교차검증이 성립한다. 재현: μ=5e-3, ω₂=6.283 rad/s, R₁=0.1016 m, R₂=0.1778 m,
p=21 kPa → z₀ = 232.48 µm, √2·√(μU R₁/p) = 232.48 µm (일치).

### 1.6 극한 거동

| 극한 | 식의 예측 | 물리적 타당성 |
|---|---|---|
| μ → 0 | h_min → 0 (스케일 ∝ μ^{1/2}) | ✅ 점성 없으면 부양 불가 → 완전 고체접촉 |
| μ → ∞ | h_min → ∞ | ⚠ **부분적으로만 타당**. 실제로는 h가 거칠기·그루브 깊이에 도달하면 유동장 가정이 깨지고 하이드로플레이닝으로 전이해 Reynolds 축약형 자체가 무효 |
| V → 0 | h_min → 0 | ✅ 드래그 유입이 사라져 스퀴즈만 남음 |
| p → 0 | h_min → ∞ | ⚠ 하중이 없으면 간극이 무한대라는 것은 수학적 귀결일 뿐 — 실제로는 슬러리 공급·중력이 h를 결정 |
| p → ∞ | h_min → 0 | ✅ 접촉 지배 |
| h → Ra | Reynolds 해 자체가 무의미 | **CMP의 실제 운전점이 여기다** (§3) |

### 1.8 FabSim 현 구현과의 차이

- `sim/tier2_physics/slurry_film_lubrication.py`는 **z₀ 스케일만** 구현하고 2-D PDE는 풀지 않는다.
  모듈 docstring이 이를 명시하고 있고, engine의 `_film_thickness_diagnostic`도 진단 전용으로만 쓴다
  (MRR 경로 미연결). 정직하게 표기돼 있으므로 **허위 아님** — 다만 "h_min을 계산한다"고 읽힐 여지가
  있는 필드명(`film_z0_scale_um`)은 이미 note로 방어되어 있다.
- 해당 모듈 self-test에 `h_min(논문 36µm)/z₀ = 0.155`가 범위 밖으로 FAIL 상태로 남아 있다.
  **이번 감사에서 원인 후보를 좁혔다**: z₀는 *무차원화 기준 스케일*이고, 논문 Fig.6c가 보이듯
  h_min/z₀는 d₀/z₀의 함수다. 위 조건에서 d₀/z₀ = 10 µm/232 µm = 0.043이며, P1이 제시한
  안정 경계 `d₀/√(μUL/p) < 0.085`(역류 발생 조건)과 같은 오더의 작은 값이다. 즉 h_min/z₀가
  O(1)일 이유가 애초에 없다 — **FAIL을 통과시키려 범위를 넓히지 말고, 이 check를 "O(1) 기대"에서
  "d₀/z₀의 함수이므로 상수 비교 불가"로 재정의하는 것이 옳다.** (수정은 이 감사 범위 밖.)
- `h_min_scaling(mu, U, P_app, k, c)`의 `k_porosity`/`c_compress`는 무차원 감쇠인자이며 원 논문의
  k[m/(Pa·s)]·c[m/Pa]와 **차원이 다르다**. 정성 부호 재현 목적임이 docstring에 적혀 있으나,
  이름이 같아 혼동 위험이 있다.
- (1b) 2-D 축약형과 그 역류(reverse flow) 안정조건은 **FabSim에 미구현**. §1.9 참조.

### 1.9 미구현이지만 값싼 것 — 역류(recirculation) 판정

P1은 웨이퍼 입구에서 역류가 생기는 조건을 닫힌형으로 준다:
```
d₀ / sqrt( μ V L / p )  <  0.085     → 역류 발생(불안정, 엣지 비균일 유발)
```
차원 검사: 분자 L, 분모 √[(M L⁻¹T⁻¹)(LT⁻¹)(L)/(M L⁻¹T⁻²)] = √(L²) = L → **무차원** ✅.
이 한 줄은 μ·V·p·곡률을 모두 쓰는 **무차원 안정성 게이트**이고 FabSim에 없다. §4의 체류시간
재순환 논의와 직접 연결된다.

## 2. Sommerfeld 수 vs Hersey 수 — 정의 차이와 무차원 여부

### 2.1 모델식

```
Hersey 수 :  He = μ V / p                  [P2 Eq.(1), Mullany & Byrne 2003]
Sommerfeld 수(CMP 관례) :  So = μ V / (p · δ_eff)   [US20110076924A1]
```

### 2.2 차원 검사 — **이것이 이 절의 핵심**

```
He = μV/p → (M L⁻¹T⁻¹)(L T⁻¹)/(M L⁻¹T⁻²) = L      ⇒ 길이 차원! 무차원이 아니다.
So = He/δ_eff → L/L = 1                            ⇒ 무차원.
```
P2가 보고한 Hersey 값이 이를 뒷받침한다: 상용 폴리셔 **1.5×10⁻⁸**, 실험 폴리셔 **2×10⁻⁸**.
"작은 수"가 아니라 **~20 nm 길이**다. 이번 감사에서 P2 Table 1(μ=0.99/1.47/1.74 cP, V=0.059 m/s,
p=3.5 kPa)로 직접 재계산하면 He = 1.67×10⁻⁸ / 2.48×10⁻⁸ / 2.93×10⁻⁸ m로, 저자가 보고한
"2×10⁻⁸ 오더"와 **일치**한다(재현 성공).

⇒ **He는 유체역학적 부양이 만들 수 있는 특성 막두께 ℓ_hd 그 자체다.** CMP 전형 조건
(μ=1e-3 Pa·s, V=0.75 m/s, p=3 psi)에서 ℓ_hd = 36.3 nm. 패드 Ra(~µm)보다 2오더 작다.

| 항목 | Hersey He | Sommerfeld So (CMP 관례) |
|---|---|---|
| 식 | μV/p | μV/(p·δ_eff) |
| 차원 | **길이 [m]** | **무차원** |
| 해석 | 부양 가능 막두께 스케일 ℓ_hd | ℓ_hd를 표면 스케일로 정규화한 값 |
| 로그 가로축으로 쓸 때 | 장비별 스케일이 섞임 | 장비 간 비교 가능 |
| 1차 출처 | P2 Eq.(1) (원전은 베어링 문헌 — **CMP 맥락 1차 출처는 P2**) | US20110076924A1 |

주의: 일부 2차 문헌이 `So = ηVp/δ`로 적는다. 차원상 틀렸고(압력이 분자) 저장소 노트
`cmp-lubrication-regimes.md §2`가 이미 이를 오식으로 판정했다 — 이번 감사도 같은 결론.

### 2.3 유도 가정과 깨지는 조건

- He/So 모두 **뉴턴 유체** 전제(P2가 명시적으로 "Stribeck 개념은 뉴턴 유체 기반"이라 경고).
  전단의존 점도 슬러리에서는 μ가 단일 값이 아니므로 가로축 자체가 정의되지 않는다.
- So는 δ_eff 정의에 민감하다. δ_eff = α·Ra + (1−α)·d_g에서 그루브 항을 넣느냐 빼느냐로
  So가 2오더 이상 달라진다. **δ_eff의 그루브 가중 관례를 확정한 1차 출처는 P4 Eq.(4)**
  (Philipossian & Olsen 인용, 원 CMP-MIC 프로시딩 원문은 **미확보** → P4를 통한 2차 인용).
  단 P4에서 이 δ_eff는 **반응기 부피 계산용**이지 레짐 판별용이 아니다(§1.1c) — 즉 현재 CMP 관례는
  같은 기호를 두 목적에 쓰고 있으며, 이 중의성은 **문헌 차원의 미해결**이다.
- 정규화 길이로 δ_eff 대신 합성 RMS 거칠기 σ를 쓰면 So ≈ λ가 된다(§3).

### 2.4 무차원수 크기에 따른 항 무시

| So 범위 | 지배 항 | 무시 가능 항 |
|---|---|---|
| So ≲ 10⁻² | 고체 접촉 전단 | 점성 전단(유체 기여 ≈ floor) |
| 10⁻² ≲ So ≲ 10⁻¹ | 둘 다 | — (혼합, 어느 것도 못 버림) |
| So ≳ 10⁻¹ | 점성 전단 | 고체 접촉(접촉분율 f→0) |

경계값 자체는 관례이며 **CMP 전용 캘리브레이션 문헌 미확보**(§3.3).

### 2.5 극한 거동

- μ→0 또는 V→0: He→0, So→0 → 순수 경계윤활. ✅
- p→∞: So→0. ✅
- δ_eff→0 (완전 평활 패드): So→∞ — ⚠ 수학적 발산. 실제로는 δ_eff에 하한(분자 스케일)이 있고
  그 전에 접촉역학이 지배한다.

### 2.6 파라미터 분류

μ/V/p: 독립 측정 가능. Ra, d_g: 독립 측정 가능. α: 기하 계산. **δ_eff의 가중 형태 자체: 문헌값 차용
(그리고 §2.3대로 중의적)**. λ 경계값(1, 3): **문헌값 차용, CMP 검증 안 됨**.

### 2.7 FabSim 현 구현과의 차이

- `cmp_lubrication_regime.cmp_sommerfeld`는 `μV/(p·δ_eff)` — 차원 정합 형태로 올바르다. ✅
- `tribology_basics.hersey_number(eta, N, P)` docstring이 "무차원이 아닐 수 있다"고만 적어 두었다.
  **이번 감사에서 P2 1차 출처로 확정: CMP 관례의 He = μV/p는 길이 차원이며, 그 값은 곧 ℓ_hd다.**
  docstring을 이 결론으로 승격할 수 있다(수정은 감사 범위 밖).
- `engine._lubrication_diagnostics`는 `d_eff = delta_eff(Ra, 0.0, 1.0) = Ra` 로 그루브 항을 의도적으로
  버린다. §2.3 기준으로 **레짐 판별 목적이라면 이 선택이 옳다**(그루브 깊이를 넣으면 So가
  저평가된다). 근거를 note로 남기는 것이 좋다.
- 같은 함수가 `lam = so`로 두는데, 이는 δ_eff≈σ 근사에서만 성립하는 **오더 등식**이다. 코드 주석에
  이미 "정량 항등식 아님"으로 적혀 있다. ✅

## 3. Stribeck 곡선 — 레짐 경계 판정과 접촉분율 f

### 3.1 모델식

```
λ = h_min / σ                                (막두께비)
레짐:  λ < 1  boundary | 1 ≤ λ < 3  mixed | λ ≥ 3  full-film

COF(So) = f·μ_bl + (1−f)·c_h·So + μ_floor
f(So)   = exp(−α_tr · So)                    (접촉분율, FabSim 채택형)
```

### 3.2 기호·단위표

| 기호 | 의미 | 단위 |
|---|---|---|
| λ | 막두께비 | – |
| σ | 합성 RMS 거칠기 | m |
| f | 고체-고체 접촉분율 | – (0~1) |
| μ_bl | 경계윤활 COF | – |
| c_h | 유체전단 계수 | – (So당) |
| α_tr | 전이 급격도 | – (So⁻¹) |

### 3.3 차원 검사

λ = L/L = 1 ✅. f = exp(−무차원) ✅ (α_tr·So가 무차원이어야 하므로 α_tr도 무차원).
COF = 무차원 ✅. c_h·So는 무차원이므로 c_h 무차원 ✅.

### 3.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| Stribeck 가로축이 단일 스칼라(He 또는 So)로 정의된다 | 비뉴턴 슬러리(P2가 명시 경고) |
| 하중분담이 f로 선형 분해된다(고체 f, 유체 1−f) | 입자 매개 3체 접촉이 지배할 때 — CMP는 원래 3체다 |
| f = exp(−α_tr·So) | **이 함수형의 1차 출처를 찾지 못했다.** GW 접촉모델에서 유도하면 f는 h/σ의 가우시안 상보오차함수꼴이지 지수꼴이 아니다 → **f의 지수형은 FabSim의 편의 가정이며 문헌 근거 미확보** |
| λ 경계값 1, 3 | 일반 트라이볼로지 관례. **CMP 전용 캘리브레이션 미확보** |
| COF 절대값이 μ_bl, c_h, α_tr 세 상수로 재현된다 | 실측 캘리브레이션 없이는 정량 불가(저장소 노트도 같은 결론) |

### 3.5 무차원수 판정과 CMP의 운전점

§2.2 결과: ℓ_hd ≈ 36 nm ≪ Ra ≈ 5 µm ⇒ λ ≈ 7×10⁻³ ≪ 1 ⇒ **CMP는 구조적으로 boundary/mixed**.
이것이 Preston식(ḣ = K_p·p·V)이 성립하는 전제다.

**실험적 교차검증(이번 감사에서 P2로 확보)**: P2는 점도만 바꾼 3종 슬러리(0.99/1.47/1.74 cP,
같은 연마입자 함량)로 Stribeck 곡선을 실측했고, He 증가에 따라 COF가 **하강**했다 →
Stribeck 최소점의 **왼쪽 가지(경계~혼합)**에 있다는 직접 실측이다. 동시에 단위 미끄럼거리당
제거량도 He 증가에 따라 감소했다. 즉 "CMP는 boundary/mixed"는 오더 논증만이 아니라
**점도를 독립변수로 바꾼 실측으로도 확인된다** — 이는 저장소 노트가 "실측 산점도 원데이터
미확보"로 남겨둔 항목을 **부분 해소**한다.

### 3.6 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| So→0 | COF → μ_bl + μ_floor | ✅ 경계윤활 평탄 구간 |
| So→∞ | COF → c_h·So → ∞ | ⚠ 형식적으로는 발산하지만, 실제 full-film에서 COF=μV/(h·p)이고 h도 So와 함께 커지므로 무한 상승은 물리적이지 않다. 모델은 So≲O(1)에서만 써야 한다 |
| σ→0 | λ→∞ → full-film 판정 | ⚠ 평활면이라도 하중이 크면 접촉한다 — λ 단독 판정의 한계 |
| f: So→0 ⇒ f→1, So→∞ ⇒ f→0 | ✅ 경계조건은 옳다 | 중간 구간 함수형만 미검증 |

### 3.7 파라미터 분류

- λ, σ, h_min: **독립 측정 가능**(σ는 프로파일로미터, h_min은 모델 산출 또는 특수 계측).
- μ_bl: **문헌값 차용**(산화막 CMP 0.23~0.40 오더 — 저장소 노트 기준, 원 저널 원문 미확보).
- c_h, α_tr: **피팅 필요**. 현재 FabSim 기본값(8.0, 40.0)은 **정성 형태를 맞추기 위한 임의값**.
- λ 경계 1/3: **문헌값 차용, 미검증**.

### 3.8 FabSim 현 구현과의 차이

- `cmp_lubrication_regime.cof_stribeck`와 `tribology_basics.stribeck_cof`가 **같은 구조를 두 번**
  구현하고 기본 파라미터만 다르다(μ_bl 0.30 vs 0.15, c_h 8.0 vs 0.02, α 40 vs 50).
  `equipment_outputs.py`는 전자를 호출하도록 통일돼 있고 그 이유(2026-09-08 사고: 로지스틱 자작 시
  마찰발열이 압력에 무반응)가 주석으로 남아 있다 — 좋은 기록이다. 다만 **두 구현의 공존 자체가
  잠재적 중복**이며, `tribology_basics` 쪽은 학습용임을 명시하는 것이 안전하다.
- `f = exp(−α_tr·So)`의 **문헌 근거가 없다**는 사실은 코드 어디에도 적혀 있지 않다(§3.4).
  "정성 모델"이라는 표기는 있으나 "함수형 자체가 미확보"라는 구체적 표기는 없다 → 보강 권고.
- λ 판정이 engine에서 `lam = so`로 대체되어 있어, **실질적으로 λ 축은 독립적으로 존재하지 않는다**.

## 4. 슬러리 유량(SFR) → 웨이퍼 아래 실제 도달량 — 체류시간·재순환

### 4.1 모델식 (P4 원전, P5가 그루브 축으로 확장)

```
η   = q_actual / Q_total × 100 %                (슬러리 이용효율, P4 Eq.1)
q_actual = V_reactor / τ                        (P4 Eq.2)
V_reactor = π r² · δ_eff                        (P4 Eq.3)
δ_eff = α·Ra + (1−α)·d_g                        (P4 Eq.4)
τ   = ∫₀^∞ t·E(t) dt,   E = dF/dt               (P4 Eq.5,6 — RTD 정의)
⇒ η = 100·π r²[α Ra + (1−α)d_g] / (Q_total · τ)   (P4 Eq.7)

그루브 분해형(P5): V_total = V_land + V_groove
   V_land   = (1−GFQ)·A_w·h_land,   V_groove = GFQ·A_w·d_g,   GFQ = w_g/p_g
```

### 4.2 기호·단위표

| 기호 | 의미 | 단위 |
|---|---|---|
| Q_total | 공급 슬러리 유량(SFR) | m³/s (실무 mL/min) |
| q_actual | 웨이퍼 아래 실제 통과 유량 | m³/s |
| η | 이용효율 | – (%) |
| τ | 평균체류시간 MRT | s |
| V_reactor | 패드-웨이퍼 계면 반응기 부피 | m³ |
| E(t) | 체류시간 분포 | s⁻¹ |
| F(t) | 누적분포 | – |
| GFQ | 그루브 면적/폭 분율 w_g/p_g | – |
| A_w | 웨이퍼 면적 | m² |
| h_land | land 위 슬러리 막두께 | m |

### 4.3 차원 검사

τ = V/q → L³/(L³T⁻¹) = **T** ✅.
η = q/Q → 무차원 ✅.
E의 차원: F 무차원이므로 E = dF/dt → T⁻¹, τ = ∫t·E dt → T·T⁻¹·T = **T** ✅.
V_land = (1−GFQ)·A·h_land → L²·L = L³ ✅.

### 4.4 정량 재현 (이번 감사에서 직접 수행)

P5 Table 2/3 재현(웨이퍼 200 mm, h_land=15 µm @3 PSI, d_g=400 µm, land=1200 µm):

| w_g (µm) | GFQ | V_land 계산/문헌 (cm³) | V_groove 계산/문헌 | τ 문헌 (s) | q_actual=V/τ 계산/문헌 (mL/min) | η 계산/문헌 |
|---|---|---|---|---|---|---|
| 300 | 0.200 | 0.38 / 0.38 | 2.51 / 2.66 | 9.2 | 19.8 / 19.8 | 9.9% / 9.9% |
| 600 | 0.333 | 0.31 / 0.31 | 4.19 / 4.41 | 10.6 | 26.7 / 26.7 | 13.4% / 13.4% |
| 900 | 0.429 | 0.27 / 0.27 | 5.39 / 5.64 | 13.9 | 25.5 / 26.1 | 12.8% / 12.8% |

V_land는 완전 일치, V_groove는 계산이 문헌보다 4~5% 낮다(논문이 land 폭을 그루브 벽면까지
포함하는 등 미세한 기하 관례 차이로 보이나 **원문에 계산 상세가 없어 확정 불가 — 미검증**).
q_actual·η는 문헌 τ를 쓰면 재현된다.

### 4.5 핵심 정량 사실 (모두 1차 출처)

1. **η는 2~22% 범위다** (P4 결론). 즉 **공급 SFR의 80% 이상은 웨이퍼 아래에 도달하지 않는다.**
   이것이 "SFR을 올리면 MRR이 오른다"가 자주 실패하는 이유다.
2. **SFR을 2배로 낮추면 η가 평균 약 25% 증가한다** (P4, Phase I). 즉 η는 Q_total에 대해
   **감소 함수**다 — "유량을 늘리면 이용률이 는다"는 통념을 P4가 명시적으로 반박한다.
   ⚠ 주의: η가 오르는 것과 q_actual이 오르는 것은 다르다. q_actual = η·Q_total이므로
   유량 반감 시 q_actual는 약 0.5×1.25 = 0.63배로 **여전히 줄어든다**. 이 절의 논점은
   "효율"이지 "절대 도달량"이 아니다.
3. **상대속도 V가 η를 지배한다**: 2배 속도 → η 2배(P4 Phase I). 패드 표면 유체가 패드와 같은
   속도로 끌려 들어가기 때문. 압력 효과는 훨씬 약하다(낮은 p에서 막이 두꺼워져 미세 증가).
4. **패드 표면 텍스처가 η를 3배 이상 바꾼다**: 같은 조건에서 저류 부피비 3.1배 ↔ η비 3.2배로
   거의 비례(P4). 즉 **η의 1차 결정 변수는 계면 저류 부피다**.
5. τ는 압력이 오르면 짧아진다(막이 얇아져 부피가 줄어서, P5).

### 4.6 재순환(recirculation)

- P1은 웨이퍼 **입구에서 역류**가 생기는 조건을 닫힌형으로 준다(§1.9). 역류는 슬러리 재순환과
  유동 불안정을 낳고 엣지 비균일로 나타난다.
- P4/P5의 RTD 모델은 **CSTR형 완전혼합**을 암묵 가정한다(사역/정체영역 없음을 P4가 명시적으로
  전제). 역류·정체가 존재하면 q_actual = V/τ 자체가 과대평가된다 — **두 문헌의 가정이 서로
  긴장 관계에 있으며, 이를 통합한 문헌은 미확보.**

### 4.7 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 사역·정체영역 없음(P4 명시) | 저류 부피가 과대할 때(§5의 폭 확대 정체 구간), 역류 발생 시 |
| 입자가 유체를 따라간다(Stokes 수 ≪1) | 굵은 응집체. P4는 St≈10⁻⁴, P5는 St<0.1로 계산 — **입자 크기가 µm급으로 커지면 재검토** |
| 트레이서(입자농도)와 COF의 대응이 단조 | COF-농도 관계가 비단조인 계 |
| δ_eff가 계면 부피를 대표 | 그루브가 마모로 얕아지면 δ_eff가 시간의존이 됨 |
| h_land를 상수로 가정 | P5는 3 PSI=15 µm, 5 PSI=10 µm를 **가정값으로 쓴다**(별도 문헌 인용) — 이 값 자체는 이 실험에서 측정된 것이 아니다 |

### 4.8 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| Q_total → 0 | η → 100%로 발산 경향 | ⚠ 식 자체는 η=q/Q라 Q→0에서 무의미. 실제로는 슬러리 기아로 MRR 붕괴 |
| Q_total → ∞ | η → 0 | ✅ 넘치는 슬러리는 패드 밖으로 버려진다 |
| τ → 0 | q_actual → ∞ | ⚠ 부피가 유한이면 τ에 하한이 있다 |
| d_g → 0 (그루브 소진) | V→V_land, τ 급감, η 급감 | ✅ 패드 수명말 거동과 정합 |

### 4.9 파라미터 분류

| 파라미터 | 분류 |
|---|---|
| Q_total | **독립 측정 가능**(레시피) |
| τ | **독립 측정 가능**(RTD 실험) — 단 장비 내 in-situ 계측 필요 |
| V_reactor | **기하 계산 + h_land 가정** → h_land는 **문헌값 차용/가정** |
| η | **측정 결과**(직접 피팅 대상 아님) |
| α, GFQ, d_g, Ra | **독립 측정 가능** |

### 4.10 FabSim 현 구현과의 차이

- `pad_groove_wear_flow.residence_time_s(...)`가 τ = V_total/q_actual을 구현하고 있다. ✅
  그러나 **q_actual을 입력으로 받는다** — 즉 "SFR에서 q_actual을 얻는" 고리(η)가 없다.
- `η`를 다루는 곳은 `sim/factors.py`의 τ 팩터뿐이며, **Mu 2016 Table 3의 실측 3점 선형보간**으로
  η(w_g)만 쓴다. §4.5의 더 강한 사실들 — **η ∝ V(속도 2배→η 2배), η는 Q_total에 대해 감소,
  η ∝ 저류 부피** — 은 FabSim에 전혀 반영돼 있지 않다. **이것이 이 감사에서 발견한 가장 큰 공백이다**:
  슬러리 유량 축이 "그루브 폭 3점 보간"으로만 존재하고, 1차 출처(P4)가 주는 속도·유량 의존성이
  빠져 있다.
- 역류 안정조건(§1.9)은 미구현.
- `factors.py`가 `slurry_viscosity_pa_s`를 τ 팩터에서 **의도적으로 제외**하고 그 사유를
  "Prasad/Mu 문헌에 정량 관계가 없어서"로 적어 두었다 — τ 축에 한정하면 이 판단은 옳다.
  그러나 MRR 축 전체로 확장하면 **틀렸다**(§7).

## 5. 그루브 형상 → 슬러리 수송 효율 — 최적 폭이 존재하는 이유

### 5.1 모델식

```
GFQ = w_g / p_g                                (폭 분율; 접촉면적비 = 1 − GFQ)
GSQ = d_g / T_pad                              (강성 지표)
V_groove = GFQ · A_w · d_g,  V_land = (1−GFQ)·A_w·h_land
τ(w_g) = [V_land + V_groove] / q_actual
η(w_g) = q_actual / Q_total = V_total(w_g) / (τ(w_g)·Q_total)

채널 컨덕턴스(직사각 덕트 Poiseuille, 짧은 변 h):
G(w,h) = (w h³/12)·[1 − (192 h)/(π⁵ w)·Σ_{n odd} tanh(nπw/2h)/n⁵]
```

### 5.2 기호·단위표

| 기호 | 의미 | 단위 |
|---|---|---|
| w_g | 그루브 폭 | m |
| d_g | 그루브 깊이 | m |
| p_g | 피치(= land 폭 + w_g) | m |
| T_pad | 패드 두께 | m |
| G | 컨덕턴스 (Q = G·Δp/(μ·L_ch)) | m⁴ |

### 5.3 차원 검사

GFQ, GSQ 무차원 ✅. G = w·h³ = L⁴ ✅ → Q = G·(Δp/L_ch)/μ → L⁴·(M L⁻¹T⁻²/L)/(M L⁻¹T⁻¹) = L³T⁻¹ ✅.

### 5.4 왜 "최적 폭"이 존재하는가 — 메커니즘 분해

세 효과가 서로 반대로 작동한다:

1. **저류 부피 ↑** (w_g↑ → V_groove ∝ GFQ·d_g ↑): 슬러리 보유·수송량 증가 → η↑.
2. **체류시간 ↑** (τ = V/q): 같은 부피 증가가 τ를 함께 늘린다. η = V/(τ·Q)이므로 **V와 τ가
   같은 비율로 늘면 η는 변하지 않는다** — 이것이 포화의 수학적 원인이다.
3. **접촉면적 ↓** (1−GFQ 감소): 같은 하중이 좁은 land에 실려 국소압이 오르고 패드 강성·평탄화
   능력이 떨어진다(GSQ/GFQ 특허 근거).

P5 실측이 이 셋의 합성을 그대로 보여준다: w_g 300→600 µm에서 η가 3 PSI 9.9→13.4%(+35% 상대),
5 PSI 10.6→14.7%(+39%)로 **크게 증가**하지만, 600→900 µm에서는 13.4→12.8% / 14.7→13.6%로
**정체·미세 감소**한다. 저자의 설명이 정확히 (2)다: V_total과 τ가 함께 커져 q_actual이
26.7→26.1 mL/min으로 거의 안 변한다.

⇒ **최적 폭의 존재는 "저항이 줄어서 좋다"가 아니라 "부피는 늘지만 체류시간도 같이 늘어
   유량비가 포화한다"에서 나온다.** 컨덕턴스(§5.1 G)는 단조 증가 함수이므로 **컨덕턴스만으로는
   최적을 설명할 수 없다** — 이 점이 이 절의 핵심 결론이다.

### 5.5 깊이·피치의 역할 (폭과 구분)

- **깊이 d_g**: V_groove ∝ d_g이므로 저류 부피에 **선형**. 그러나 컨덕턴스는 G ∝ h³로 **3승**이므로,
  마모로 깊이가 줄면 컨덕턴스가 깊이비보다 훨씬 빠르게 떨어진다(FabSim `conductance_ratio`가
  이를 구현). 즉 깊이는 "부피(선형)"와 "통수능(3승)" 두 경로로 동시에 작용한다.
- **피치 p_g**: GFQ = w_g/p_g를 통해 폭과 결합해서만 들어간다. 같은 GFQ를 유지하면서 피치를
  키우면 그루브 간 land 스팬이 길어져 슬러리가 재공급되기까지의 거리가 늘어난다
  (→ 갱신 시간 증가). 이 방향성은 CFD 시뮬레이션 인용으로만 존재하며, **피치를 독립변수로
  분리해 η를 측정한 실험 1차 출처는 미확보**.
- **패턴 형상(연속 그루브가 아닌 이산 미세패턴)**: 둘레/면적 지표(DICL류)가 압력강하보다 MRR을
  잘 설명한다는 1차 실험 보고가 있다(Sadri Mofakham 2024, DOI 10.1149/2162-8777/ad8fd3).
  이는 "수송 효율 = 부피"가 아니라 "수송 효율 = 신선 슬러리가 접촉선에 닿는 경계길이"라는
  **다른 축**이 존재함을 시사한다. 두 지표(GFQ/부피 vs 둘레/DICL)를 통합한 모델은 **미확보**.

### 5.6 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 그루브가 완전히 슬러리로 채워짐 | 고속 회전에서 원심력에 의한 배출, 기포 |
| 단면이 직사각(컨덕턴스식) | V/U자 단면, 마모로 모서리가 둥글어진 경우 |
| land 막두께 h_land가 폭과 무관 | 폭이 극단적으로 넓으면 land가 좁아져 국소압↑ → h_land↓ |
| 완전혼합 반응기 | §4.7과 동일 |
| d_g가 시간 불변 | 컨디셔닝 마모 — 실제로는 항상 깨진다 |

### 5.7 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| w_g → 0 | GFQ→0, V_groove→0, τ→V_land/q, η → 최소 | ✅ 무그루브 패드 = 슬러리 기아·하이드로플레이닝 위험 |
| w_g → p_g | GFQ→1, land 면적→0 | ❌ 접촉면적이 0이면 연마가 불가능 — 식은 계속 값을 내지만 물리가 무너진다. **상한 가드 필요** |
| d_g → 0 | 컨덕턴스 → 0(3승), 부피 → V_land | ✅ 패드 수명말 |
| d_g → ∞ | V_groove→∞, τ→∞, η→포화 | ⚠ 패드 두께 T_pad가 물리적 상한(GSQ ≤ 1) |

### 5.8 파라미터 분류

w_g, d_g, p_g, T_pad: **독립 측정 가능**. h_land: **문헌값 차용/가정**(§4.7).
η(w_g) 곡선 형태: **실측 3점뿐 → 사이 구간은 보간, 외삽 금지**.
τ의 절대값: **측정 필요**(RTD).

### 5.9 FabSim 현 구현과의 차이

- `pad_groove_wear_flow.py`가 V_land/V_groove/τ/컨덕턴스비를 모두 구현하고 있고 Mu 2016 Table 2를
  self-test로 재현한다. ✅ 이 감사의 독립 재현(§4.4)과도 일치한다.
- `factors.py`의 η는 **폭 3점 선형보간**이며, 문헌 범위(300~900 µm) 밖에서는 근거가 없다.
  코드가 이를 명시하는지 확인 필요 — **외삽 가드 권고**.
- `factors.py`가 τ→MRR 결합 지수를 `n = ln(1.08)/ln(3) ≈ 0.07`로 두고 **기공률 실험에서 역산한
  값을 그루브 축에 교차 대입했다**고 스스로 적어 두었다. 이 교차 대입은 **미검증이며, 감사 결과
  더 나쁜 소식이 있다**: 그 실험(기공률 15→45%에서 RR +8%)은 "저류 용량"과 "모듈러스 저하"가
  상쇄된 순효과이므로, 상쇄 항이 없는 그루브 축에 그대로 옮길 근거가 없다. **지수 0.07은
  캘리브레이션 대상으로 명시적으로 강등하는 것이 정직하다.**
- `groove_depth_mm`/`groove_pitch_mm`을 드라이버에서 제외한 스코프 축소 결정은 기록이 명확하다.
  ✅ 다만 §5.5대로 **깊이는 컨덕턴스 3승 경로로 이미 다른 모듈에 들어와 있어**, "깊이는 τ에
  못 넣는다"와 "깊이는 컨덕턴스에 3승으로 들어간다"가 같은 저장소 안에 공존한다. 모순은 아니지만
  (다른 물리량) 독자가 혼동하기 쉽다.

## 6. 열 수송 — 마찰 발열 vs 슬러리 냉각의 정상상태 균형

### 6.1 모델식 (White/Melvin/Boning 2003, DOI 10.1149/1.1560642)

```
Q_f = μ_COF · p · A · V                                  마찰 동력 [W]
Q_f = (G_slurry + G_pad + G_air) · ΔT_ss                  정상상태 열저항 네트워크
  G_slurry = ṁ c_p = ρ Q_total c_p          [W/K]         슬러리 엔탈피 수송
  G_pad    = k_pad A_heated / L_pad          [W/K]         패드 두께방향 전도
  G_air    = h_air A_exposed,  h_air = a k_air √(Ω/ν)     회전원판 대류
⇒ ΔT_ss = Q_f / (G_slurry + G_pad + G_air)
```

### 6.2 기호·단위표

| 기호 | 의미 | 단위 |
|---|---|---|
| Q_f | 마찰 발열 | W |
| μ_COF | 마찰계수 | – |
| A | 웨이퍼 면적 | m² |
| ṁ | 슬러리 질량유량 | kg/s |
| c_p | 슬러리 비열 | J/(kg·K) |
| k_pad | 패드 열전도도 | W/(m·K) |
| L_pad | 패드 두께 | m |
| h_air | 대류계수 | W/(m²·K) |
| Ω | 플래튼 각속도 | rad/s |
| ν | 공기 동점성계수 | m²/s |
| ΔT_ss | 정상상태 계면 온도상승 | K |

### 6.3 차원 검사

Q_f = (1)(M L⁻¹T⁻²)(L²)(L T⁻¹) = M L² T⁻³ = **W** ✅.
G_slurry = (kg/s)(J/kg·K) = J/(s·K) = **W/K** ✅.
G_pad = (W/m·K)(m²)/(m) = **W/K** ✅.
h_air = (W/m·K)·√(s⁻¹/(m²s⁻¹)) = (W/m·K)(1/m) = **W/(m²·K)** ✅ → G_air = W/K ✅.
ΔT = W/(W/K) = **K** ✅.

### 6.4 유량이 열에 들어오는 유일한 정량 경로

`G_slurry = ρ·Q_total·c_p` — **이것이 SFR이 모델에 정량적으로 들어오는 유일하게 튼튼한 지점이다.**
Q_total = 200 mL/min, 물 물성 → G_slurry = 13.9 W/K. Q_f가 수백 W 오더이므로 ΔT는 10 K 오더가 된다.

⚠ **그러나 여기에 §4와의 심각한 불일치가 있다**: 열 모델은 **공급 유량 전체**가 계면 열을 실어
나른다고 가정하는데(완전 열교환), §4.5는 공급의 **2~22%만** 웨이퍼 아래에 도달한다고 말한다.
- 만약 계면 열이 웨이퍼 아래를 통과한 슬러리로만 빠져나간다면 G_slurry는 5~50배 과대평가다.
- 반대로 패드 위로 흐르는 슬러리도 패드를 식히므로 전량이 냉각에 기여한다고 볼 여지도 있다.
- **이 두 관점을 조정한 1차 출처를 찾지 못했다 — 미확보.** FabSim의 열 모듈은 전량 가정을
  쓰고 있으며, 이는 **ΔT의 하한(냉각 과대평가)** 쪽으로 편향된다.

### 6.5 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 세 싱크가 모두 같은 기준온도 T₀ | 플래튼 냉각 사용, 슬러리 공급온도 ≠ 실온 |
| 슬러리 출구가 패드 온도까지 완전히 데워짐 | 체류시간이 짧아 열교환이 불완전할 때(= §4의 τ가 작을 때) — **NTU가 작으면 G_slurry가 과대평가** |
| 웨이퍼/헤드 전도 무시 | 헤드 냉각·금속 캐리어 |
| 회전원판 층류 상관식(공기, Pr≈0.71) | Re_r > 1.8×10⁵ (난류 전이) |
| 정상상태 | 폴리싱 시간이 열시정수보다 짧을 때 — 짧은 스텝에서는 과도응답 지배 |
| μ_COF가 온도 무관 | 실제로는 온도↑ → 점도↓ → So↓ → COF↑ 의 **양의 되먹임** 가능 |

### 6.6 무차원수

```
NTU = (h_int A_int)/(ṁ c_p)      열교환 유효도 — NTU≫1일 때만 "완전 열교환" 가정 성립
Re_r = Ω r²/ν                    회전원판 층류/난류 판정 (층류 상한 ~1.8×10⁵)
Bi   = h L_pad / k_pad           패드 내부 온도구배의 1-D 타당성
Pe   = V L / a_th                슬러리 이류/확산 비 — Pe≫1이면 전도 무시
```
FabSim 열 모듈은 Re_r는 명시적으로 판정하지만 **NTU·Bi·Pe는 계산하지 않는다**.
특히 NTU는 §6.4 불일치의 판정 열쇠다.

### 6.7 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| Q_total → 0 | G_slurry→0, ΔT → Q_f/(G_pad+G_air) (유한) | ✅ 패드 전도·공기 대류가 남는다. 발산하지 않음 — 좋은 성질 |
| Q_total → ∞ | ΔT → 0 | ⚠ 무한 냉각은 비물리적. NTU 한계(계면 열전달계수)가 상한을 준다 — **모델에 없음** |
| V → 0 | Q_f→0, ΔT→0 | ✅ (G_air도 Ω→0으로 0이 되지만 ΔT는 0/유한 = 0) |
| p → ∞ | Q_f ∝ p → ΔT ∝ p | ✅ 선형 — 단 μ_COF(p) 의존이 있으면 깨진다 |
| k_pad → 0 | G_pad→0 | ✅ 패드가 단열체라는 실제 상황에 수렴 |

### 6.8 파라미터 분류

| 파라미터 | 분류 |
|---|---|
| Q_total, p, V, A, Ω | **독립 측정 가능** |
| ρ, c_p (슬러리) | **문헌값 차용**(물 근사) — 고형분 낮으면 타당 |
| k_pad | **문헌값 차용** |
| L_pad | **독립 측정 가능**(단 "열이 실제로 흐르는 유효 길이"는 두께와 다를 수 있음 → 이 경우 **피팅**) |
| A_heated, A_exposed | **기하 계산 + 모델 선택**(웨이퍼가 쓸고 가는 고리) |
| a (Nu 계수 0.3286) | **문헌값 차용**(정확 자기상사해) |
| μ_COF | §3대로 **피팅 필요** |

### 6.9 FabSim 현 구현과의 차이

- `cmp_theta_steady_state_heat_balance.py`가 위 네트워크를 그대로 구현하고, White 2003의
  Eq.3/5/9/10 수치를 self-test로 재현한다. ✅ 구현 품질이 이 축에서 가장 좋다.
- 모듈 docstring이 세 가지 한계(웨이퍼/헤드 전도 무시, 완전 열교환 가정, L_pad 유효길이)를
  스스로 적어 두었고 confidence를 올리지 않는다고 선언한다. ✅ 정직한 설계.
- **누락**: §6.4의 η(2~22%) 대 전량 냉각 가정 불일치는 **어디에도 기록돼 있지 않다**.
  이것은 슬러리 축과 열 축이 서로 다른 유량 정의를 쓰고 있다는 뜻이고, 두 축이 나중에
  결합될 때 조용히 5~50배 오차를 만들 수 있다.
- **누락**: NTU 무차원수 미계산 → "완전 열교환" 가정의 성립 여부를 자체 점검할 수 없다.

## 7. 특별 조사 — 슬러리 점도 μ가 MRR에 미치는 정량 관계

### 7.1 판정

> **판정: "문헌에 정량 관계가 없다"는 FabSim의 현재 전제는 틀렸다. 관계는 존재하며, 1차 출처도
> 있다. 다만 부호가 계에 따라 뒤집히고, 보편 상수가 있는 단일 멱법칙은 아니다.**

`sim/factors.py` 1046행이 "slurry_viscosity_pa_s도 τ 결합 문헌(Prasad/Mu)에 정량 관계가 없어
같은 이유로 제외한다"고 적고 있다. **τ 축(그루브/기공률)에 한정하면 이 진술은 맞다.** 그러나
"점도-MRR 관계가 문헌에 없다"로 일반화하면 틀리며, 실제로 세 계열의 1차 출처가 존재한다.

### 7.2 확보한 1차 출처 3건과 각각의 관계식

**(A) Mullany & Byrne 2003 (P2) — 점도만 바꾼 통제 실험, 부호: MRR ↓**

설계가 이 질문에 정확히 맞춰져 있다: 연마입자 함량을 10 vol%로 **고정**하고 나머지 90%를
물/증점제 비율로만 바꿔 점도 3수준(0.99 / 1.47 / 1.74 cP, 25 °C)을 만들었다. 저자 표현 그대로
"입자 수와 활성 화학종이 동일하므로 MRR 변화는 점도 변화만의 결과로 기대된다".

결과(원문 결론): 점도가 낮을수록 마찰이 높고 **MRR이 높다**. 단위 미끄럼거리당 제거량은
**He = μV/p 증가에 따라 단조 감소**한다(모든 속도·점도 조합).

```
d(MRR/L_slide) / d(He) < 0       He = μV/p   [m]
```
정량 계수(기울기)는 논문이 그래프로만 제시하고 표를 주지 않아 **수치 회귀계수 미확보**.
그러나 저자가 준 명시적 감도 수치가 하나 있다:

> **점도 10% 변화는 압력 또는 속도 10% 변화와 같은 크기의 막두께 변화를 일으킨다.
> 그리고 점도 10% 변화는 온도 5 °C 변화로 발생한다.**

이것이 이 감사에서 찾은 **가장 실용적인 정량 진술**이다. 즉 점도는 He 안에서 p, V와 **동등한
1차 가중치**를 가진다. 이는 FabSim이 이미 So/He를 계산하고 있으므로 **추가 피팅 없이 바로
쓸 수 있는 형태**다.

**(B) Grover, Liang, Ganeshkumar, Fortino 1998 (P3) — 산화막 vs 금속, 부호가 재료에 의존**

콜로이달 실리카계 슬러리에 점도 개질제를 농도별로 첨가(정규화 농도 0~5)하고 두 재료계를 비교:
- **산화막(주로 화학적, 연마입자가 제거를 매개)**: 첨가량 증가에 따라 **MRR이 거의 선형으로 감소**,
  고농도에서 감소율이 완만해짐(포화 조짐). 원문 표현 "the decrease in the removal rate was
  roughly linear".
- **금속(부동태막 형성-마모 반복형)**: **소량 첨가만으로 MRR이 급락**하고, 그 이상 첨가해도
  거의 변하지 않는다(계단형).
- 기전 분해: 금속계에서 개질제 첨가 후에는 **고형분 함량에 대한 MRR 의존이 강하게 나타난다**
  (첨가 전에는 고형분에 거의 둔감). 저자 해석 — 개질제가 산화(화학 경로)를 억제해 제거가
  기계적 경로로 전환된다.
- 또한 개질제가 **뉴턴 → 약한 전단박화**로 레올로지 자체를 바꾼다(즉 단일 스칼라 μ 가정도 함께 깨진다).

⇒ **점도-MRR 부호는 음(−)이며, 크기·형태는 재료계(화학 지배 vs 기계 지배)에 따라 선형 vs 계단형으로 갈린다.**

**(C) Stokes 드래그 경로 — 부호: MRR ↑ (반대 방향!)**

Lee et al. 2025 (Nanomaterials 15(16) 1248, DOI 10.3390/nano15161248, OA)은 정반대 방향의
정량 경로를 제시한다:
```
F_d = 3 π μ d_p V_rel          (Stokes 항력, 논문 Eq.2)
```
점도를 증점제로 올려 입자 항력을 키우면 입자-표면 접촉 확률이 올라 **기계적 제거가 증가**한다.
이번 감사에서 논문 수치를 직접 역검산했다: 보고된 F_d 값(μ=1.01 cP → 9.52×10⁻¹⁰ N,
μ=1.12 cP → 1.06×10⁻⁹ N, μ=0.98 → 9.2×10⁻¹⁰, μ=1.02 → 9.61×10⁻¹⁰, μ=1.13 → 1.06×10⁻⁹)은
d_p=100 nm, **V_rel = 1.00 m/s**를 넣으면 전부 0.5% 이내로 재현된다 — 즉 논문은 상대속도를
1 m/s로 고정해 F_d ∝ μ로 계산했다. 관측된 MRR은 **저점도 구간에서 μ와 함께 증가하다가 임계
농도 위에서 감소**(비단조, 증점제가 표면 차폐층을 만들기 때문).

차원 검사: F_d = (M L⁻¹T⁻¹)(L)(L T⁻¹) = M L T⁻² = **N** ✅.

### 7.3 세 출처를 어떻게 화해시키는가 — 경쟁하는 두 경로

점도는 **서로 반대 부호의 두 경로**로 MRR에 들어간다:

| 경로 | 식 | 부호 | 지배 조건 |
|---|---|---|---|
| (i) 막 부양 / 접촉 감소 | h ↑ with He=μV/p ↑ → 접촉분율 f ↓ | **MRR ↓** | 점도 변화가 막두께를 의미 있게 바꿀 때 (P2, P3) |
| (ii) 입자 항력 | F_d = 3πμ d_p V_rel ∝ μ | **MRR ↑** | 막두께가 이미 접촉 지배여서 변하지 않고, 입자 전달이 율속일 때 (Lee 2025) |
| (iii) 화학 경로 차폐 | 개질제가 반응층 형성/용해를 방해 | **MRR ↓** | 화학 지배 공정(P3의 금속계, Lee의 고농도 구간) |

세 경로가 공존하므로 **순 부호는 조건 의존**이고, 그래서 "단일 지수 n으로 MRR ∝ μⁿ"을 쓰는 것은
**부적절**하다. 그러나 "정량 관계가 없다"도 틀렸다.

**추가로, 모델 내부에는 명확한 단조 관계가 하나 있다**(P1 자체 결론):
> 점도를 올리면 τ_w(웨이퍼면 전단응력)와 h_min이 **둘 다 증가**한다 → 전단응력 기반 제거 모델에서는
> 연마율↑, 동시에 스크래치↓.

이는 (i)과 반대 부호로 보이지만 다른 모델 계보(전단응력 기반 침식 vs 접촉분율 기반 마모)에서
나온 것이다. **두 계보를 실험으로 판별한 문헌은 미확보.**

### 7.4 그래서 FabSim은 무엇을 해야 하나 (권고, 구현은 범위 밖)

1. **"문헌에 정량 관계 없음"이라는 사유 문구를 수정하라.** 정확한 사유는
   "관계는 존재하나 부호가 계 의존이고 보편 지수가 없다"이다. 현재 문구는 후속 작업자가
   재조사를 포기하게 만든다.
2. **점도를 MRR에 직접 곱하지 말고, 이미 있는 So/He 경로로 넣어라.** P2의
   "점도 10% ≡ 압력 10% ≡ 속도 10%"는 추가 상수 없이 쓸 수 있는 등가 진술이고,
   FabSim은 이미 `cmp_sommerfeld(mu, U, p, Ra)`를 계산하고 있다. 즉 **점도는 이미 So를 통해
   COF와 마찰발열에는 들어가 있고, MRR에만 안 들어가 있다** — 이 비대칭이 현재 구조의 실제 문제다.
3. **부호를 상수로 박지 마라.** 재료계별 팩 파라미터로 두되, 값이 없으면 계수 0(비활성)으로 두고
   "문헌상 부호 조건부"라고 표기하는 것이 정직하다.
4. **전단속도 검증 게이트를 넣어라.** 위 관계들은 모두 뉴턴 가정 위에 있다. 증점제가 들어간 계는
   P3가 보고했듯 전단박화로 바뀐다.

### 7.5 이 절의 파라미터 분류

| 항목 | 분류 |
|---|---|
| μ 자체 | **독립 측정 가능**(CMP 전단속도에서 측정 필요) |
| d(MRR)/d(He) 기울기 | **피팅 필요** — P2가 그래프만 제공, 회귀계수 **미확보** |
| "점도 10% ≡ 압력 10%" 등가율 | **문헌값 차용**(P2, 정성-정량 중간 진술) |
| Stokes 항력 계수 3π | **이론값**(유도 상수, 측정·피팅 불필요) |
| 개질제 농도→MRR 감소 기울기 | **미확보**(P3가 정규화 농도 축의 그래프만 제공) |
| 부호 자체 | **조건 의존 — 상수화 금지** |
