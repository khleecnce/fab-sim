## 0. 이 문서의 추상화 규약

특정 슬러리·산화제 제품·고객사 조건은 쓰지 않는다. 일반 변수로만 서술한다:

| 기호 | 의미 | 단위 |
|---|---|---|
| $C_{ox}$ | 산화제 농도 | mol L⁻¹ (또는 wt%) |
| $C_{inh}$ | 억제제 농도 | mol L⁻¹ |
| $C_{ch}$ | 킬레이터(착화제) 농도 | mol L⁻¹ |
| $\theta$ | 표면 피복률 | 무차원 (0–1) |
| $\mathrm{pH}$ | $-\log_{10} a_{H^+}$ | 무차원 |
| $I$ | 이온강도 $\tfrac12\sum c_i z_i^2$ | mol L⁻¹ |
| $E$ | 전극전위 (vs SHE) | V |
| $\eta$ | 과전압 $E - E_{eq}$ | V |
| $i$ | 전류밀도 | A cm⁻² |
| $L$ | 표면 산화막 두께 | m |
| $H$ | 표면 유효경도 | Pa |
| $K_{ads}$ | 흡착 평형상수 | L mol⁻¹ |
| $\Delta G_{ads}$ | 흡착 자유에너지 | J mol⁻¹ |

공통 상수: $R = 8.314462618$ J mol⁻¹ K⁻¹, $F = 96485.33$ C mol⁻¹, $T = 298.15$ K,
$\frac{RT}{F}\ln 10 = 59.1593$ mV (A3.3/A4.1 재현).

**자기검열 규칙**: 각 문장에 대해 "이 서술을 금속 A에서 금속 B로 바꿔도 성립하는가"를
물었다. 안 되면 그것을 낳은 일반 규칙으로 한 단계 올려 다시 썼다. 특정 재료계에서만
성립하는 관측은 §축별 "재료 의존" 항으로 격리했다.

## 1. 우선순위 요약 — χ에 무엇이 빠져 있는가

FabSim의 화학 반응성 팩터 χ(`sim/factors.py:_f_chi`)는 현재 세 항을 곱한다:
`oxidizer` × `ceria_tooth` × (`ph_peak` | `ph_ceria_window` | `ph_softening`).
표면 보호 ψ(`_f_psi`)가 억제제·분산제를 따로 가져간다.

과제 브리핑은 "χ에 pH 항 하나만 있고 산화제·억제제·킬레이터가 없다"고 했으나,
**실제 코드는 산화제 항과 억제제 항을 이미 갖고 있다**(산화제는 χ, 억제제는 ψ).
정확한 결측은 다음이다:

| 축 | 현 상태 | 결측의 성격 |
|---|---|---|
| 산화제 $C_{ox}$ | χ에 구현됨 (`_oxidizer_term`) | **모델 형태가 현상론**. 1차원리 유도 부재(§3) |
| 억제제 $C_{inh}$ | ψ에 구현됨 (`_inhibitor_term`) | **식별 불가능한 피팅 파라미터** $k_{inhib}$ 도입(§4, §9) |
| **킬레이터 $C_{ch}$** | **없음. 통로 자체가 없다** | `chelation_surface_charge.py`가 $K'(\mathrm{pH}, I)$를 계산하지만 팩터에 배선 안 됨 |
| pH | χ에 3분기 구현 | 재료계별 분기가 하드코딩 — 일반 규칙 미추출(§5) |
| Pourbaix/Nernst | 순수 함수만 존재 | 팩터에 미배선. 상 판정이 MRR에 영향 없음(§6) |
| Butler-Volmer/갈바닉 | **없음** | 표준전위 방향 판정만 있고 전류·속도 없음(§7) |
| 화학-기계 시너지 | 지수 3/2만 구현 | 화학 → $H_{eff}$ 사상이 축별로 분리 안 됨(§8) |

**따라서 우선순위는 킬레이터(통로 없음) > 갈바닉(통로 없음) > 산화제 형태 교정 >
억제제 식별성 개선이다.**

## 2. 축 1 — Langmuir 흡착 등온식

### 2.1 모델식

**단일 성분 (Langmuir 1918)**

$$\theta = \frac{K_{ads} C}{1 + K_{ads} C}, \qquad
\Delta G^\circ_{ads} = -RT \ln(55.5\, K_{ads})$$

55.5 mol L⁻¹은 물의 몰농도로, 수용액 흡착상수를 몰분율 기준으로 환산하는 관례 인자다.

**경쟁 흡착 (다성분 + 양성자 경쟁)**

$$\theta_i = \frac{K_i C_i}{1 + K_H a_{H^+} + \sum_j K_j C_j}, \qquad
\Theta = \sum_i \theta_i = \frac{\sum_i K_i C_i}{1 + K_H a_{H^+} + \sum_j K_j C_j}$$

**측면 상호작용 확장 (Frumkin)**

$$K_{ads} C = \frac{\theta}{1-\theta}\exp(-2 f \theta)$$

$f > 0$: 인력(협동적 흡착 — 흡착종이 표면에서 서로 결합해 사슬/중합막을 이루는 계),
$f < 0$: 반발(정전 반발이 지배하는 계).

| 기호 | 의미 | 단위 |
|---|---|---|
| $\theta, \Theta$ | 성분별/총 피복률 | 무차원 |
| $K_{ads}, K_i$ | 흡착 평형상수 | L mol⁻¹ |
| $K_H$ | 양성자 경쟁 상수 | L mol⁻¹ |
| $C, C_i$ | 용액상 농도 | mol L⁻¹ |
| $f$ | Frumkin 상호작용 파라미터 | 무차원 |
| $\sigma_0$ | 총 흡착점 밀도 | sites cm⁻² |

### 2.2 차원 검사

$K_{ads} C$: (L mol⁻¹)(mol L⁻¹) = 무차원 ✔ → $\theta$ 무차원 ✔
$RT \ln(55.5 K)$: (J mol⁻¹ K⁻¹)(K)·무차원 = J mol⁻¹ ✔ ($55.5K$가 무차원이 되려면
55.5의 단위가 mol L⁻¹이어야 하고 실제로 그렇다) ✔
경쟁형 분모: $K_H a_{H^+}$에서 $a_{H^+}$는 활동도(무차원)이므로 엄밀히는 $K_H$가
무차원이어야 한다. **FabSim `competitive_metal_langmuir.py`는 $K_H$를 L mol⁻¹로
문서화하고 $[H^+] = 10^{-\mathrm{pH}}$를 mol L⁻¹로 넘긴다** — 이 조합에서는 차원이 맞는다.
단 "활동도 vs 농도"를 혼용하므로 $I$가 커지면 오차가 된다(§2.4).

### 2.3 유도 가정과 각각이 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 흡착점이 모두 동등(균일 표면) | 결정면·결함·입계가 섞인 실제 다결정 표면. 단차/볼록부와 오목부의 반응성이 다른 패턴 웨이퍼 |
| 흡착종 간 측면 상호작용 없음 | 흡착종이 표면에서 중합·사슬을 이루는 계 → Frumkin($f>0$)로 교체해야 함 |
| 단분자층 (다층 없음) | 부동태막이 분자층 수 개로 자라는 계. 이때 $\theta$는 "면적 피복"이 아니라 "두께"의 대리변수로 오용됨 |
| 흡착/탈착 평형 도달 | CMP는 패드가 초당 수 회 표면을 긁는 **비평형** 계다. 재부동태 시간상수가 접촉 간격보다 길면 $\theta$가 정상상태에 못 간다 |
| 흡착이 전위와 무관 | 전기화학적 흡착은 $\theta(E)$다. 전위 축이 있는 계에서 $K_{ads}$는 사실 $K_{ads}(E)$ |
| 용액상 활동도 ≈ 농도 | $I \gtrsim 0.01$ mol L⁻¹. 활동도계수 보정(Davies) 필요 |

### 2.4 극한 거동

| 극한 | 모델 값 | 물리적 타당성 |
|---|---|---|
| $C \to 0$ | $\theta \to K_{ads}C$ (Henry 선형) | ✔ 타당 |
| $C = 1/K_{ads}$ | $\theta = 1/2$ | ✔ 검증(A1.2): $\Delta G_{ads} = -35.4$ kJ mol⁻¹ → $K = 2.868\times10^4$ L mol⁻¹ → $C_{1/2} = 34.9$ µM |
| $C \to \infty$ | $\theta \to 1$, $1-\theta \to 1/(K_{ads}C)$ | ✔ 수학적으로 타당하나 **모델 사용 관점에서 치명적**(§2.5) |
| 경쟁형, 성분 추가 | 기존 성분 피복 감소 | ✔ 검증(A1.9): 경쟁종 추가로 $\sigma_A$ $1.43\times10^{12} \to 9.68\times10^{11}$ sites cm⁻² |
| 경쟁형 총합 | $\Theta \le 1$ 항상 | ✔ 검증(A1.8): $\Theta = 0.6452$ |

### 2.5 ⚠ 포화 함정 — $\theta$가 1에 붙으면 농도 구분이 사라진다

이것이 이 축의 **가장 중요한 실무 결론**이고, FabSim이 실제로 밟은 함정이다
(`sim/chemistry.py:_inhibitor_term` docstring이 2026-09-06 사고로 기록).

검증된 수치(A1.1–A1.5, $K = 2.868\times10^4$ L mol⁻¹):

| $C$ | $\theta$ | $1-\theta$ |
|---|---|---|
| 0.01 mM | 0.2229 | 0.777 |
| 0.1 mM | 0.7414 | 0.259 |
| 1 mM | 0.9663 | 0.0337 |
| 2 mM | 0.9829 | 0.0171 |
| 5 mM | 0.9931 | 0.0069 |

고농도 점근: $\dfrac{d \ln(1-\theta)}{d \ln C} \to -1$ (A1.3 측정값 $-0.9755$).

**함정의 구조는 두 단계다.**

1. **$\theta$ 자체로는 분해능이 없다.** 1 mM → 5 mM (5배)에 $\theta$는 0.966 → 0.993
   (2.8% 변화). $\theta$를 그대로 MRR 인자로 쓰면 고농도 구간이 평평해진다.
2. **$(1-\theta)$는 분해능이 있지만 하한 클램프가 그것을 죽인다.** $(1-\theta)$ 비는
   농도 2배에 0.509 (A1.4) — 즉 $C^{-1}$로 제대로 감소한다. 문제는 구현이
   $\max(1-\theta, 0.05)$ 같은 하한을 두면 $\theta > 0.95$인 전 구간이 한 값으로
   뭉개진다는 점이다.

FabSim의 현 대응은 잔여율을 $\exp(-k_{inhib}\theta)$로 바꾼 것인데, **이것은 함정을
해결하지 않는다**: 같은 1→2 mM 구간에서 응답이 0.9515 (A1.5), 즉 **5% 미만으로
사실상 평평하다**. $(1-\theta)$ 선형형(0.509)보다 오히려 분해능이 나쁘다.

> **일반 규칙**: 피복률 기반 항의 유용한 동적 범위는 $C \lesssim 1/K_{ads}$ 뿐이다.
> $K_{ads} C \gg 1$에서 농도를 비교해야 한다면 $\theta$가 아닌 다른 상태변수
> (막 두께, 막 치밀도, 재생 시간상수)를 모델에 세워야 한다. $\theta$를 비틀어
> 분해능을 만들어내는 것은 물리가 아니라 피팅이다.

Frumkin 확장은 이 문제를 **악화**시킨다: $f>0$이면 포화가 더 급격해져
$\theta: 0.4 \to 0.6$ 농도폭이 2.25배 → 1.235배로 좁아진다(A1.6/A1.7).

| $K_H$ | **문헌값 차용** | 원논문이 "probably ~$10^3$"라고 쓴 오더값 |

### 2.8 식별 불가능성 위험

$K_{ads}$와 $k_{inhib}$는 **MRR 스캔만으로는 식별 불가능하다.**
검증(A7.1): 4점 농도 스캔(0.5/1/2/5 mM)에서 로그 RMS 오차 1% 이내의 동등해가 **994개**,
$K_{ads}$ $4.02\times10^3$–$1.43\times10^5$ L mol⁻¹ (35배 범위), $k_{inhib}$ 0.61–12.0 (20배 범위),
$\mathrm{corr}(\log_{10} K_{ads}, k_{inhib}) = +0.929$.

즉 **강한 흡착 + 약한 억제**와 **약한 흡착 + 강한 억제**가 MRR 데이터에서 구별되지
않는다. $K_{ads}$를 독립 측정(등온선)으로 고정하지 않으면 $k_{inhib}$ 피팅은 의미가 없다.

### 2.9 FabSim 현 구현과의 차이

- `slurry_components.langmuir_coverage`: 단일 Langmuir 정확히 구현 ✔
- `competitive_metal_langmuir.competitive_langmuir_surface`: 경쟁형 구현 ✔ 단
  **팩터에 배선 안 됨** (모듈 docstring이 "Recipe에 pH·이온농도 필드 부재"로 사유 기록)
- Frumkin: **미구현**. 협동 흡착이 있는 계를 Langmuir로 다루면 포화 급격성을 과소평가
- `_inhibitor_term`의 $\exp(-k_{inhib}\theta)$: **문헌 근거 없는 형태**. 코드 주석이
  스스로 "문헌값이 없으므로 confidence=unverified"로 표기 ✔ (정직성은 확보)
- 활동도 보정: 미구현. $I$를 받는 통로가 없다

## 3. 축 2 — 산화제 농도 → 표면 산화막 형성 속도

### 3.1 FabSim 현 구현 (현상론)

$$\mathrm{MRR}_{ox}(C) = \mathrm{MRR}_{peak}\cdot
\frac{(n+1)\,x}{1 + n\, x^{(n+1)/n}}, \qquad x = \frac{C_{ox}}{C_{peak}}$$

지수 $(n+1)/n$은 $x=1$에서 $d\mathrm{MRR}/dx = 0$이 되도록 역설계된 값이다.

| 기호 | 의미 | 단위 |
|---|---|---|
| $C_{peak}$ | 정점 농도 | mol L⁻¹ (구현은 wt%) |
| $n$ | 정점 후 감쇠 형상 | 무차원 |
| $\phi_{floor}$ | 기계적 바닥값 | 무차원 (0–1) |

기계적 바닥값 결합(구현됨): $\mathrm{MRR} \leftarrow \phi_{floor} + (1-\phi_{floor})\cdot\mathrm{MRR}$.

### 3.2 차원 검사

$x$ 무차원 ✔. $x^{(n+1)/n}$ 무차원 ✔. 전체가 $\mathrm{MRR}_{peak}$ 단위 ✔.
**단 이 식은 차원적으로 자명하다** — 정규화형이라 물리 상수가 하나도 없다.
이것이 곧 이 축의 문제다: 차원 검사를 통과해도 물리를 담보하지 않는다.

### 3.3 단봉형의 물리적 이유 — 1차원리 유도 시도와 그 결과

브리핑이 요구한 "단봉형의 물리적 이유"를 실제로 유도해봤고, **교과서적 설명이
불충분하다는 것을 발견했다.**

**흔한 설명**: "산화제가 늘면 무른 막이 빨리 생겨 MRR↑, 과하면 부동태막이 두꺼워져
보호하므로 MRR↓." 이것을 식으로 세우면:

정상상태 막두께: 형성 = 제거, 형성 속도 $\propto C_{ox}$ (1차), 기계 제거효율이 막
두께에 지수 감쇠 $\exp(-L/L_c)$ (입자 압입이 두꺼운 막을 관통 못 함), $L \propto C_{ox}$:

$$\mathrm{MRR} \propto \theta_{ox}(C)\cdot\exp(-L/L_c), \qquad
\theta_{ox} = \frac{K_{ox}C}{1+K_{ox}C}$$

이 형태도 내부 정점을 낸다(A2.5, argmax $C = 0.101$). **즉 "단봉이 나온다"는 사실
자체는 여러 서로 다른 메커니즘과 양립하므로 모델 선택의 근거가 못 된다.** 단봉을
재현했다고 물리를 맞힌 것이 아니다.

**하강 가지의 지수가 메커니즘을 가른다.** 화학-기계 시너지(§8)와 결합한 형태:

$$\mathrm{MRR} \propto \theta_{ox}(C)\cdot H_{eff}(L)^{-3/2}, \qquad
H_{eff} = H_f(L) + \big(H_{metal} - H_f(L)\big)e^{-L/L_c}, \quad
H_f(L) = H_{f0}\Big(1 + \frac{L}{L_d}\Big)$$

물리적 읽기: 막이 얇으면 경질 하지 금속이 유효경도를 지배하고(저 MRR), 막이 두꺼워
지면 무른 막이 표면을 덮어 MRR이 오르지만, 막 자체가 더 두꺼워지며 치밀화
($H_f$↑)해 다시 MRR이 떨어진다. 검증(A2.6–A2.8):

- 내부 정점 존재: argmax $C = 0.9885$ ✔
- 하강 가지 **점근 기울기 $= -3/2$** (측정값 $-1.4999$). $H_{eff} \propto C$이므로
  $H^{-3/2}$ 지수가 그대로 드러난다
- 양끝 극한 $\mathrm{MRR}\to 0$ ✔

> **일반 규칙**: 단봉형 산화제 응답의 **하강 가지 로그기울기가 $-3/2$에 가까우면**
> 메커니즘이 "막 치밀화 → 유효경도 상승"이고, $-1/n$ 같은 임의 지수면 그것은
> 피팅 상수일 뿐이다. FabSim 현 구현은 후자다(A2.3: $n=2$에서 측정 기울기 $-0.4934
> = -1/n$). **즉 현 구현의 하강 가지는 물리가 아니라 형상 파라미터다.**

### 3.4 $C_{ox}=0$에서의 기계적 바닥값

현 구현은 $C \to 0$에서 정확히 0을 준다(A2.1: $3\times10^{-12}$). 이것은
**산화제가 없어도 순수 기계 연마로 제거가 남는 계를 표현할 수 없다**는 뜻이다.
`_oxidizer_term`이 `oxidizer_mech_floor`로 이를 보정하며, 결합 후 $C=0$ 값이 정확히
$\phi_{floor}$가 됨을 확인했다(A2.4).

> **일반 규칙**: 화학 항을 곱셈으로 넣으면 화학이 0일 때 MRR이 0이 된다. 기계 경로가
> 독립적으로 살아 있는 계에서는 화학 항을 **덧셈 분해**($\phi_{floor} + (1-\phi_{floor})f$)
> 해야 하고, 이때 $\phi_{floor}$는 "산화제 0 조건의 실측 MRR / 기준 조건 MRR"로
> **독립 측정 가능한 양**이다. 피팅 파라미터가 아니다.

### 3.5 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 막 형성이 $C_{ox}$에 1차 | 산화제 분해가 촉매(전자 셔틀)로 매개되는 계 — 율속이 촉매 농도로 넘어가 $C_{ox}$ 의존성이 포화 |
| 정상상태 막두께 존재 | 재부동태 시간상수 > 패드 접촉 간격. 이때 막은 정상상태에 못 가고 이력(hysteresis)을 갖는다 |
| 막 두께가 $C_{ox}$에 선형 | 확산 제한 성장($L \propto \sqrt{t}$)이나 자기제한 성장(로그형)인 계 |
| 정점이 하나 | 산화제가 두 개 이상의 산화 경로(저차/고차 산화물)를 열면 다봉이 가능 |
| 산화제와 pH가 독립 | 산화제의 산화력 자체가 $E^\circ - $ (Nernst pH 항)이므로 **본질적으로 결합돼 있다**(§6). FabSim은 두 항을 독립으로 곱한다 — 미모델링 |

- 형태가 현상론이며 코드가 이를 정직히 표기 ✔
- **하강 가지가 물리적 지수를 갖지 않는다**(§3.3). $H_{eff}$ 경로로 재유도하면
  하강 기울기가 $-3/2$로 고정돼 피팅 파라미터 $n$이 제거된다 — 개선 제안

- 기준 조건 폴백 경고가 구현돼 있음 ✔ (`oxidizer_ref_wt_pct` 부재 시 notes에 경고)

## 4. 축 3 — 억제제 → 표면 보호

### 4.1 모델식

**정통형 (피복 면적 가중)**

$$\mathrm{MRR} = \mathrm{MRR}_0 \cdot (1 - \theta_{inh}), \qquad
\theta_{inh} = \frac{K_{inh}C_{inh}}{1+K_{inh}C_{inh}}$$

억제 효율 $\mathrm{IE} = \theta$ (피복률이 그대로 부식전류 억제율로 근사).
전기화학적으로는 $\mathrm{IE} = 1 - i_{corr}/i_{corr,0}$이며 §7의 Stern-Geary로
$R_p$ 측정에서 독립 산출 가능하다.

**FabSim 현 구현 (지수 감쇠)**

$$\mathrm{MRR} = \mathrm{MRR}_0 \cdot \exp(-k_{inhib}\,\theta_{inh})$$

### 4.2 차원 검사

$(1-\theta)$ 무차원 ✔. $k_{inhib}\theta$ 무차원(∴ $k_{inhib}$ 무차원) ✔.
단 $k_{inhib}$는 **차원 분석으로 그 존재가 정당화되지 않는다** — 무차원 상수를
지수에 넣는 것은 언제나 가능하므로, 차원 검사가 이 형태를 검증하지 못한다.

### 4.3 단조 vs 포화 — 핵심 쟁점

| 형태 | $C\to 0$ | $C\to\infty$ | 1→2 mM 응답 |
|---|---|---|---|
| $(1-\theta)$ | → 1 ✔ | → 0 (as $1/K C$) | 0.509 (A1.4) |
| $\exp(-k\theta)$ | → 1 ✔ | → $e^{-k} > 0$ | 0.9515 (A1.5) |

두 형태 모두 **$C$에 대해 단조 감소**다. 차이는 (a) 고농도 극한값($0$ vs $e^{-k}$)과
(b) 고농도 분해능이다.

- $(1-\theta) \to 0$: "피복이 완성되면 제거가 완전히 멈춘다" — 정적 식각에는 맞지만
  **기계 제거가 있는 CMP에서는 틀렸다.** 패드가 막을 벗기므로 제거는 0이 되지 않는다.
- $\exp(-k\theta) \to e^{-k} > 0$: 바닥값이 있어 **CMP 문맥에 더 맞다.** 그러나
  $k$의 값이 문헌에 없고, 고농도 분해능이 오히려 나쁘다(§2.5).

> **일반 규칙**: 억제제가 만드는 MRR 저하의 상한은 "피복률"이 아니라 **막 재생 속도와
> 패드 접촉 빈도의 비**가 정한다. $\theta$만으로 모델을 세우면 그 경쟁이 빠진다.
> 올바른 상태변수는 $\theta$와 재생 시간상수 $\tau_{re}$의 쌍이고, 저농도 극한에서만
> $\theta$ 단독으로 축약된다.

바닥값 있는 단조 감소를 원한다면 $\exp(-k\theta)$ 대신
$\mathrm{MRR}/\mathrm{MRR}_0 = \phi_{floor} + (1-\phi_{floor})(1-\theta)$
가 낫다 — $\phi_{floor}$가 **독립 측정 가능**(고농도 포화 MRR / 무억제 MRR)해서
피팅 파라미터를 늘리지 않는다. §3.4의 산화제 바닥값과 정확히 같은 구조다.

### 4.4 유도 가정과 깨지는 조건

§2.3의 Langmuir 가정 전부를 상속한다. 추가로:

| 가정 | 깨지는 조건 |
|---|---|
| 피복된 면적은 제거 0, 나머지는 완전 제거 (이진) | 막이 얇아 입자가 관통하는 경우. 막 두께가 압입 깊이와 비교 가능하면 이진 근사가 깨진다 |
| $\mathrm{IE} = \theta$ | 막의 치밀도·유전율이 농도로 변하는 계. 같은 $\theta$에서 $\mathrm{IE}$가 다르다 |
| 억제제가 다른 축과 독립 | pH가 억제제 양성자화·배위를 바꿔 $K_{inh}(\mathrm{pH})$. 산화제가 막을 산화시켜 억제막을 파괴 — **FabSim은 χ와 ψ를 독립으로 곱한다(미모델링)** |
| 볼록부/오목부 동일 피복 | 평탄화의 본질은 볼록부만 마모되는 것이다. 억제제의 실제 가치는 **오목부 선택적 보호**인데, 면적 평균 $\theta$는 이 공간 구분을 담지 못한다 |

마지막 행이 중요하다: **$\theta$ 기반 스칼라 항은 평탄화(dishing/erosion)를 원리적으로
설명할 수 없다.** MRR 배수만 바꿀 뿐이다. 평탄화를 다루려면 볼록부의 $\theta_{up}$과
오목부의 $\theta_{down}$을 구분해야 하고, 그 차이는 $\theta$가 아니라
"기계적 막 제거율 vs 재생률"에서 나온다.

### 4.7 FabSim 현 구현과의 차이

- ψ 팩터가 억제제를 담당하며, 기준 조건 대비 상대비만 반환 ✔ (이중 계상 방지)

  실제로는 해결하지 못했다. 이 문서가 처음 정량 확인한 사항
- 킬레이터($C_{ch}$)가 억제제와 **반대 방향**으로 작용하는데 통로가 없다(§10)

## 5. 축 4 — pH → 표면 전하·용해도·경도

### 5.1 모델식

**표면 전하 (자리 해리)**

$$\equiv\!\mathrm{M{-}OH}_2^{+} \rightleftharpoons \equiv\!\mathrm{M{-}OH} + H^+
\rightleftharpoons \equiv\!\mathrm{M{-}O}^{-} + 2H^+$$

$$\mathrm{sign}(\zeta) = \mathrm{sign}(\mathrm{IEP} - \mathrm{pH}), \qquad
\left|\frac{d\psi_0}{d\mathrm{pH}}\right| \le \frac{RT}{F}\ln 10 = 59.16\ \mathrm{mV/pH}$$

**정전 인력창 (두 IEP 모델)**

입자 IEP $= \mathrm{IEP}_p$, 피연마막 IEP $= \mathrm{IEP}_w$일 때 정전 인력 조건:

$$\mathrm{sign}(\mathrm{IEP}_p - \mathrm{pH})\cdot\mathrm{sign}(\mathrm{IEP}_w - \mathrm{pH}) < 0
\iff \min(\mathrm{IEP}_p,\mathrm{IEP}_w) < \mathrm{pH} < \max(\mathrm{IEP}_p,\mathrm{IEP}_w)$$

**이온강도 → 전기이중층**

$$\kappa^{-1} \approx \frac{0.304}{\sqrt{I}}\ \mathrm{nm}\ (1{:}1, \text{물}, 25^\circ\mathrm{C}),
\qquad \mathrm{CCC} \propto z^{-6}\ (\text{Schulze–Hardy})$$

| 기호 | 의미 | 단위 |
|---|---|---|
| $\zeta$ | 제타전위 | V |
| $\psi_0$ | 표면 전위 | V |
| IEP | 등전점 | pH 단위 |
| $\kappa^{-1}$ | Debye 길이 | m |
| $z$ | 반대이온 원자가 | 무차원 |

### 5.2 차원 검사

$\frac{RT}{F}\ln10$: (J mol⁻¹)/(C mol⁻¹) = J/C = V ✔ → mV/pH ✔ (A3.3: 59.1593 mV/pH).
$0.304/\sqrt{I}$: 경험식이므로 차원 은닉 — $I$를 mol L⁻¹로 넣을 때만 nm가 나온다.
$z^{-6}$ 무차원 ✔.

### 5.3 정점형 거동이 나오는 조건 — IEP의 역할

**이것이 이 축의 핵심 일반 규칙이다.**

검증(A3.1/A3.2): 두 IEP가 각각 2.5, 6.8일 때 인력창 = pH 2.6–6.8.
**두 IEP가 같으면 인력창이 완전히 소멸한다**(A3.2).

> **일반 규칙**: pH-MRR이 정점형(또는 플래토+양측 급락)이 되는 **필요조건은
> 입자 IEP $\neq$ 피연마막 IEP**다. 두 IEP가 겹치는 계에서는 정전 경로가 정점을
> 만들 수 없고, 정점이 관측된다면 원인은 다른 경로(용해도, 가수분해 연화, 흡착)다.

정점형이 나오는 세 가지 서로 다른 메커니즘이 있고, **혼동하면 부호까지 틀린다**:

| 메커니즘 | 정점 위치 | 양측 하강의 원인 |
|---|---|---|
| (a) 정전 인력창 | 두 IEP 사이 | 창 밖에서 동부호 반발 → 접촉 빈도 감소 |
| (b) 가수분해 연화 vs 반발 경쟁 | 연화가 반발에 지는 지점 | 저 pH: 연화 부족 / 고 pH: 입자·표면 동시 강전하 반발 |
| (c) 양쪽성 용해도 (U자의 역) | 용해도 최소(≈PZC) 근처 | 양극단 pH에서 등방 용해 → 평탄화 실패(MRR은 오르나 선택성 붕괴) |

FabSim은 (a)와 (b)를 각각 구현하고 연마재 종류로 분기한다. **분기 자체는 옳다**
(코드 주석이 2026-09-08에 한쪽 항을 다른 재료계에 상속시켜 상관계수 $\rho=-0.525$가
나온 사고를 기록) — 그러나 분기 기준이 연마재 문자열 하드코딩이라 **일반 규칙
(두 IEP의 상대 위치)으로 추상화되어 있지 않다.**

### 5.4 pH → 경도 경로 (가장 약한 고리)

FabSim `_ph_softening_term`: $H/H_0 = 1 - k_{pH}(\mathrm{pH} - \mathrm{pH}_{ref})$,
하한 0.2 클램프, 이후 $(H/H_0)^{-3/2}$.

- **선형 가정에 문헌 근거 없음** — 코드가 "⚠ 선형 가정, 미검증"으로 표기 ✔
- 극한 거동: $\mathrm{pH} \to$ 큰 값에서 $H/H_0 \to 0$ → MRR 발산.
  0.2 클램프가 이를 막지만 **클램프는 물리가 아니다.** 클램프에 닿으면 그 이상의
  pH는 전부 같은 값이 되어 §2.5와 같은 분해능 소멸이 발생
- 단조 가정이 (b) 메커니즘과 **모순**된다. 코드가 정점형 항으로 교체한 것은 옳은 판단 ✔

### 5.5 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| IEP = PZC | 특이흡착이 있으면 분리된다. 다가 금속이온·고분자 흡착이 IEP를 이동시킨다 |
| IEP가 고정 상수 | 용존 이온이 표면을 코팅하면 IEP가 코팅상의 IEP로 끌려간다 — **오염이 $\zeta$-pH 곡선 자체를 바꾼다** |
| $\zeta$가 Nernst 기울기 | 실제 산화물은 아-Nernst. $-59$ mV/pH는 **상한**이고 절대 기울기는 재료·$I$ 의존 |
| 정전 인력이 접촉을 지배 | 입자 농도가 높으면 반발이 있어도 기계 접촉이 유지된다 — 저장소 노트가 두 문헌의 상충(저농도 정전 창 지배 vs 고농도 무관)을 기록 ✔ |

| 벌크 분말 IEP = 박막 IEP | CMP 후 실제 박막의 IEP는 다를 수 있다 — `chelation_surface_charge.py`가 이를 한계로 표기 ✔ |

### 5.6 극한 거동

| 극한 | 거동 | 타당성 |
|---|---|---|
| pH 양끝 (정전 창 모델) | 창 밖 잔류값으로 수렴 | ✔ 단 **산성 측과 염기 측 잔류값이 달라야 한다** — 물리가 다르기 때문(산성: 양쪽 거의 무전하 / 염기: 강반발이나 화학결합 경로 생존). FabSim이 두 값을 분리 구현 ✔ |

### 5.9 식별 불가능성

정점 곡률을 좌/우 비대칭으로 따로 두면($a_{lo}, a_{hi}$) 3점 데이터에 3파라미터
($\mathrm{pH}_{peak}, a_{lo}, a_{hi}$)를 맞추는 것이 되어 **자유도가 0**이다 —
적합은 완벽하지만 예측력 검증이 불가능하다. 정전 창 모델도 4파라미터
(잔류율 2개 + 기울기 2개)를 단일 데이터셋에서 역산하므로 같은 위험이 있다.
저장소가 "격자탐색 log-err 5.3 vs 0.02"로 단일 잔류값이 안 됨을 기록한 것은
**데이터가 파라미터를 요구했다는 증거**이므로 정당하나, 외부 검증셋이 필요하다.

### 5.10 FabSim 현 구현과의 차이

- 재료계별 3분기 구현, 상속 사고 이력 기록 ✔
- 분기 기준이 하드코딩 — 일반 규칙(두 IEP 상대 위치)으로 미추출
- 이온강도 $I$ 통로 없음. `chelation_surface_charge.logK_at_I`가 Davies 보정을
  구현했으나 팩터에 미배선
- 알려진 반례를 코드 주석에 명시 ✔ (한쪽을 맞추면 다른 쪽이 깨지는 진짜 상충)

## 6. 축 5 — Pourbaix 도표와 Nernst 식

### 6.1 모델식

반응 $a\,\mathrm{Ox} + m\,H^+ + n\,e^- \rightleftharpoons b\,\mathrm{Red} + \cdots$에 대해

$$E = E^\circ - \frac{RT\ln 10}{nF}\log_{10}\frac{a_{Red}^b}{a_{Ox}^a}
- \frac{RT\ln 10}{F}\cdot\frac{m}{n}\,\mathrm{pH}$$

경계선 기울기:

$$\frac{dE}{d\mathrm{pH}} = -\frac{RT\ln10}{F}\cdot\frac{m}{n}
= -59.16\cdot\frac{m}{n}\ \ \mathrm{mV/pH}$$

**영역 판정** (3 영역):

| 영역 | 안정상 | CMP 의미 |
|---|---|---|
| 면역(immunity) | 금속 | 화학 제거 없음 → 순수 기계 |
| 부식(corrosion) | 용존 이온 | 정적 식각 → 등방 용해, 평탄화 실패 |
| 부동태(passivation) | 산화물/수산화물 | **CMP가 원하는 영역** — 무른 막 형성 후 기계 제거 |

### 6.2 차원 검사 (전부 A4 검증)

| 검사 | 결과 |
|---|---|
| $\frac{RT\ln10}{F}$ = V | ✔ 59.1593 mV |
| $m=n \Rightarrow -59.16$ mV/pH | ✔ (A4.1) |
| $m=2n \Rightarrow$ 기울기 2배 | ✔ $-118.32$ mV/pH (A4.2) |
| $m/n$ 비만 중요 (반응식 배율 불변) | ✔ $(6,6)$과 $(1,1)$ 동일 (A4.3) |
| $n=0$ (산-염기, 전자 없음) → 기울기 미정의 | ✔ ValueError (A4.4) — 수직선이며 pH만의 함수 |
| 활동도 1 decade 이동, $n=2$ → 경계 29.58 mV 이동 | ✔ (A4.5) |

### 6.3 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| **열역학 평형** | CMP는 기계적으로 막을 계속 벗기는 **정상상태 비평형**계다. Pourbaix는 "어느 상이 안정한가"만 말하고 **얼마나 빨리 가는가는 말하지 않는다** — 속도는 §7의 몫 |
| 착화제 없음 | 착화제가 있으면 용존종의 활동도가 낮아져 **부식 영역이 넓어진다**. 이것이 킬레이터의 작동 원리이고, FabSim에 통로가 없는 축이다(§10) |
| 활동도 = 농도 | $I \gtrsim 0.01$. 경계 위치가 $I$에 약하게 의존 |
| 고려한 상이 전부 | DB에 없는 상(준안정상·혼합 산화물·수화물)은 도표에 안 나온다. `cu_pourbaix.py`가 한 상의 표준 반쪽반응 부재로 대용상을 쓰고 **"대용, 미검증"이라 표기** ✔ |
| 단일 금속 | 이종금속이 접촉하면 각자의 Pourbaix가 아니라 **혼합전위**가 실제 전위다(§7) |
| 온도 25 °C | 마찰 발열로 계면 온도가 올라간다. $E^\circ$, $\ln10\,RT/F$, $K_w$ 전부 온도 의존 |

### 6.4 극한 거동

- pH → 매우 낮음: 대부분 계에서 용존 이온 영역(부식). MRR은 높으나 등방 → 평탄화 실패 ✔ 타당
- pH → 매우 높음: 양쪽성 금속은 옥소음이온으로 재용해(부식 재진입). **단조 부동태가
  아니다** ✔ 타당
- $E$ → 매우 낮음: 면역(금속). 물의 수소 발생선 아래는 **물이 분해되므로 물리적으로
  도달 불가** — 도표의 안정성 창을 벗어난다. FabSim `stable_phase`는 이 창 검사를
  하지 않는다(제한 사항)
- $E$ → 매우 높음: 산소 발생선 위, 동일 이유로 도달 불가
- 활동도 → 0: 경계가 $\log a$에 선형으로 이동, 발산 없음 ✔

- `pourbaix_nernst_slope.py`: 기울기 공식 정확 구현, 자기시험 통과 ✔
- `cu_pourbaix.py`: 6개 표준전위에서 경계선 유도, 문헌 도표 판독값과 ±0.03 V /
  ±0.15 pH 일치 ✔ 우수
- **팩터에 미배선.** 상 판정 결과가 MRR에 아무 영향을 주지 않는다. 부동태/부식/면역
  판정은 계산되지만 사용되지 않는다 → **가장 아까운 결측**
- 물 안정성 창(수소·산소 발생선) 검사 없음
- 착화제에 의한 부식 영역 확장 미모델링

## 7. 축 6 — Butler-Volmer / 갈바닉 부식

### 7.1 모델식

**Butler-Volmer (단일 반응)**

$$i = i_0\left[\exp\!\Big(\frac{\alpha n F \eta}{RT}\Big)
- \exp\!\Big(\frac{-(1-\alpha) n F \eta}{RT}\Big)\right], \qquad \eta = E - E_{eq}$$

**저과전압 극한 (선형, 분극저항)**

$$i \approx \frac{i_0 n F}{RT}\eta \quad\Longrightarrow\quad
R_p = \left(\frac{\partial \eta}{\partial i}\right)_{\eta\to0} = \frac{RT}{n F i_0}$$

**고과전압 극한 (Tafel)**

$$\eta = a + b\log_{10}|i|, \qquad b_a = \frac{RT\ln10}{\alpha n F},\quad
b_c = \frac{RT\ln10}{(1-\alpha)nF}$$

**혼합전위 이론 (Wagner–Traud 1938) — 갈바닉 쌍**

양극 금속(면적 $A_a$, 평형전위 $E_a$)과 음극 금속(면적 $A_c$, $E_c$)이 전기적으로
접촉하면 계 전체가 단일 혼합전위 $E_{mix}$로 간다:

$$A_a\, i_a(E_{mix}) + A_c\, i_c(E_{mix}) = 0$$

**Stern–Geary (부식속도 ← 분극저항)**

$$i_{corr} = \frac{B}{R_p}, \qquad B = \frac{b_a b_c}{\ln10\,(b_a+b_c)}$$

**Faraday 환산 (전류 → 제거율)**

$$v = \frac{i\,M}{n F \rho}$$

| 기호 | 의미 | 단위 |
|---|---|---|
| $i_0$ | 교환전류밀도 | A cm⁻² |
| $\alpha$ | 전하이동계수 | 무차원 (0–1) |
| $R_p$ | 분극저항 | Ω cm² |
| $b_a, b_c$ | 양극/음극 Tafel 기울기 | V decade⁻¹ |
| $B$ | Stern-Geary 상수 | V |
| $M$ | 몰질량 | g mol⁻¹ |
| $\rho$ | 밀도 | g cm⁻³ |
| $v$ | 두께 제거율 | cm s⁻¹ |

### 7.2 차원 검사 (전부 A5 검증)

| 검사 | 결과 |
|---|---|
| $\frac{\alpha n F\eta}{RT}$ 무차원 | ✔ (C mol⁻¹·V)/(J mol⁻¹) = 1 |
| 저과전압 선형 근사 | ✔ $\eta=1$ mV에서 상대오차 $6.3\times10^{-5}$ (A5.1) |
| $\eta=50$ mV에서 선형 근사 붕괴 | ✔ 상대오차 **16.5%** (A5.2) |
| $b = RT\ln10/(\alpha F)$, $\alpha=0.5$ | ✔ **118.32** mV decade⁻¹ (A5.4) |
| $B$ (대칭, $b=118$ mV) | ✔ **25.62** mV (A5.5) |
| Faraday: A cm⁻²·g mol⁻¹ / (C mol⁻¹·g cm⁻³) = cm s⁻¹ | ✔ 1 mA cm⁻², $M=60$, $n=2$, $\rho=9$ → **20.73 nm/min** (A5.9) |

### 7.3 ⚠ 검증이 뒤집은 두 가지 통념

**(1) "선형 영역에서 $\alpha$는 안 보인다"는 1차 근사에서만 참이다.**
1차항에서는 $\alpha$가 정확히 소거되지만, 2차항이 비율

$$\frac{\Delta i(\alpha)}{i} \simeq 2\,\big|2\alpha-1\big|\frac{F\eta}{2RT}$$

로 남아 **$\eta$에 선형으로 커진다.** 검증(A5.3), $\alpha=0.2$ vs $0.8$:

| $\eta$ | 수치 | 해석식 |
|---|---|---|
| 0.1 mV | 0.234% | 0.234% |
| 1 mV | 2.335% | 2.335% |
| 10 mV | 23.406% | 23.353% |

수치와 해석식이 1% 이내로 일치한다. **$R_p$ 측정에서 $\alpha$를 무시하는 것은
$|\eta| \lesssim 0.1$ mV에서만 1% 수준으로 안전하고, 통상 LPR에 쓰는 ±10 mV에서는
$\alpha$ 미지가 20%대 오차를 만든다.**

**(2) "면적비 법칙 $i_a \propto A_c/A_a$"는 음극이 분극되지 않을 때만 선형이다.**
두 반응이 모두 Tafel 거동이면 $E_{mix}$가 함께 이동해 지수가 깎인다:

$$i_a \propto \left(\frac{A_c}{A_a}\right)^{\,b_c/(b_a+b_c)}$$

검증(A5.7): 대칭 Tafel($\alpha=0.5$, $b_a=b_c$)에서 측정 지수 **0.4994 = 1/2**.
즉 면적비 10배에 양극 전류밀도는 **$\sqrt{10} \approx 3.2$배**뿐이고 10배가 아니다.
동시에 $E_{mix}$가 면적비 1 decade당 **59.08 mV** 이동한다(A5.7b).

> **일반 규칙**: 갈바닉 가속 배수를 면적비로 선형 추정하면 과대평가한다. 정확한
> 지수는 두 Tafel 기울기의 비 $b_c/(b_a+b_c)$이고, 이는 $\alpha$가 두 반응에서 다를
> 때 1/2에서 벗어난다. 면적비 효과를 쓰려면 두 Tafel 기울기를 측정해야 한다.

### 7.4 극한 거동

| 극한 | 거동 | 타당성 |
|---|---|---|
| $\eta \to 0$ | $i \to 0$ 선형 | ✔ |

### 7.8 식별 불가능성

- $(i_0, \alpha)$: Tafel 플롯의 절편과 기울기에 각각 분리 대응되어 **잘 식별된다.**
- $(i_{corr}, B)$: $R_p$ 측정 하나만으로는 **분리 불가능**. $B$를 26 mV로 가정하는
  관행이 여기서 나오며, 이는 $b_a \approx b_c \approx 118$ mV 가정과 동치다.
  $b$가 실제로 다르면 $i_{corr}$에 그만큼 오차가 실린다.
- **$\alpha$와 면적비 지수**: §7.3(2)에서 보인 대로 면적비 응답 지수가
  $b_c/(b_a+b_c)$이므로, 면적비 스캔 데이터만으로는 $\alpha$와 면적비를 분리하기
  어렵다. 면적비를 **설계에서 정확히 아는** 것이 이 상관을 끊는 열쇠다.

## 8. 축 7 — 화학-기계 시너지

### 8.1 모델식

**단일 입자 소성 압입 (구형 압자, $\delta \ll R$)**

$$F = H\pi a_p^2 \Rightarrow a_p = \sqrt{\frac{F}{\pi H}}, \qquad
\delta_p = \frac{a_p^2}{2R} = \frac{F}{2\pi R H} \propto H^{-1}$$

**Plowing 홈 단면적 → 제거 체적**

$$A_f = \frac{4}{3}\sqrt{2R}\ \delta_p^{3/2} \propto H^{-3/2}$$

**화학 → 기계 결합 (FabSim의 계약)**

$$\boxed{\ \frac{\mathrm{MRR}}{\mathrm{MRR}_0} =
\left(\frac{H_0}{H_{eff}}\right)^{3/2}\ }$$

화학 조건(모든 축)이 하는 일은 $H_{eff}/H_0$ 하나를 정하는 것으로 환원된다.

| 기호 | 의미 | 단위 |
|---|---|---|
| $F$ | 입자당 하중 | N |
| $R$ | 입자 반경 | m |
| $H$ | 표면 유효경도 | Pa |
| $a_p$ | 소성 접촉 반경 | m |
| $\delta_p$ | 소성 압입 깊이 | m |
| $A_f$ | 홈 단면적 | m² |

### 8.2 차원 검사

$F/(\pi H)$: N/Pa = N/(N m⁻²) = m² → $a_p$ m ✔
$\delta_p = F/(2\pi R H)$: N/(m·Pa) = N·m²/(m·N) = m ✔
$A_f = \sqrt{2R}\,\delta_p^{3/2}$: m^(1/2)·m^(3/2) = m² ✔
$(H_0/H_{eff})^{3/2}$ 무차원 ✔

### 8.3 지수 3/2의 위상 — 유도값인가 피팅값인가

**유도값이다.** 검증(A6.1–A6.4):

- $H$ 4배 연화 → 압입깊이 정확히 **4.0배** (A6.1)
- → 제거 체적 정확히 **8.0배** $= 4^{1.5}$ (A6.2)
- 지수 $= \log(8)/\log(4) = $ **1.500000** (A6.3)
- 하중 2배 → 체적 $2^{1.5} = 2.8284$배 (A6.4)

지수는 $\delta_p \propto H^{-1}$과 $A_f \propto \delta_p^{3/2}$의 합성이며,
**두 관계 모두 구형 압자 기하에서 나온다** — 튜닝 여지가 없다.

> **중요한 부작용**: 하중과 경도가 **같은 지수 $3/2$**로 들어간다(A6.4 vs A6.2).
> 즉 $\mathrm{MRR} \propto (F/H)^{3/2}$이므로 "화학이 경도를 4배 낮춘 것"과
> "기계가 하중을 4배 올린 것"이 모델 안에서 **구별되지 않는다.** 이것이 이 축의
> 근본적 식별 불가능성이다(§8.7).

### 8.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 완전 소성 접촉 | 하중이 작아 탄성 지배($p_{max} < \sim H/3$)면 Hertz 탄성이고 제거 없음. 탄성-소성 전이 판정이 선행돼야 함 |
| $\delta \ll R$ (구형 압자 근사) | 깊은 압입, 각진 입자, 응집체 |
| **절삭 효율 1** (파낸 것 전부 제거) | 실제로는 ploughing(옆으로 밀어냄)과 cutting(칩 생성)이 섞인다. 저장소 노트가 "구분 미해결"로 명시 ✔ — **이 가정이 MRR 절대값을 직접 스케일한다** |
| $H$가 잘 정의된 스칼라 | 화학 연화층은 깊이 방향 경도 구배를 갖는다. 압입 깊이가 연화층 두께와 비슷하면 "어느 $H$인가"가 모호 |
| 입자당 하중 $F$가 균일 | 활성 입자 통계에 분포가 있다. 저장소가 "$F$는 오더만 채택, 절대값 캘리브레이션 대상"으로 표기 ✔ |
| 화학이 경도로만 작용 | 화학은 용해(재료를 직접 제거), 표면 결합(화학적 이빨), 정전 접촉 빈도로도 작용한다. **경도 단일 채널은 축약이다** |

### 8.5 극한 거동

| 극한 | 거동 | 타당성 |
|---|---|---|
| $H_{eff} \to H_0$ | 배수 → 1 | ✔ |
| $H_{eff} \to 0$ | 배수 → ∞ | ✘ **비물리적 발산.** 검증(A6.5): $H$를 1000배 낮추면 체적 $3.2\times10^4$배. 클램프 필수 |
| $H_{eff} \to \infty$ | 배수 → 0 | ✔ 형식적으로 타당 |
| $F \to 0$ | $A_f \to 0$ | 형식적으로 ✔ 이지만 실제로는 탄성 영역으로 넘어가 소성식 자체가 무효 |

$H \to 0$ 발산이 실무적으로 중요하다: **화학 항들을 곱한 뒤 $-3/2$승하면 작은
오차가 증폭된다.** 화학 배수가 2배 틀리면 MRR은 2.83배 틀린다.

**심각한 식별 불가능성 세 건:**

1. **$F$와 $H_{eff}$**: $(F/H)^{3/2}$로만 들어가므로 둘의 **비만 결정되고 각각은
   결정되지 않는다.** 기계 축(하중)을 조정해 맞춘 결과와 화학 축(연화)을 조정해
   맞춘 결과가 동일 데이터에서 구별 불가.
2. **절삭 효율과 $H_{eff}$**: 효율 $\epsilon$을 곱하면 $\epsilon \cdot H^{-3/2}$이고,
   $\epsilon$은 $H^{-3/2}$의 스케일과 완전 축퇴된다.
3. **화학 축들 사이**: FabSim은 산화제·pH·연마재 항을 **곱한다.** 각 항이 모두
   무차원 배수이므로, 한 항을 2배 올리고 다른 항을 절반 내리면 결과가 같다.
   조성을 한 축씩만 스윕한 데이터가 없으면 축별 기여를 분리할 수 없다.

> **처방**: 이 축의 파라미터는 MRR 피팅으로 확정하지 말아야 한다. $H_{eff}$는
> 나노압입으로, $R$은 입도로, $F$는 접촉역학 모델로 **각각 독립 확보**한 뒤
> MRR은 **예측 검증용**으로만 쓰는 것이 유일하게 건전한 경로다.

### 8.8 FabSim 현 구현과의 차이

- `particle_chemomechanical_synergy.py`: 식 정확 구현, 자기시험 통과 ✔
- `SOFTENING_EXPONENT = 1.5`가 코드에 상수로 있고 주석이 "유도된 값이지 튜닝
  파라미터가 아니다"라고 명시 ✔ 우수
- **$H \to 0$ 클램프가 경도 경로에만 부분적으로 있다**(`_ph_softening_term`의 0.2
  하한). 다른 화학 항은 $H$를 경유하지 않고 MRR 배수를 직접 만들므로 이 보호가 없다
- 모듈이 팩터에 미배선 — docstring이 "Preston $K_p$로의 정량 연결식 없음"으로 명시 ✔
- 탄성/소성 전이 판정이 MRR 경로에 미반영

## 9. 교차 축 — 구조적 문제 3건

### 9.1 곱셈 독립 가정

FabSim은 화학 항을 전부 곱한다(`chemistry_factor`, `_f_chi`). 코드가 이를
"⚠ 독립으로 보고 곱했다 — 커플링 미모델링"으로 표기하는 것은 정직하나 ✔,
**실제로 존재하는 커플링이 최소 다섯 개**다:

| 커플링 | 물리 |
|---|---|
| pH ↔ 산화제 | 산화제의 산화력이 $E^\circ - 59.16(m/n)\mathrm{pH}$ mV. **Nernst가 이 결합을 정량으로 준다**(§6) — 모델링 가능한 결합인데 안 하고 있다 |
| pH ↔ 억제제 | 억제제 양성자화·배위가 $K_{inh}(\mathrm{pH})$. Ringbom $\alpha_H$로 정량 가능 |
| pH ↔ 킬레이터 | 조건부 안정도상수 $K'(\mathrm{pH})$. `chelation_surface_charge.py`에 **이미 구현됨** |
| 산화제 ↔ 킬레이터 | 킬레이터가 과-부동태막을 재용해 → 산화제 정점이 고농도로 이동. 정성 근거 있음 |
| $I$ ↔ 모든 축 | 활동도계수가 흡착상수·안정도상수·Nernst 활동도항에 동시 작용 |

이 중 **pH↔산화제와 pH↔킬레이터는 정량 모델식이 이미 있고 코드에도 있다** —
배선만 안 됐다. 곱셈 독립을 유지할 이유가 없는 두 건이다.

### 9.2 "기준 조건 대비 상대비" 계약의 양면

FabSim의 모든 화학 팩터는 기준 조건에서 1.0을 반환한다. 이는 $K_p$에 이미 반영된
효과를 두 번 세지 않기 위한 옳은 설계다 ✔ (2026-09-06 사고 기록).

**그러나 대가가 있다**: 기준 조건 파라미터(`*_ref`)가 팩에 없으면 기준=현재로
폴백해 **배수가 영원히 1.0**이 된다. 코드는 이를 경고하지만, 경고는 무시될 수 있다.
민감도 분석에서 "미모델링"으로 오진된 사례가 실제로 기록돼 있다.

> **구조적 개선 방향**: `*_ref` 부재를 경고가 아니라 **`status='unmodeled'` 반환**으로
> 승격하면 침묵 실패가 구조적으로 불가능해진다. 현재 설계 계약 §2가 이미 그 원칙을
> 선언하고 있으므로 일관성 문제다.

### 9.3 피팅 파라미터 총량과 데이터 부족

축별 피팅 파라미터 수:

| 축 | 피팅 파라미터 | 식별성 |
|---|---|---|
| Langmuir/억제제 | $k_{inhib}$, ($f$) | ✘ $K_{ads}$와 corr $+0.93$ |
| 산화제 | $n$ | ✔ 양호 |
| pH 정점 | $a_{lo}, a_{hi}$ | ⚠ 자유도 0 |
| pH 창 | 잔류율 2 + 기울기 2 | ⚠ 단일 데이터셋 역산 |
| 시너지 | $H_{eff}$, $F$, $\epsilon$ | ✘ 3중 축퇴 |
| Pourbaix/Nernst | **없음** | ✔ |
| Butler-Volmer | (미구현) | ✔ 구현하면 대부분 독립 측정 가능 |

**결론: 흡착·경도 계열은 피팅 파라미터가 많고 식별 불가능하며, 전기화학 계열은
피팅 파라미터가 거의 없고 독립 측정 가능하다.** 그런데 FabSim이 구현한 것은
전자이고 미구현이 후자다 — **모델링 투자 순서가 거꾸로 되어 있다.**

## 10. 킬레이터 축 — 유일한 완전 결측

브리핑이 지적한 세 축 중 **실제로 통로가 없는 것은 킬레이터뿐이다.**

### 10.1 모델식

**조건부 안정도상수 (Ringbom)**

$$\log K'(\mathrm{pH}, I) = \log K(I) - \log \alpha_H(\mathrm{pH}), \qquad
\alpha_H = 1 + \sum_{j} 10^{\,\log\beta_j - j\,\mathrm{pH}}$$

**이온강도 보정 (Davies)**

$$\log K(I) = \log K^{0} - A\!\left(\frac{\sqrt I}{1+\sqrt I} - 0.3 I\right)
\big(z_M^2 + z_L^2 - z_{ML}^2\big)$$

**유리 금속이온 분율 → 용해 구동력**

$$\frac{[M]_{free}}{[M]_{tot}} = \frac{1}{1 + K' C_{ch}}, \qquad
\frac{[M]_{tot}}{[M^{z+}]} = 1 + K_1 [L] + \beta_2 [L]^2 + \cdots$$

| 기호 | 의미 | 단위 |
|---|---|---|
| $K'$ | 조건부 안정도상수 | L mol⁻¹ |
| $\alpha_H$ | Ringbom 부반응 계수 | 무차원 |
| $\beta_j$ | 누적 양성자화 상수 | (L mol⁻¹)^j |
| $z_M, z_L, z_{ML}$ | 금속·리간드·착물 전하 | 무차원 |
| $A$ | Debye–Hückel 계수 | 무차원 (0.509 @25 °C) |

### 10.2 차원 검사

$K' C_{ch}$: (L mol⁻¹)(mol L⁻¹) 무차원 ✔
$10^{\log\beta_j - j\mathrm{pH}}$ 무차원 ✔ ($\beta_j$가 활동도 기준이므로 일관)
Davies 괄호 무차원 ✔

### 10.3 CMP에서의 역할 — 산화제·억제제와의 삼각관계

| 첨가제 | 작용 장소 | 정량 척도 | 방향 |
|---|---|---|---|
| 산화제 | 표면 (산화) | $E^\circ$, 형성 속도 | 구동력 생성 |
| 억제제 | 표면 (흡착) | $\theta$, $K_{ads}$ | 게이트 **닫기** |
| **킬레이터** | **용액상 (착화)** | $\log K'$ | 게이트 **열기** |

킬레이터의 Pourbaix 상 작용: 용존종 활동도를 낮춰 **부식 영역을 확장**하고
부동태 영역을 침식한다. 이는 §6.3의 "착화제 없음" 가정을 정면으로 깨는 것이며,
그래서 킬레이터는 **Pourbaix 축과 반드시 함께 모델링돼야 한다.**

### 10.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 리간드 양성자화만 경쟁 | 금속 가수분해·수산화물 침전·혼합 착물 무시 → `chelation_surface_charge.py`가 "알칼리 영역 값은 **상한 추정**"으로 명시 ✔ |
| 단일 금속 단일 리간드 | 다금속 경쟁(오염 이온이 킬레이터를 소비) |
| Davies 식 유효 | $I \gtrsim 0.5$ mol L⁻¹에서 붕괴 |
| 착화가 용해로 직결 | 착화는 **열역학**이고 용해는 **속도**다. $K'$가 커도 표면 반응이 율속이면 MRR이 안 오른다 |
| 용액상 작용만 | 킬레이터가 표면에 흡착해 오히려 보호하는 경우가 있다 (역할 반전) |

### 10.5 극한 거동

| 극한 | 거동 | 타당성 |
|---|---|---|
| $C_{ch} \to 0$ | $[M]_{free}/[M]_{tot} \to 1$ | ✔ |
| $C_{ch} \to \infty$ | → 0 (완전 착화) | ✔ 형식적으로 타당. 단 리간드 자체가 표면을 덮는 고농도 효과 미포함 |
| pH → 낮음 | $\alpha_H \to$ 큰 값, $K' \to$ 작음 (착화 불가) | ✔ 물리적으로 타당 — 리간드가 양성자화되어 금속과 경쟁 못 함 |
| pH → 높음 | $\alpha_H \to 1$, $K' \to K(I)$ | ✔ 단 이 극한에서 무시한 가수분해가 실제로 지배적이 되므로 **상한 추정**(§10.4) |
| $I \to 0$ | $\log K \to \log K^0$ | ✔ |

### 10.7 파라미터 분류

| 파라미터 | 분류 |
|---|---|
| $\log K^0$, $\log\beta_j$ | **문헌값 차용**(열역학 DB). 원리적으로 독립 측정 가능(전위차 적정) |
| $z_M, z_L$ | **이론**(화학종 전하) |
| $A$ | **이론 상수** |
| $C_{ch}$ | **레시피 입력** |
| $K' \to$ MRR 사상 | **완전 미확보.** 조건부 상수에서 제거율로 가는 변환식이 문헌에 폐형식으로 없다 |

마지막 행이 이 축 구현의 진짜 장벽이다: **열역학(착화 세기)은 잘 정량화돼 있으나,
그것이 MRR 배수로 번역되는 관계식이 없다.** 억제제의 $\theta \to$ MRR과 같은 문제다.

### 10.8 식별 불가능성

$\log K'$는 문헌 DB에서 오므로 피팅 대상이 아니다 ✔. 문제는 $K' \to$ MRR 변환에
새 피팅 파라미터(예: 용해 가중치 $w_{ch}$)를 도입할 때다. 이 $w_{ch}$는
산화제 정점 이동과 물리적으로 같은 효과를 내므로 **$(w_{ch}, C_{peak})$가
축퇴될 위험이 크다.** 킬레이터 항을 넣을 때는 산화제 정점을 **고정**하고
킬레이터만 스윕한 데이터가 필요하다.

### 10.9 FabSim 현 구현과의 차이

- `chelation_surface_charge.py`가 $\log K'(\mathrm{pH}, I)$, $\alpha_H$, Davies 보정,
  유리 금속 분율을 **전부 구현**하고 자기시험 통과 ✔
- 모듈 docstring이 "Recipe에 pH·이온세기·킬레이트 농도 필드 없어 engine.Model로
  조립할 입력이 없다"로 배선 부재 사유를 명시 ✔
- `_f_chi`가 `chelator_mM`을 **drivers로만 수집**하고 항으로 쓰지 않는다 —
  즉 UI에 값은 보이지만 결과에 영향이 없다. **이것이 가장 오해를 부르는 상태**다
- $K' \to$ MRR 변환식 미확보(§10.7) — 구현 전 문헌 조사가 필요한 진짜 공백

| Cook 1990 | DOI·서지 확인, **원문 미확보**(Elsevier 유료) |
| Stern & Geary 1957 | DOI 확인, **원문 미독** |
| Ringbom / Davies / Schulze-Hardy 원저 | **DOI 미확보.** 교과서 2차 인용 |
| $\Delta G_{ads}$ 절대값 | **미확보.** 저장소가 2차 인용·미검증 표기 |
| 아-Nernst $\zeta$ 기울기 실측 | **미확보** |
| 산화제 단봉 폐형식 | **문헌에 없음.** FabSim 현상론이 문헌식이 아님 |
| $\theta \to$ MRR, $K' \to$ MRR 변환식 | **문헌에 폐형식 없음.** 억제제·킬레이터 공통 장벽 |

### 12.2 모델링 공백

1. **킬레이터 축이 팩터에 전혀 없다** — 모듈은 있고 배선이 없다. `chelator_mM`이
   drivers로만 수집되어 "값이 보이는데 효과가 없는" 최악의 상태
2. **갈바닉 속도 경로 없음** — 방향만 판정. Butler-Volmer·혼합전위·Faraday 미구현
3. **Pourbaix 상 판정이 MRR에 미연결** — 계산되지만 쓰이지 않음
4. **pH↔산화제 결합(Nernst)이 미모델링** — 정량 모델식이 이미 있는데 곱셈 독립 유지
5. **이온강도 $I$ 통로 없음** — Davies 보정 구현됐으나 미배선
6. **볼록/오목 구분 없음** — $\theta$ 기반 스칼라 항으로는 평탄화를 원리적으로 설명 불가
7. **비평형(마찰 중) 화학 미모델링** — 모든 흡착·부동태 식이 평형 가정. 재부동태
   시간상수 vs 패드 접촉 간격의 경쟁이 빠짐
8. **온도 의존성 미결합** — 마찰 발열이 $K_{ads}$, $E^\circ$, $\ln10\,RT/F$에 동시 작용

### 12.3 이 문서가 새로 발견한 것

1. **$\exp(-k_{inhib}\theta)$ 형태가 의도와 반대로 고농도 분해능을 악화시킨다**
   (0.9515 vs $(1-\theta)$의 0.509, A1.4/A1.5). 2026-09-06 수정이 해결하려던 문제를
   실제로는 해결하지 못했다
2. **산화제 단봉의 하강 가지 기울기가 메커니즘을 판별한다** — 경도 경로면 점근적으로
   $-3/2$(A2.7), 현 구현은 $-1/n$(A2.3) = 형상 파라미터. 단봉 재현 자체는 물리를
   담보하지 않는다(A2.5가 반증)
3. **갈바닉 면적비 법칙 지수가 1이 아니라 $b_c/(b_a+b_c)$**, 대칭 Tafel에서 **1/2**
   (A5.7 측정 0.4994). 면적비 선형 추정은 과대평가
4. **선형 분극 영역에서도 $\alpha$가 2차항에 남고, 그 크기가 $\eta$에 선형으로
   커진다**(A5.3): $\eta=1$ mV에서 2.3%, 10 mV에서 23%. 통상 LPR 진폭(±10 mV)에서
   $\alpha$ 미지는 20%대 오차다
5. **$(K_{ads}, k_{inhib})$가 MRR 데이터로 식별 불가능**(동등해 994개, corr +0.929, A7.1).
   반면 $(C_{peak}, n)$은 잘 식별된다(A7.2) — 축별로 피팅 정당성이 다르다
6. **FabSim의 모델링 투자 순서가 거꾸로다**(§9.3): 피팅 파라미터가 많고 식별
   불가능한 흡착·경도 계열은 구현됐고, 파라미터가 거의 없고 독립 측정 가능한
   전기화학 계열이 미구현이다
