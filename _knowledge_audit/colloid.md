## 1. DLVO 이론 — van der Waals 인력 + 전기이중층 반발

### 1.1 모델식과 기호표

```
V_T(h) = V_vdW(h) + V_EDL(h)

V_vdW(h) = − A_H·a / (12 h)                                    (동일 구-구, Derjaguin, h ≪ a)

V_EDL(h) = 2π ε₀ ε_r a ζ² · ln(1 + e^(−κh))                    (일정전위, 선형 PB, κa ≫ 1)
         = 64π a n_∞ k_BT γ² κ⁻² · e^(−κh)                     (LSA, 고전위에서도 유효)
  γ = tanh(z e ψ₀ / 4k_BT)
```

| 기호 | 의미 | SI 단위 |
|---|---|---|
| V_T, V_vdW, V_EDL | 상호작용 자유에너지 | J (실무는 k_BT 단위) |
| A_H | Hamaker 상수 (매질 낀 물질쌍 고유) | J |
| a | 입자 반경 = d_p/2 | m |
| h | 표면간 최단거리 | m |
| ζ | 제타전위 (ψ₀의 실험 대리값) | V |
| ψ₀ | 표면전위 | V |
| κ | 역 Debye 길이 | m⁻¹ |
| n_∞ | 벌크 이온 수밀도 (z:z) | m⁻³ |
| γ | 무차원 표면전위 함수 | — |
| ε₀, ε_r | 진공 유전율, 매질 비유전율 | F/m, — |

### 1.2 차원 검사 (스크립트 §2)

- `V_vdW`: [J]·[m]/[m] = **J** ✓
- `V_EDL` (일정전위형): [F/m]·[m]·[V²] = [C/V/m]·[m]·[V²] = C·V = **J** ✓
- `V_EDL` (LSA형): [m]·[m⁻³]·[J]·[m²] = **J** ✓
- Derjaguin 변환 일반형 `V_sphere-sphere = πa ∫_h^∞ W_plate(x)dx`: [m]·[J/m²]·[m]... 정확히는
  [m]·([J/m²]·[m]) = **J** ✓ (적분이 J/m²에 길이를 곱한다)

### 1.3 유도 가정과 각 가정이 깨지는 조건

| # | 가정 | 깨지는 조건 |
|---|---|---|
| A1 | Derjaguin 근사 (h ≪ a): 곡면을 평판 스택으로 근사 | h ~ a 이상. 즉 **작은 입자 + 넓은 간격**에서 곧바로 무효 — d_p가 10 nm급이면 h가 5 nm만 돼도 이미 위험 |
| A2 | 비지연(non-retarded) vdW: A_H가 h에 무관한 상수 | h ≳ 5–10 nm에서 지연효과로 실효 A_H가 감소 → V_vdW를 **과대평가**. 2차 최소의 깊이·위치가 이 구간에 있으므로 2차 최소 예측은 항상 보수적으로 읽을 것 |
| A3 | 선형 Poisson–Boltzmann (Debye–Hückel): \|ψ₀\| ≲ 25 mV | CMP에서 흔히 쓰는 \|ζ\| = 40–60 mV는 이미 선형 영역 밖 → 일정전위 ln(1+e^{−κh}) 형은 반발을 **과대평가**. 이 구간에서는 LSA(γ 형)가 맞다 |
| A4 | κa ≫ 1 (평판 근사 EDL) | 작은 입자 + 저이온강도. κa < 1이면 구면 확산층 보정 필요 |
| A5 | 일정전위(CP) 경계조건 | 접근 중 표면 해리평형이 못 따라오면 **일정전하(CC)** 가 맞고, 이 경우 반발이 훨씬 커진다. 두 조건은 h→0에서 정반대(CP는 유한/인력, CC는 발산) |
| A6 | 표면이 매끈한 강체 구 | 각진 다면체·표면 거칠기·수화층은 non-DLVO 힘(수화반발, 구조력)을 만들고 이들은 h ≲ 2 nm에서 vdW를 압도할 수 있다 |
| A7 | 두 표면 사이에 DLVO 이외의 힘 없음 | 고분자·계면활성제가 있으면 §6 입체항이 지배 |

### 1.4 무차원수와 판정

| 무차원수 | 정의 | 판정 |
|---|---|---|
| **V_max/k_BT** (에너지 장벽) | 곡선 최댓값 | ≳ 20 → 동역학적으로 안정(수 시간~일 규모). 5–20 → 준안정(교반·온도로 넘어감). ≲ 5 → 급속응집 |
| **κa** | 반경/Debye 길이 | ≫1 Smoluchowski·Derjaguin 유효 / ≲1 Hückel·구면 보정 필요 |
| **γ** | tanh(zeψ₀/4k_BT) | γ→1(고전위, \|ψ₀\| ≳ 100 mV)에서 반발이 ψ₀에 포화 → 전위를 더 올려도 안정성이 안 는다 |
| **W** (Fuchs 안정도비) | 실제 응집시간 / 확산율속 응집시간 | ≈ exp(V_max/k_BT)/(2κa). W=1이 확산율속 상한 |
| **A_H/k_BT** | 인력의 열에너지 대비 크기 | 산화물-물-산화물이 통상 1–10 오더 → vdW가 항상 k_BT급으로 존재한다는 뜻 |

### 1.6 CCC(임계응집농도) 폐형식 — Schulze–Hardy 법칙

V_T = 0 **및** dV_T/dh = 0 을 동시에 풀면 임계점에서 **κh\* = 1**(정확히 1 Debye 길이)이고,

```
CCC ∝ (ε₀ε_r k_BT)³ γ⁴ / (N_A e⁶ A_H² z⁶)
```

스크립트 §2b 실행 결과:

- **CCC는 입자 반경 a에 완전히 무관**(V와 dV/dh 두 항 모두 a에 선형 ⇒ 소거). 유도로 확인.
- **CCC ∝ A_H⁻²**: A_H를 2배로 하면 CCC는 정확히 1/4 (수치 4.000, 해석해 4).
- **고전위 극한(γ→1)에서 Schulze–Hardy z⁻⁶ 회복**: CCC(1:1)/CCC(2:2) = **63.97**(해석해 64),
  CCC(1:1)/CCC(3:3) = **728.65**(해석해 729).
- 중간 전위(ψ₀ = −100 mV)에서는 γ가 z에 의존해 비율이 **23.8 / 236.1**로 줄어든다 —
  "z⁻⁶는 고전위 극한 법칙이지 보편 법칙이 아니다"가 이 계산의 결론이다.
- ⚠ **모델 붕괴 신호**: ψ₀=−100 mV, A_H=8.5×10⁻²¹ J를 넣으면 CCC(1:1) = **16.8 M**이 나온다.
  물에서 도달 불가능한 농도다. 이는 "이 입자는 1:1 무관이온으로는 응집시킬 수 없다"가 아니라
  **가정이 깨졌다**는 뜻이다 — 그 농도에서 κ⁻¹ ≈ 0.07 nm로 A2·A3·A4가 전부 무효.
  CCC 폐형식은 "z 스케일링"과 "A_H 스케일링"에만 쓰고 **절대값을 쓰지 마라**.

### 1.7 응집 동역학 — Fuchs 안정도비와 반감기

```
t½ = 3η / (4 k_BT n₀) · W          n₀ = 6φ / (π d_p³)
W ≈ exp(V_max/k_BT) / (2κa)         (Reerink–Overbeek 근사)
```

차원: [Pa·s]/([J]·[m⁻³]) = [N·s/m²]·[m³/J] = **s** ✓

스크립트 §2c 실행값(η = 8.9×10⁻⁴ Pa·s, 25 °C):

| φ | d_p [nm] | n₀ [m⁻³] | t½ (W=1) | t½ (W=10⁵) |
|---|---|---|---|---|
| 0.01 | 50 | 1.53×10²⁰ | 1.06 ms | 0.029 h |
| 0.10 | 50 | 1.53×10²¹ | 0.106 ms | 0.003 h |
| 0.01 | 200 | 2.39×10¹⁸ | 68 ms | 1.89 h |

**읽는 법**: t½ ∝ d_p³/φ 이므로(수치 확인: 200/50 nm에서 정확히 64배) **작고 진한 슬러리일수록
확산 충돌이 압도적으로 빠르다**. 무장벽(W=1) 상태에서는 밀리초 단위로 응집한다 —
슬러리가 며칠 버틴다는 것은 W가 최소 10⁷–10⁹ 오더, 즉 V_max ≳ 20 k_BT라는 뜻이다.
이것이 "\|ζ\| ≳ 30 mV" 경험칙의 정량적 정체다.

⚠ **미검증**: 이 t½은 **초기(2체) 응집** 반감기이며 후기 클러스터-클러스터 성장은 다루지 않는다.
또 CMP 공급 라인의 전단(shear)은 orthokinetic 응집을 추가로 만드는데 여기 없다.

| I | **독립 측정 가능** | 전도도 또는 조성 계산 |
| ε_r, η, T | **문헌값 차용** (물성표) | 온도의존성 알려짐 |
| A_H | **문헌값 차용 → 실무상 피팅** | Lifshitz 이론으로 계산 가능하나 광학 스펙트럼이 필요; 실제로는 계별 오더값을 차용하고 안정성 데이터로 조정 |
| Born 컷오프 / 1차 최소 깊이 | **모델 밖** | DLVO가 주지 않음 |
| CP vs CC 경계조건 | **선택(가정)** | 데이터로 구분하려면 CCC의 ψ₀ 의존성을 재야 함 |

### 1.9 FabSim 현 구현과의 차이

`sim/tier2_physics/dlvo_colloid.py` 는 위 식 중 **일정전위 ln(1+e^{−κh}) 형만** 구현했고
정성 재현(이온강도↑ → 장벽↓, 2차최소 심화 / \|ζ\|↓ → 장벽 붕괴)까지 검증했다.

| 항목 | 현 구현 | 이 감사가 추가한 것 |
|---|---|---|
| EDL 함수형 | 일정전위 선형 PB 1종 | LSA(γ) 형 — \|ζ\| > 25 mV에서 이쪽이 맞다 |
| CCC | 없음 | 폐형식 + z⁻⁶ 검증 + a 무관성 증명 |
| 응집 동역학 | 없음 | Fuchs W, Smoluchowski t½ (φ, d_p 스케일링 검증) |
| 이종(입자-웨이퍼) 상호작용 | **없음** | HHF 식 (§3) |
| 엔진 연결 | `engine.py`가 IEP 거리만 정성 진단으로 씀 | — |
| 임계값 근거 | `stability_qualitative()`의 \|pH−IEP\| < 1.0 / ≥ 2.0 은 코드 주석 자체가 "미검증(arbitrary)"이라 자인 | **이 감사도 이 임계를 정당화할 근거를 찾지 못했다.** V_max ≳ 20 k_BT라는 물리 기준이 있으므로, pH 거리가 아니라 **장벽 높이로 판정하는 경로가 원칙적으로 가능**하다(ζ(pH) 곡선이 필요) |

## 2. Debye 길이 — 이온강도 의존성과 슬러리 안정성 창

### 2.1 모델식과 기호표

```
κ⁻¹ = √( ε₀ ε_r k_B T / (2 · 10³ N_A e² z² I) )

물, 25 °C, 1:1 전해질:  κ⁻¹ ≈ 0.304 / √I  [nm],  I in mol/L

일반 이온강도:  I = ½ Σ_i c_i z_i²
```

| 기호 | 의미 | 단위 |
|---|---|---|
| κ⁻¹ | Debye 차폐거리 | m (실무 nm) |
| I | 이온강도 | mol/L |
| z | 대칭 전해질 원자가 | — |
| e | 기본전하 | C |
| N_A | 아보가드로 수 | mol⁻¹ |
| 10³ | mol/L → mol/m³ 환산 | L/m³ |

### 2.2 차원 검사 (스크립트 §1)

κ² = 2·(ze)²·I·10³·N_A / (ε₀ε_r k_BT)
→ [C²]·[mol·m⁻³]·[mol⁻¹] / ([C²·J⁻¹·m⁻¹]·[J]) = [C²·m⁻³] / [C²·m⁻¹] = **m⁻²** ✓
따라서 κ⁻¹ [m] ✓

### 2.3 수치 검증 (스크립트 §1 실행값)

| I [M] | 정확식 [nm] | 0.304/√I [nm] | 상대오차 |
|---|---|---|---|
| 1e−4 | 30.4206 | 30.4000 | 0.07 % |
| 1e−3 | 9.6198 | 9.6133 | 0.07 % |
| 1e−2 | 3.0421 | 3.0400 | 0.07 % |
| 1e−1 | 0.9620 | 0.9613 | 0.07 % |
| 1.0 | 0.3042 | 0.3040 | 0.07 % |

원자가 스케일링 κ⁻¹ ∝ 1/z 확인: κ⁻¹(z=1)/κ⁻¹(z=2) = **2.0000** (해석해 2).

### 2.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 점전하 이온(크기 없음) | I ≳ 0.1 M에서 이온 크기·수화가 무시 불가 → 실효 κ⁻¹이 예측보다 큼 |
| 평균장(이온 상관 무시) | 다가 이온(z ≥ 2) 또는 고농도 — 이온-이온 상관이 전하역전(charge inversion)까지 일으킬 수 있다 |
| 매질이 연속 유전체, ε_r 상수 | 표면 1–2 nm 이내에서 물의 ε_r이 크게 떨어짐(유전포화) → 실제 차폐가 예측과 다름 |
| 선형화(Debye–Hückel) | 이 식 자체는 선형화 없이도 성립하는 **길이 척도**의 정의이므로 견고. 무너지는 건 그것을 쓰는 V_EDL 쪽 |
| 완전 해리 | 약전해질·완충계에서는 실효 I가 조성 I보다 작음 |

### 2.5 무차원수와 판정

| 무차원수 | 판정 |
|---|---|
| **κa** = a/κ⁻¹ | ≫1: 표면이 평판처럼 보임, Smoluchowski f=1.5. ≲1: Hückel f=1.0 |
| **κ·h** | 반발이 실제로 미치는가 — 두 입자가 h에서 만날 때 κh ≳ 3이면 EDL은 사실상 없음 |
| **κ⁻¹/d_p** | ≳ 0.1이면 EDL이 입자 크기와 겨루는 두께 ⇒ 유효 유체역학 반경·점도가 EDL에 좌우됨 |
| **κ⁻¹ / (이온 반경 ~0.3 nm)** | ≲1이면 **연속체 모델 자체가 무효** — 안전 하한 |

### 2.6 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| I→0 | κ⁻¹ → ∞ (I=10⁻⁸ M에서 3042 nm) | 수학적으로 타당하나 **물리적으로 도달 불가** — 대기 CO₂ 평형만으로 I ≳ 10⁻⁵ M. 또 κ⁻¹이 입자간 평균거리를 넘으면 이중층이 겹쳐 "고립 입자" 가정이 깨진다 |
| I→∞ | κ⁻¹ → 0 (I=10 M에서 0.096 nm) | **비타당** — 수화이온 반경(≈0.3 nm)보다 작다. 연속체 PB 붕괴 |
| z→∞ | κ⁻¹ ∝ 1/z | 타당하나 다가이온은 특이흡착·전하역전을 함께 일으켜 DLVO 예측 범위 밖 |
| T→0 | κ⁻¹ → 0 | 무의미(물이 언다). CMP 온도창(20–60 °C)에서 κ⁻¹의 T 의존은 √T와 ε_r(T) 감소가 부분 상쇄돼 약함 |

### 2.7 슬러리 안정성 창 — 두 부등식의 교집합

Debye 길이 하나가 안정성을 정하지 않는다. **안정 창은 두 조건의 교집합**이다:

```
(i)  장벽 조건    V_max(ζ, I, A_H, a) ≳ 20 k_BT      ⇒ I 에 상한
(ii) 반발 도달거리 κ⁻¹ ≳ (표면 거칠기 진폭 + 수화층 두께)  ⇒ I 에 또 하나의 상한
```

(ii)를 명시하는 이유: 장벽이 κ⁻¹ 근방에 서는데(§1.6에서 임계점이 정확히 κh\*=1임을 보였다),
표면 거칠기가 κ⁻¹보다 크면 **돌기끼리는 이미 장벽 안쪽에서 만난다**. 즉 매끄러운 구 가정의
장벽 계산이 통째로 낙관적이 된다. 스크립트 §2 표에서 I ≥ 0.1 M일 때 장벽 위치가 0.5 nm까지
내려오는데, 이는 어떤 실제 산화물 표면의 거칠기보다도 작다 — **고이온강도에서 DLVO 장벽
계산을 믿지 마라**는 정량적 근거다.

### 2.8 파라미터 분류

| 파라미터 | 분류 |
|---|---|
| I | **독립 측정 가능** (전도도/조성). 단 CMP 슬러리는 pH 조절제·첨가제가 I에 기여하므로 "설계값"이 아니라 실측이 옳다 |
| z (실효 원자가) | **독립 측정 가능**하나 혼합 전해질에서는 I 정의로 흡수 |
| ε_r(T), T | **문헌값 차용** |
| 0.304 계수 | **유도값** (위 상수들의 조합) — 피팅 대상 아님 |

### 2.9 FabSim 현 구현과의 차이

- `dlvo_colloid.py::debye_length_nm()` 은 정확식을, `debye_length_approx_nm()` 은 0.304/√I를
  구현하고 둘의 일치를 self-test한다. **이 축은 구현이 정확하다.**
- **차이 1**: 팩에 `slurry_ionic_strength_M` 같은 필드가 없다. 즉 I는 코드 안에서만 살아 있고
  레시피→모델 경로에 연결돼 있지 않다(`engine.py`는 IEP 거리만 씀).
- **차이 2**: §2.7의 "안정 창 = 두 부등식 교집합"이 구현돼 있지 않다. 현 구현의 안정성 판정은
  pH−IEP 거리 하나뿐이고, **이온강도 축이 판정에 전혀 들어가지 않는다** — 같은 pH에서
  염을 넣으면 응집한다는 §1의 물리를 판정 함수가 못 본다.

## 3. 제타전위와 등전점 — 입자-웨이퍼 정전 상호작용의 부호 반전

### 3.1 모델식과 기호표

**(a) ζ의 측정 — Henry 식**

```
μ_E = 2 ε₀ ε_r ζ f(κa) / (3 η)

f(κa) → 1.5 (Smoluchowski, κa ≫ 1)
f(κa) → 1.0 (Hückel,       κa ≪ 1)
Ohshima 근사:  f(κa) = 1 + 1/[2(1 + 2.5/(κa(1+2e^{−κa})))³]
```

**(b) 이종 상호작용 — Hogg–Healy–Fuerstenau (일정전위, 구-평판 Derjaguin)**

```
V_EDL(h) = π ε₀ ε_r a { 2ψ₁ψ₂ ln[(1+e^{−κh})/(1−e^{−κh})] + (ψ₁²+ψ₂²) ln(1−e^{−2κh}) }

원거리 점근 (κh ≫ 1):  V_EDL → 2π ε₀ ε_r a ψ₁ ψ₂ e^{−κh}
```

| 기호 | 의미 | 단위 |
|---|---|---|
| μ_E | 전기영동 이동도 | m²·V⁻¹·s⁻¹ |
| f(κa) | Henry 함수 | — |
| ψ₁, ψ₂ | 입자·웨이퍼 표면전위(실무상 ζ로 대입) | V |
| IEP | 표면전하 0이 되는 pH | — |

### 3.2 차원 검사

- Henry: [F/m]·[V]/[Pa·s] = [C·V⁻¹·m⁻¹]·[V]/[N·s·m⁻²] = C·m⁻¹·m²/(N·s) = **m²·V⁻¹·s⁻¹** ✓
  (C/N = m/V 이므로)
- HHF: [F/m]·[m]·[V²] = **J** ✓ (스크립트 §3)

### 3.3 부호 반전 조건 — 이것이 이 축의 핵심 결론

원거리 점근에서 **V_EDL의 부호 = sign(ψ₁·ψ₂)** 이다. 따라서:

```
입자 IEP = IEP_p,  웨이퍼(막) IEP = IEP_w  일 때

  pH < min(IEP_p, IEP_w)  → 둘 다 (+) → ψ₁ψ₂ > 0 → 반발
  pH > max(IEP_p, IEP_w)  → 둘 다 (−) → ψ₁ψ₂ > 0 → 반발
  min < pH < max          → 이부호     → ψ₁ψ₂ < 0 → 인력   ← 부호가 뒤집히는 창
```

**부호 반전 창의 폭은 \|IEP_p − IEP_w\| 이고, 그 안에서 입자는 웨이퍼로 끌려간다.**
이것은 재료 조합에 무관한 일반 규칙이다 — 어떤 산화물 쌍을 넣어도 성립한다.

스크립트 §3 수치(a=50 nm, I=10 mM, 일정전위):

| 조합 | h=1 nm | h=3 nm | h=10 nm |
|---|---|---|---|
| 동부호 (−40, −40) mV | +92.04 k_BT | +53.81 k_BT | +6.23 k_BT |
| 동부호 (−40, −10) mV | +5.58 k_BT | +9.88 k_BT | +1.52 k_BT |
| 이부호 (−40, +20) mV | −115.74 k_BT | −41.21 k_BT | −3.25 k_BT |
| 한쪽 0 (−40, 0) mV | −30.99 k_BT | −6.36 k_BT | −0.06 k_BT |

**두 가지 비자명한 결과를 짚는다.**

1. **동부호 비대칭(−40, −10)에서 근거리 반발이 오히려 꺾인다**: h=3 nm에서 +9.88인데
   h=1 nm에서 +5.58로 **감소**한다. 일정전위 조건에서는 표면이 가까워질 때 전하가
   재조정되며, 전위 차이가 크면 (ψ₁²+ψ₂²)ln(1−e^{−2κh}) 항(항상 음수)이 이겨서
   근거리에서 인력으로 돌아설 수 있다. **"둘 다 음전하면 항상 밀어낸다"는 직관은 틀렸다.**
2. **한쪽이 정확히 IEP(ψ₂=0)일 때 일정전위 모델은 인력을 준다**(−6.36 k_BT @3 nm).
   반면 **일정전하 모델에서는 이 조합이 무상호작용(0)** 이다. 즉 IEP 근처에서
   경계조건 선택이 부호를 바꾼다 — 이 조건에서의 예측은 **가정 의존적**임을 명시해야 한다.

### 3.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| ζ ≈ ψ₀ (전단면이 표면과 같다) | 전단면은 표면에서 0.2–0.5 nm 떨어져 있어 \|ζ\| < \|ψ₀\| 항상. 고이온강도에서 격차 확대 |
| 매끈한 강체 표면 | 다공성·젤층 표면("soft particle")에서는 Henry 식 대신 Ohshima soft-particle 이론이 필요하고, 이 경우 μ_E가 I→∞에서 0으로 안 가고 유한값에 수렴한다 — **이것이 젤층 존재의 진단 신호** |
| 균일 표면전하 | 패치 전하(patchy) 표면에서는 평균 ζ가 0(=IEP)이어도 국소 인력이 남는다 → "IEP에서 상호작용 0"이 거짓 |
| IEP가 재료 고유 상수 | **거짓에 가깝다.** IEP는 표면 수산기 밀도·불순물 흡착·전처리에 민감하고, 용액 중 다른 종의 특이흡착이 IEP를 통째로 이동시킨다. 저장소 형제 노트도 같은 재료의 문헌 IEP 실측이 4 pH 단위 넘게 흩어짐을 기록하고 있다 |
| 선형 PB (HHF) | \|ψ\| ≳ 25 mV → 반발 과대평가. 위 표의 절대값은 순위·부호 판정용이고 절대 k_BT 값은 상한 추정 |
| 두 표면이 같은 κ를 본다 | 간극이 κ⁻¹급으로 좁으면 간극 내 이온농도가 벌크와 다름(이온 배제) |

### 3.5 무차원수

| 무차원수 | 판정 |
|---|---|
| **κa** | Henry f 선택. CMP 통상 조건은 κa ≫ 1 ⇒ f=1.5 |
| **zeζ/k_BT** | 무차원 전위. 25 mV(=k_BT/e)가 1 — 이보다 크면 선형 PB 밖 |
| **\|pH − IEP\|** | 부호는 정하지만 크기는 못 정함. ζ(pH) 기울기(전위차 적정 곡선)가 없으면 \|ζ\|를 못 준다 |
| **ψ₁/ψ₂** | 비대칭도. 1에서 멀어질수록 §3.3-(1)의 근거리 인력 반전이 잘 생긴다 |

### 3.6 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| pH → IEP_p | ζ→0, V_EDL(동종) → 0, 장벽 붕괴 | 타당 — §1.5에서 수치 확인 |
| I → ∞ | μ_E → 0 (강체 입자) | 타당. **유한값 수렴하면 젤층 있음** |
| I → 0 | κa ≪ 1 → f → 1.0 (Hückel) | 타당하나 저I에서 μ_E 측정 자체가 어렵다(전도도 부족) |
| ψ₂ → 0 | CP: 인력 / CC: 0 | **모델 의존** — 이 극한을 예측에 쓰지 마라 |
| h → 0 | HHF의 ln(1−e^{−2κh}) → −∞ | **비타당**. Derjaguin + 선형 PB 동시 붕괴. h ≳ 0.5 nm 이상에서만 쓸 것 |

### 3.7 파라미터 분류

| 파라미터 | 분류 | 비고 |
|---|---|---|
| μ_E | **독립 측정 가능** | ELS |
| ζ | **유도값** (μ_E + Henry) — f(κa) 선택에 따라 1.5배 차이 | Smoluchowski/Hückel 선택이 곧 50 % 불확실성 |
| IEP_p, IEP_w | **독립 측정 가능**하나 **표면 상태 의존** — 실무상 문헌값 차용 후 재확인 필요 | 웨이퍼 박막의 IEP는 벌크 분말값과 다를 수 있고, 저장소도 이를 "미확보"로 기록 |
| ψ₀ | **측정 불가** — ζ로 대리 | 구조적 한계 |
| ζ(pH) 곡선 기울기 | **피팅 필요** | 이게 없으면 pH→\|ζ\| 정량 매핑 불가 |

### 3.8 FabSim 현 구현과의 차이

| 항목 | 현 구현 | 차이 |
|---|---|---|
| Henry 역산 | `dlvo_colloid.py::henry_zeta_from_mobility()` — f를 인자로 받음 | Ohshima 보간 f(κa) 미구현: 사용자가 1.0/1.5 중 골라야 하고 그 선택이 결과를 1.5배 바꾼다 |
| IEP 부호 판정 | `chelation_surface_charge.py::oxide_surface_charge_sign()` — pH vs IEP 비교로 +/0/− | **단일 표면의 부호만** 판정. 입자·웨이퍼 **쌍**의 곱 부호(§3.3의 핵심 규칙)를 판정하는 함수가 없다 |
| 이종 상호작용 에너지 | **없음** | HHF 미구현 |
| 안정성 판정 | `stability_qualitative(ph, abrasive_iep_ph, wafer_iep_ph)` — 웨이퍼 IEP를 받긴 하나 코드 주석대로 **"위험도 분류에 반영하지 않는다"** | §3.3이 이 자리에 넣을 물리를 준다: `min(IEP_p,IEP_w) < pH < max(...)` 이면 입자-웨이퍼 인력 레짐 ⇒ 부착/잔류 위험 ↑, 동시에 접촉 확률 ↑로 MRR ↑ 방향. 두 결과가 반대 방향이라 단일 "risk" 스칼라로 뭉개면 안 된다 |
| \|ζ\| 크기 | 계산하지 않음(코드가 명시적으로 자인) | ζ(pH) 곡선이 없어서다 — 정직한 처리이며 이 감사도 대안이 없다 |

## 4. 입도 분포 — D50 / D90 / D99 와 꼬리가 결함을 지배하는 이유

### 4.1 정의와 모델식

**정의** (반드시 구분할 것):

- **D50 / D90 / D99**: 누적분포의 백분위 직경. "D99 = 이 값 이하가 전체의 99 %".
  ⚠ **개수 기준(number-weighted)인지 부피 기준(volume-weighted)인지가 결정적**이다.
  같은 분포라도 부피 기준 D99가 개수 기준 D99보다 훨씬 크다 — 큰 입자가 d³ 가중되기 때문.
- **LPC(large particle count)**: 임계 직경 d_c **초과 입자의 절대 개수 밀도** [개/mL].
  D99와는 **다른 축**이다: D99는 대표 직경, LPC는 개수. 둘을 동일시하면 안 된다.

**대수정규 PSD**(단일봉 슬러리의 표준 모형):

```
ln d ~ N(ln D50, σ_ln²),   σ_ln = √ln(1 + CV²)

D_p / D50 = exp(σ_ln · z_p),   z_90 = 1.2816,  z_99 = 2.3263

임계경 초과 개수분율:  N(d > d_c)/N_tot = 1 − Φ( ln(d_c/D50) / σ_ln )
```

**스크래치 모델** (저장소 형제 노트가 원문에서 확보한 형태):

```
스크래치 밀도 = s · [d_c 초과 입자 개수]        (개수축에서 선형)
Δ(대표직경축 근사) = (D99 / D99_ref)^n
```

| 기호 | 의미 | 단위 |
|---|---|---|
| D50, D90, D99 | 누적 백분위 직경 | m (nm) |
| CV | 변동계수 σ/평균 | — |
| σ_ln | 로그공간 표준편차 | — |
| d_c | 스크래치 임계 직경 | m |
| n | 손상 지수 | — |

### 4.2 차원 검사

- `D_p/D50 = exp(σ_ln z_p)`: 지수의 인수가 무차원 ✓, 결과 무차원 비 ✓
- `N(d>d_c)/N_tot`: 무차원 ✓
- `스크래치 = s·N`: [counts] = [counts/(개/mL)]·[개/mL] ✓
- `Δ = (D99/D99_ref)^n`: 무차원 ✓ (기준 조건에서 항등적으로 1.0)

### 4.3 왜 꼬리가 지배하는가 — 계산으로

스크립트 §4 실행값:

| CV | σ_ln | D90/D50 | D99/D50 | N(d > 4·D50) |
|---|---|---|---|---|
| 0.1 | 0.100 | 1.136 | 1.261 | ~0 |
| 0.2 | 0.198 | 1.289 | 1.585 | 1.28e−12 |
| 0.3 | 0.294 | 1.457 | 1.980 | 1.17e−06 |
| 0.5 | 0.472 | 1.832 | 3.001 | 1.67e−03 |
| 0.7 | 0.631 | 2.246 | 4.345 | 1.41e−02 |

**꼬리가 지배하는 이유는 세 겹이다:**

1. **임계 현상**: 스크래치는 "임계 직경 d_c를 넘는 단일 입자가 소성 압입 궤적을 남기는 사건"이다.
   d_c 아래 입자는 아무리 많아도 스크래치 카운트에 기여하지 않는다 → 관계가 **개수축에서 선형**이 되고,
   D50은 이 개수를 거의 결정하지 못한다.
2. **분포 꼬리의 지수적 민감도**: 위 표에서 CV가 0.3 → 0.5로 **1.7배** 커질 때
   4·D50 초과 개수분율은 1.17e−6 → 1.67e−3으로 **1400배** 늘어난다.
   같은 D50에서 폭만 조금 바뀌어도 꼬리 개수는 자릿수로 움직인다.
3. **민감도 정량**(스크립트 §4, d_c = 4·D50, CV=0.3 기준):
   ∂ln N/∂ln CV = **+24.5**, ∂ln N/∂ln D50 = **+18.1**.
   **꼬리 개수는 분포 폭에 D50보다 더 민감하다.** 즉 평균 입경을 관리해도 폭이 새면 결함이 난다.

역산 검사: 저장소가 채택한 업계 일반비 D99/D50 = 4.29–5.00을 대수정규로 역산하면
σ_ln = 0.626–0.692, 즉 **CV = 0.69–0.78**이 나온다. 단일봉 콜로이드로는 비현실적으로 넓다
→ **실제 분포는 단일 대수정규가 아니라 "본체 + 별개의 대입자 모집단"의 이봉(bimodal) 구조**일
가능성이 높다. 이것이 "D99를 D50에 일반비를 곱해 유도하는" 관행의 구조적 약점이다:
이봉 분포에서 꼬리 모집단은 본체 D50과 물리적으로 독립(제조 잔류·응집·오염 기원)이므로
비례 관계가 성립할 이유가 없다.

### 4.4 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 단일봉 대수정규 | 위에서 보인 대로 CMP 슬러리 꼬리는 이봉일 가능성 — 이때 D99 예측이 무너진다 |
| d_c가 슬러리계와 무관한 상수 | d_c는 막 경도·패드·압력에 의존한다. 저장소 형제 노트도 원문 저자가 "다른 공정으로의 일반화는 범위 밖"이라 명시했음을 기록 |
| 스크래치 ∝ 개수 (선형) | 대입자가 많아 서로 궤적이 겹치면 포화(같은 자리를 두 번 긁어도 1개) |
| D99가 LPC의 대리변수 | **정량적으로 동일시 불가**(§4.1). Δ = (D99/D99_ref)^n 은 개수축 선형성을 직경축으로 옮긴 근사이고, 지수 n은 그 옮김에서 생기는 **분포 꼬리 기울기의 그림자**이지 물리 상수가 아니다 |
| 대입자가 원래 크기로 접촉에 참여 | 큰 응집체는 접촉 중 파쇄될 수 있다(§7) |
| 광산란 등가직경 = 기하 직경 | 굴절률·형상이 다르면 등가직경 환산에 계통오차 |

### 4.5 무차원수

| 무차원수 | 판정 |
|---|---|
| **d_c/D50** | ≫1이면 스크래치는 순수 꼬리 사건(D50 무관). ~1이면 본체가 직접 긁음(공정 자체가 잘못 설계됨) |
| **D99/D50** (span) | 꼬리 폭 지표. 4–5 이상이면 이봉 의심(§4.3) |
| **σ_ln** | 로그폭. 0.2 미만 = 단분산에 가까움 |
| **d_agg/d_c** (§7) | 응집체가 스크래치 임계를 넘는가 |

### 4.6 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| CV → 0 (완전 단분산) | 꼬리 개수 → 0, 스크래치 → 0 | 타당(이상적). 실제로는 오염·응집 기원의 꼬리가 CV와 독립으로 남는다 → **0으로 예측하는 것은 위험한 외삽** |
| D50 → 0 (모든 입자 미세화) | 꼬리도 함께 축소, N(d>d_c) → 0 | 타당하되 MRR도 함께 죽는다(§5) — 결함만 보고 최적화하면 안 되는 이유 |
| D50 → ∞ | 전 분포가 d_c 초과 → 스크래치가 개수 자체에 비례 | 타당하나 이 레짐은 "연마"가 아니라 "가공" |
| n → 0 (Δ 지수) | D99를 바꿔도 손상 불변 | "모른다"와 "효과 없다"를 구분해야 함 — FabSim이 이 구분을 코드에 명시적으로 넣어둔 점은 옳다 |

### 4.7 파라미터 분류

| 파라미터 | 분류 |
|---|---|
| D50 | **독립 측정 가능** (DLS/SEM) |
| D90 | **독립 측정 가능** (누적분포) |
| D99 | **원칙상 측정 가능하나 실무상 어렵다** — 개수 기준 D99를 재려면 꼬리를 통계적으로 유의하게 셀 만큼 큰 표본이 필요(단일입자 광산란/계수기 영역). 저장소가 D99를 "D50 × 일반비"로 **유도**하고 있는 것도 이 때문 |
| LPC(d_c 초과 개수) | **독립 측정 가능** (SPOS/광차단 계수기) — D99보다 이쪽이 물리적으로 옳은 축 |
| d_c | **피팅 필요** (계·공정 의존) |
| n (damage_exponent) | **피팅 필요** — 문헌값의 산포가 크고 화학종·막질별로 다름 |
| CV / σ_ln | **독립 측정 가능**하나 팩 스키마에 자리가 없음 |

### 4.8 FabSim 현 구현과의 차이

| 항목 | 현 구현 | 차이 |
|---|---|---|
| Δ 함수형 | `(D99/D99_ref)^n`, 기준에서 항등 1.0 | 개수축 선형 모델(물리적으로 옳은 축)이 아니다. FabSim의 노트가 이미 이 불일치를 기록해 뒀다 |
| 드라이버 | `abrasive_size_nm`을 Δ 드라이버에서 **제외**함(2026-09-13 스코프 축소) | 이 감사도 그 판단을 지지한다: §4.3의 민감도 계산이 "평균이 아니라 폭·꼬리"라는 같은 결론을 준다 |
| 분포 폭 | 팩에 CV/σ_ln 필드 **없음** — `abrasive_size_nm` 스칼라뿐 | §4.3에서 폭 민감도(+24.5)가 D50 민감도(+18.1)보다 크다는 것을 보였으므로 **가장 민감한 축이 스키마에 없는 상태**다 |
| D99 출처 | 대부분 "D50 × 일반비 5.00" 유도값 | §4.3의 역산이 그 일반비가 CV≈0.7을 함의함을 보인다 → 이봉 가정이 필요하고, 그렇다면 비례 유도의 근거가 약하다. **다만** FabSim은 Δ에서 D99/D99_ref **비율**만 쓰므로 유도값 불확실성이 출력을 오염시키지 않도록 설계돼 있다(이 방어선은 옳다) |
| LPC 축 | 없음 | `abrasive_lpc_per_ml` 신설이 물리적으로 옳은 방향 |
| Δ의 MRR 결합 | Δ는 MRR에 곱해지지 않음(진단 전용) | 옳다 — 대입자가 MRR을 올리지 않는다는 관측과 정합 |

## 5. 입자 농도 → 접촉 입자 수 · 면밀도 스케일링 · 포화

### 5.1 모델식과 기호표

**(a) 공급 면밀도** (세 가지 경쟁 가정 — 어느 것이 맞는지가 지수를 정한다)

```
(S1) 단층 가정:      간극 두께 ≈ d_p  ⇒  σ_supply = φ·d_p / (π d_p³/6) = 6φ/(π d_p²)  ∝ C / d_p²
(S2) 투영면적 가정:  단위면적당 개수를 부피농도의 2/3승으로  ⇒  σ_supply ∝ C^{2/3} / d_p²
(S3) 고정간극 가정:  간극 g 가 유체역학으로 정해져 d_p 와 무관  ⇒  σ_supply ∝ φ·g/d_p³ ∝ C / d_p³
```

**(b) 자리 점유(포화)**

```
n_s = 접촉 자리 수 ∝ A_r / d_p²        (자리 하나의 footprint ≈ 입자 단면)
λ   = C / C_h                          (자리당 평균 공급)
N_a = n_s · (1 − e^{−λ})               (포아송 점유)
또는 N_a = n_s · λ/(1+λ)               (Langmuir 점유)
```

**(c) 하중 분배**

```
F = χ · W / N_a + (1 − χ) · F₀
  χ = 1 : 완전 하중분배 (총 하중이 활성입자 수로 나뉨)
  χ = 0 : 패드 지지 (입자당 하중이 국소적으로 정해지고 개수와 무관)
```

**(d) 종합**

```
MRR ∝ N_a · Q₁ ,   Q₁ ∝ F^α · d_p^β
```

| 기호 | 의미 | 단위 |
|---|---|---|
| C | 입자 질량분율 (또는 φ 부피분율) | — (wt%) |
| C_h | 반포화 농도 | 같은 단위 |
| λ | 무차원 점유 파라미터 | — |
| n_s | 접촉 자리 면밀도 | m⁻² |
| N_a | 활성 입자 면밀도 | m⁻² |
| χ | 입자가 짊어지는 하중 분율 | — |
| α, β | 단일입자 법칙의 하중·크기 지수 | — |
| Q₁ | 입자 1개가 단위 슬라이딩당 제거하는 부피 | m³/m |

### 5.2 차원 검사

- σ_supply = 6φ/(π d_p²): [—]/[m²] = **m⁻²** ✓
- N_a = n_s·(1−e^{−λ}): m⁻²·무차원 = **m⁻²** ✓ (λ 무차원 ✓)
- F = χW/N_a: [N]/[m⁻²] = N·m² ✗ — **여기서 걸린다.** 올바른 형태는
  F = χ·(W/A_n)/N_a = χ·P/N_a: [Pa]/[m⁻²] = **N** ✓.
  본문의 W는 "단위 면적당 하중(=P)"으로 읽어야 한다. (스크립트에서는 W를 1로 정규화해
  이 구분이 지수 계산에 영향을 주지 않음을 확인했다.)
- MRR = N_a·Q₁: [m⁻²]·[m³/m] = **m** (단위 슬라이딩 거리당 두께) ✓ → ×V로 m/s ✓

### 5.3 (a) **농도 지수 n_C 의 레짐 판정 규칙** — 이 감사의 핵심 산출

문헌이 1/3(표면적 지배)과 4/3(압입 지배)로 갈리는 문제를, 특정 사례가 아니라
**3인자 분해**로 재구성한다. §5.1의 형태를 로그미분하면 **해석해**가 나온다:

```
n_C = p · (1 − α χ)                      p = 공급의 C 지수 (S1: 1, S2: 2/3)
n_d = − q · (1 − α χ) + β                q = 공급의 d 지수 (S1/S2: 2, S3: 3)
```

스크립트 §5b가 이 지도를 전수 계산했다(18개 조합):

| 공급 | 단일입자 법칙 | χ | n_C | n_d |
|---|---|---|---|---|
| S1 단층 C/d² | 소성 plowing Q₁∝F^1.5/d | 1.0 | **−0.500** | **+0.000** |
| S1 단층 C/d² | 소성 plowing | 0.0 | **+1.000** | −3.000 |
| S1 단층 C/d² | 탄성 접촉면적 Q₁∝F^{2/3}d^{2/3} | 1.0 | **+0.333** | −0.000 |
| S1 단층 C/d² | 탄성 접촉면적 | 0.0 | +1.000 | −1.333 |
| S1 단층 C/d² | 분자스케일 Q₁∝d^{0.5} (F 무관) | 1.0 / 0.0 | +1.000 | **−1.500** |
| S2 투영 C^{2/3}/d² | 소성 plowing | 1.0 | −0.333 | +0.000 |
| S2 투영 C^{2/3}/d² | 소성 plowing | 0.0 | +0.667 | −3.000 |
| S2 투영 C^{2/3}/d² | 탄성 접촉면적 | 1.0 | +0.222 | −0.000 |
| S2 투영 C^{2/3}/d² | 분자스케일 | 1.0 / 0.0 | +0.667 | **−1.500** |
| S3 고정간극 C/d³ | 소성 plowing | 1.0 | −0.500 | **+0.500** |
| S3 고정간극 C/d³ | 탄성 접촉면적 | 1.0 | +0.333 | −0.333 |

**판정 규칙 (농도)**

> **R-C1. 상한 정리 — 4/3은 이 분해에서 도달 불가능하다.**
> n_C = p(1−αχ) 이고 p ≤ 1, 0 ≤ (1−αχ) ≤ 1 이므로 **n_C ≤ 1이 구조적 상한**이다
> (스크립트가 18조합 전수 확인). 따라서 문헌의 "4/3(압입 지배)"는
> *같은 MRR = 개수 × 입자당 제거* 분해 안에서 나올 수 있는 지수가 아니다.
> 4/3이 나오려면 (i) 농도가 늘 때 자리 수 n_s 자체가 늘어나거나(하중 재분배로 실접촉면적이 증가),
> (ii) 농도를 단순 대리변수로 쓰는 다른 축(점도·화학종 농도)이 함께 변했거나,
> (iii) 원 도출이 φ와 C를 다른 정의로 썼거나 중 하나다.
> **→ 4/3을 쓰려면 그 근거를 위 셋 중 하나로 명시하라. 명시 못 하면 쓰지 마라.**

> **R-C2. 1/3은 "표면적"이 아니라 "탄성 접촉 + 완전 하중분배"의 서명이다.**
> 지도에서 n_C = +1/3을 내는 조합은 오직 α = 2/3(탄성 접촉면적 법칙) **및** χ = 1(완전 하중분배)
> **및** p = 1 뿐이다(스크립트 검증). 즉 1/3이 관측되면
> **"입자가 총 하중을 나눠 지고 있고, 제거가 탄성 접촉면적에 비례한다"**는 뜻이지,
> 표면적 자체와는 관계가 없다. 이름("표면적 지배")이 물리를 오도한다.

> **R-C3. 판정 순서 — 세 질문을 이 순서로 던진다.**
> ① **하중을 누가 지는가(χ)?** — 입자가 총 하중을 나눠 지면 χ→1, 패드 돌기가 지고 입자는
>   국소 하중만 받으면 χ→0. 진단: **압력을 올릴 때 반포화 농도 C_h가 함께 올라가는가**
>   (자리 수 n_s ∝ A_r ∝ P). 올라가면 자리-지배(χ 유효), 안 올라가면 공급-지배.
> ② **제거가 탄성인가 소성인가(α)?** — 입자당 접촉응력을 표면층 유효경도 H_s와 비교.
>   p_max ≳ H_s면 소성(α=1.5), p_max ≪ H_s면 탄성(α=2/3).
> ③ **공급이 단층인가 투영인가(p)?** — 간극/d_p 비. 간극 ≈ d_p면 S1(p=1),
>   간극 ≫ d_p로 여러 겹이면 유효 p가 1보다 작아진다.
> 이 셋이 정해지면 n_C = p(1−αχ)로 **지수가 계산된다** — 고르는 게 아니라.

> **R-C4. 그러나 "지수 하나"가 애초에 잘못된 질문일 수 있다.**
> 자리 점유 모델의 **국소 지수는 농도의 함수**다(스크립트 §5, 해석해):
> ```
> n_loc(λ) = λ e^{−λ} / (1 − e^{−λ})
> ```
> | λ = C/C_h | 점유율 θ | n_loc |
> |---|---|---|
> | 0.03 | 0.030 | 0.985 |
> | 0.1 | 0.095 | 0.951 |
> | 0.3 | 0.259 | 0.857 |
> | 1.0 | 0.632 | 0.582 |
> | 2.0 | 0.865 | 0.313 |
> | 3.0 | 0.950 | 0.157 |
> | 10 | 1.000 | 0.000 |
>
> **n = 1/3이 나오는 지점은 λ ≈ 1.90, 즉 자리의 85 %가 이미 찬 포화 진입부다.**
> λ→0에서 n_loc→1(엄격 선형), λ→∞에서 n_loc→0(완전 포화)이 해석적으로 확인된다.
> ⇒ **"n = 1/3"은 물리 상수가 아니라 "측정 창이 포화 무릎에 걸쳐 있었다"는 표지일 수 있다.**
> 실제로 같은 포화 곡선을 다른 농도창에서 회귀하면(스크립트 §5c):
> | 회귀 창 C/C_h | 겉보기 n |
> |---|---|
> | [0.01, 0.1] | +0.982 |
> | [0.1, 1] | +0.833 |
> | [0.3, 3] | +0.576 |
> | [0.5, 5] | +0.404 |
> | [1, 10] | +0.180 |
> | [3, 30] | +0.013 |
> **같은 물리에서 겉보기 지수가 0.98 → 0.01로 움직인다.** 지수를 인용할 때는
> **반드시 λ 범위를 함께 적어야 한다.**

> **R-C5. 음의 지수(과밀 레짐)는 χ가 만든다.**
> λ > 1에서 입자가 자리보다 많아지면 하중이 더 잘게 쪼개진다. 스크립트 §5c
> (C/C_h ∈ [2,20] 회귀):
> | χ (입자 하중분율) | 겉보기 n_C |
> |---|---|
> | 0.0 | +1.018 |
> | 0.2 | +0.951 |
> | 0.5 | +0.788 |
> | 0.8 | +0.410 |
> | 1.0 | **−0.509** |
> **n_C < 0은 χ가 1에 매우 가까울 때만 나온다.** 즉 문헌에서 고농도 음의 지수가
> 보고되는 계는 "입자가 사실상 하중을 전부 지고 있는" 계다. 이것이 판정 규칙이다 —
> 음의 지수를 보면 화학이 아니라 **하중 경로**를 의심하라.

### 5.4 포화가 나타나는 조건과 그 물리

```
C_h ∝ A_r / a_site ∝ P                    (자리 수가 실접촉면적에 비례)
```

**포화는 "입자가 부족해서"가 아니라 "자리가 부족해서" 온다.** 따라서:

- **포화 농도는 슬러리 상수가 아니라 압력(정확히는 실접촉면적)의 함수다.**
  압력을 올리면 자리가 늘어 포화가 늦어진다. 이 예측은 저장소 형제 노트가
  독립 데이터의 압력 축으로 확인했다(C_h가 압력에 단조 증가).
- **순수 멱함수는 어떤 지수를 써도 포화를 표현할 수 없다.** (C/C_ref)^n의
  "농도 2배 이득"은 2^n으로 농도와 무관하게 일정하다 — 기울기가 0으로 가지 않는다.
  포화를 담으려면 함수형 자체를 바꿔야 한다(포아송 또는 Langmuir).
- **저농도 극한(λ≪1)**: N_a ≈ n_s λ ∝ C, **압력 무관**. 자리는 남아돌고 공급이 율속.
- **고농도 극한(λ≫1)**: N_a → n_s ∝ A_r ∝ P, **농도 무관**. Preston의 P¹ 회복.
  이 두 극한이 한 식에서 나온다는 점이 포화형 모델의 가치다.
- **입자 고갈(starvation) 신호**: 저농도에서 압력을 올렸는데 MRR이 오히려 떨어지면
  "자리는 늘었는데 공급이 그대로라 자리당 점유율이 떨어진" 상태다 — λ = C/C_h(P)에서
  분모만 커진 경우. 이 이상점은 모델의 예측이자 진단 지표다.

### 5.5 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 자리마다 독립 포아송 도착 | 입자간 상호작용(정전·유체역학)이 있으면 도착이 상관됨 → Langmuir형이 나을 수 있고 둘의 중간 곡률은 데이터로만 구분 |
| 자리 footprint ≈ d_p² | 응집체·비구형에서 무효 |
| 간극이 입자 한 겹 | 다층이면 S1이 무효, 하중이 층간에 분배됨 |
| χ가 농도와 무관한 상수 | 실제로는 농도가 올라가며 입자가 하중을 더 많이 짊어짐 ⇒ **χ = χ(C)** 가 정직. 이것이 저농도 선형 → 고농도 음지수 전이의 진짜 메커니즘일 수 있다 |
| 모든 활성 입자가 같은 F를 받음 | PSD 폭이 넓으면 큰 입자가 하중을 독점(§4) |
| C(질량분율) ∝ φ(부피분율) | 밀도가 다른 계를 비교할 때 깨진다 — **지수를 다른 계로 옮길 때 반드시 C인지 φ인지 확인** |
| MRR = N_a × Q₁ (선형 중첩) | 궤적이 겹치면 이중 제거 |

### 5.6 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| C → 0 | 포화형: N_a → 0, MRR → 0 | **타당**. 멱함수 (C/C_ref)^n도 0으로 가지만 **미분이 발산**(n<1이면 dMRR/dC → ∞) — 저농도에서 비물리적으로 민감 |
| C → ∞ | 포화형: MRR → n_s (유한 상한) | 타당. 멱함수: MRR → ∞ **비타당** |
| C → ∞ + χ=1 | MRR 감소 | 타당(하중 분산) — 과밀 레짐 |
| P → 0 | C_h → 0, 즉 어떤 농도도 포화 | 타당(자리가 없음). 동시에 MRR → 0 |
| d_p → 0 (C 고정) | σ_supply ∝ 1/d_p² → ∞ | **비타당** — 입자가 간극에 못 끼거나(활성화 실패, §5.7) 브라운 운동이 접촉을 못 유지 |

### 5.7 (b) **입자 크기 지수 n_d 의 레짐 판정 규칙**

같은 3인자 분해가 **n_d = −q(1−αχ) + β** 를 준다. 문헌이 갈리는 세 답(d⁰, d^{−1.5}, 정점형)이
전부 이 지도 안에 있다:

| 관측 지수 | 이 지도에서의 조합 | 해석 |
|---|---|---|
| **d⁰ (무반응)** | S1/S2 공급 + χ=1 (소성이든 탄성이든) | **완전 상쇄**. 개수 감소(−q)와 입자당 제거 증가(+αqχ+β)가 정확히 지워짐. 우연이 아니라 구조적 |
| **d^{−1.5}** | S1/S2 공급(q=2) + 분자스케일 Q₁∝d^{0.5} (F 무관, α=0) | 하중 분배가 제거에 영향을 안 주는 계 |
| **d^{−3}** | S1 공급 + 소성 + χ=0 | 패드 지지, 하중 고정 |
| **d^{+0.5}** | S3 고정간극(q=3) + 소성 + χ=1 | 간극이 입경과 무관하게 정해지는 계 |

**판정 규칙 (크기)**

> **R-D1. 판정의 1차 분기는 "간극이 입경을 따라가는가"다.**
> - 간극 ≈ d_p (입자가 간극을 정함, S1) → q = 2 → χ=1이면 **n_d = 0**
> - 간극 g 가 유체역학/패드 변형으로 독립 결정(S3) → q = 3 → χ=1이면 **n_d = +0.5**
> 진단: 입경을 바꿀 때 마찰계수/유막 두께가 따라 변하는가. 변하면 S1, 안 변하면 S3.

> **R-D2. 정점(peak)형은 어떤 순수 멱함수 조합으로도 나오지 않는다 — 활성화 항이 필요하다.**
> 스크립트 §5b 전수 검사에서 n_d = +4/3을 내는 조합은 **없다**.
> 정점을 만들려면 **간극 g 를 넘는 입자만 하중을 받는다**는 활성화 조건이 있어야 한다:
> ```
> N_a = σ_supply(d) · P(d > g)      P(d>g) = 1 − Φ( ln(g/D50)/σ_ln )
> ```
> 이 항은 D50 ≪ g 에서 0으로 급감(활성 입자 없음), D50 ≫ g 에서 1로 포화(활성화 무의미).
> **두 극한 사이에 반드시 정점이 생긴다** — 감소하는 공급항(1/d²)과 증가하는 활성화항의 곱이기 때문.

> **R-D3. 정점의 위치는 재료가 아니라 간극이 정한다 — 계산으로 확인.**
> 스크립트 §5d (χ=0, CV=0.4, 대수정규 PSD):
> | 간극 g | 정점 D50 | D50/g |
> |---|---|---|
> | 30 nm | 26.8 nm | 0.89 |
> | 60 nm | 53.8 nm | 0.90 |
> | 120 nm | 108.2 nm | 0.90 |
> **정점은 항상 D50 ≈ 0.9·g 에 선다** — 간극에 정확히 비례한다. 재료 상수가 아니다.
> 분포 폭도 정점을 움직인다:
> | CV | χ=0 정점 (g=60 nm) | χ=1 정점 |
> |---|---|---|
> | 0.2 | 61.9 nm (1.03·g) | 12.0 nm (0.20·g) |
> | 0.4 | 51.6 nm (0.86·g) | 10.0 nm (0.17·g) |
> | 0.6 | 43.0 nm (0.72·g) | 10.0 nm (0.17·g) |
> **폭이 넓을수록 정점이 작은 쪽으로 이동한다**(꼬리가 먼저 활성화되므로).
> ⇒ **"정점 입경 = 슬러리 고유값"이라는 서술은 틀렸다.** 정점은 (간극, PSD 폭, 하중 경로)의 함수다.

> **R-D4. D50 ≫ g 극한에서 활성화 항이 소멸하고 순수 멱지수가 회복된다.**
> 스크립트 §5d 검증: n_d(χ=1) = **−0.000**(해석해 0), n_d(χ=0) = **−3.000**(해석해 −3).
> ⇒ **큰 입자 쪽 가지의 기울기가 하중 경로 χ를 직접 읽어준다.** 실측에서 대입경 쪽 기울기가
> 0에 가까우면 χ≈1(입자가 하중 분배), −3에 가까우면 χ≈0(패드 지지).
> 이것이 χ를 데이터에서 뽑는 실용 진단이다.

> **R-D5. 분포 폭이 고정되면(CV 일정) 꼬리 항은 정확히 1/d 이다.**
> (x+3σ)²/x³ 에 σ = CV·x 를 넣으면 (1+3CV)²/x — 스크립트가 CV = 0.1/0.2/0.3에서
> d 지수 = **−1.000000**(해석해)을 확인했다. 즉 "CV 일정" 가정 하에서는
> 분포 정보가 지수를 바꾸지 못하고 상수 배만 바꾼다. **CV가 입경에 따라 변할 때만
> 분포가 지수에 들어간다** — 원 문헌도 "if approximately constant"라고 조건부로 서술했다.

> **R-D6. 부호가 반대인 두 실측이 나오면 지수를 평균하지 마라.**
> 로그축 기울기의 산술평균은 물리적 의미가 없고, 부호가 다르면 서로 다른 레짐이다.
> R-D1~R-D4로 각 데이터가 어느 레짐인지 먼저 판정하고, **레짐이 다르면 분기하라**.

### 5.8 파라미터 분류

| 파라미터 | 분류 |
|---|---|
| C (또는 φ) | **독립 측정 가능** (고형분 측정) |
| C_h (반포화 농도) | **피팅 필요** — 자리 footprint 등 기하 상수를 지어낼 수 없음. 다만 **C_h ∝ P** 는 모델 예측이므로 한 압력에서 맞추면 다른 압력은 예측 |
| χ (하중 분율) | **피팅 필요**하나 **R-D4로 데이터에서 직접 읽을 수 있다**(대입경 가지 기울기) |
| α (하중 지수) | **판정 가능** — 접촉응력 vs H_s 비교로 탄성/소성 결정 |
| p, q (공급 지수) | **판정 가능** — 간극/d_p 관계로 결정 |
| g (간극) | **간접 측정 가능** (유막 두께/마찰) — 팩에 없음 |
| n_C, n_d | **유도값**이어야 한다 — 위 인자들이 정해지면 계산된다. **직접 피팅하는 것은 정보를 버리는 짓** |

| 항목 | 현 구현 (`sim/factors.py::_f_kappa`) | 차이 |
|---|---|---|
| 농도 함수형 | `(C/C_ref)^n`, 기본 n = 1/3 | **포화를 구조적으로 표현 못 한다**(§5.4). 코드 주석 자체가 이를 자인. 교체 후보: `M∞(P)·C/(C_h(P)+C)` 또는 `M∞(P)·(1−e^{−C/C₀(P)})` |
| 지수 근거 | 실측 전역 회귀 n≈0.30이 1/3과 부합 → 1/3 채택 | R-C4가 이를 재해석한다: **전역 회귀 n은 측정 창 위치의 함수**다. n≈0.3은 λ ∈ [0.5,5] 정도의 창을 의미할 뿐, 물리 상수가 아니다. 같은 슬러리를 더 낮은 농도에서 재면 n→1이 나온다 |
| 포화 처리 | `abrasive_saturation_wt_pct` 초과 시 **경고문만** 출력, 예측값은 계속 증가 | 코드가 "이 구간 예측은 과대평가"라고 자인. §5.4가 그 크기를 준다 |
| C_h의 압력 의존 | 없음(상수) | 모델 예측 C_h ∝ P가 반영 안 됨 → 저압에서 포화를 놓치고 고압에서 과도하게 꺾는다 |
| 입경 함수형 | 단일 멱함수 또는 piecewise 정점형(peak_nm, exp_below, exp_above) | piecewise 정점형은 **정점 위치를 팩 상수로 받는다**. R-D3에 따르면 정점은 (g, CV, χ)의 함수이므로 **압력·패드·분포가 바뀌면 정점도 움직여야 한다** — 현 구현은 이를 못 따라간다 |
| 하중 분배 χ | **모델에 없음** | R-C5·R-D4가 보이듯 χ가 농도·입경 지수의 **부호까지** 정한다. 가장 중요한 미구현 축 |
| 간극 g | **모델에 없음** | R-D2/R-D3의 정점 생성 메커니즘 자체가 부재 |
| PSD 폭 (CV) | **팩 스키마에 없음** | R-D3에서 정점 위치를 움직이는 인자 |
| 지수 0 처리 | 0을 "모른다"가 아니라 "검증된 영 결과"로 구분해 계상 | **옳다.** R-D1이 그 물리적 정체(구조적 상쇄)를 준다 |

## 6. 분산제 흡착 → 입체 장벽: 응집 억제와 제거율 저하의 트레이드오프

### 6.1 모델식과 기호표

**(a) 흡착 등온식** (피복률 → 사슬 밀도)

```
Langmuir:      θ = K C / (1 + K C)
Hill / Sips:   θ = (K C)^m / (1 + (K C)^m)      m > 1 이면 협동 흡착(S자 문턱)
                                                m = 1 이면 Langmuir로 정확히 환원
```

**(b) 입체 반발 — Alexander–de Gennes brush (평판-평판, 단위면적당)**

```
W(h) = (16 k_B T L) / (35 s³) · [ 7(2L/h)^{5/4} + 5(h/2L)^{7/4} − 12 ]     (h < 2L)
W(h) = 0                                                                   (h ≥ 2L)
```

**(c) Derjaguin 변환 → 구-구**

```
V_steric(h) = π a ∫_h^{∞} W(x) dx
```

**(d) 제거율 저하** (저장소가 이미 확립한 형식)

```
잔여율 = exp(−k θ)         ψ(C) = exp(−k[θ(C) − θ(C_ref)])   (기준 조건에서 항등 1.0)
```

| 기호 | 의미 | 단위 |
|---|---|---|
| θ | 표면 피복률 | — |
| K | 흡착 평형상수 | (농도)⁻¹ |
| m | Hill 협동성 지수 | — |
| L | 사슬 뻗침 길이(brush height) | m |
| s | 그래프트 점 간 평균 간격 | m |
| k | 피복 → 제거억제 결합상수 | — |

### 6.2 차원 검사 (스크립트 §6)

- W(h): [J]·[m]/[m³] = **J/m²** ✓ (대괄호 안은 무차원)
- Derjaguin: [m]·([J/m²]·[m]) = **J** ✓
- θ, exp(−kθ): 무차원 ✓ (K·C 가 무차원이어야 하므로 K는 농도의 역수 단위)

### 6.3 수치 검증과 DLVO와의 대비 (스크립트 §6, L=5 nm, s=2 nm, a=50 nm)

| h [nm] | W(h) [J/m²] | V_steric [k_BT] | V_vdW [k_BT] | 합 [k_BT] |
|---|---|---|---|---|
| 1.0 | 0.13239 | 5747.7 | −8.60 | 5739.1 |
| 2.0 | 0.047793 | 2722.5 | −4.30 | 2718.2 |
| 5.0 | 0.007216 | 379.6 | −1.72 | 377.8 |
| 8.0 | 0.00074752 | 18.1 | −1.08 | 17.0 |
| 9.9 | 1.5567e−06 | ~0 | — | — |
| 10.0 (=2L) | **정확히 0** | 0 | — | — |

**세 가지 판정용 서명:**

1. **유한 도달거리**: h ≥ 2L 에서 정확히 0. DLVO 반발이 exp(−κh)로 꼬리를 남기는 것과 달리
   입체 반발은 **칼같이 끊긴다**. 2L 밖에서는 존재하지 않는다.
2. **이온강도 무관**: 전하 없는 사슬이면 I를 아무리 올려도 장벽이 그대로다.
   ⇒ **"염을 넣었는데 안 응집하면 입체 안정화"** 라는 진단이 여기서 나온다.
   전해질 첨가 실험이 정전 안정화와 입체 안정화를 구분하는 결정적 시험인 이유.
3. **1차 최소 자체가 사라진다**: h ≤ L 영역에서 V_steric이 vdW를 3자릿수 압도한다.
   DLVO의 "장벽을 넘으면 비가역 응집"이라는 그림이 통째로 무효 — 입체 안정화는
   장벽을 높이는 게 아니라 **접촉 자체를 금지**한다.

### 6.4 트레이드오프의 물리 — 왜 안정성과 MRR이 대립하는가

입체 장벽은 **입자-입자**와 **입자-웨이퍼** 양쪽에 똑같이 작동한다. 이것이 트레이드오프의 뿌리다:

```
입자-입자 h_min ≥ 2L   ⇒ 응집 억제 (원하는 효과)
입자-웨이퍼 h_min ≥ L  ⇒ 입자가 표면에 L 이상 못 다가감 (원치 않는 효과)
                        ⇒ 유효 압입 깊이 δ_eff = max(0, δ_nominal − L)
                        ⇒ L 이 δ_nominal 급이면 MRR 이 0으로 붕괴
```

**정량 판정 규칙**:

> **R-S1.** 단일입자 압입 깊이 δ는 통상 **sub-nm ~ 수 nm** 스케일이고, brush 높이 L도
> 같은 스케일이다. 따라서 **L/δ 가 1을 넘는 순간 MRR이 급락한다.**
> 이것이 "분산제를 넣으면 안정성은 좋아지는데 제거율이 떨어진다"의 정체다.
>
> **R-S2. 트레이드오프를 피하는 유일한 방향은 L을 줄이면서 θ를 유지하는 것이다.**
> W(h) ∝ L/s³ 이므로 **짧은 사슬을 조밀하게**(작은 L, 작은 s) 붙이면
> 같은 반발 크기를 더 짧은 도달거리로 얻는다. 즉 설계 변수는 "분산제 농도" 하나가 아니라
> **(L, s) 두 개**이고, 농도는 그 중 s만 움직인다.
>
> **R-S3.** 흡착이 협동적(m > 1)이면 임계농도 부근에서 θ가 절벽처럼 오른다.
> 이 경우 **"조금 넣으면 효과 없고 조금 더 넣으면 MRR이 무너지는"** 급격한 공정창이 생긴다.
> m을 모르면 공정창 폭을 모른다.

### 6.5 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 사슬이 brush 레짐(s ≪ R_g) | 희박 그래프트(mushroom 레짐)에서는 AdG가 무효, 반발이 훨씬 약함 |
| 좋은 용매(good solvent) | 나쁜 용매(θ 용매 이하)에서는 사슬끼리 끌려 **입체 반발이 인력으로 뒤집힌다** — 온도·염 농도가 용매질을 바꾸므로 실재하는 위험 |
| 사슬이 표면에 고정(비탈착) | 압축 중 탈착하면 반발이 사라짐. 또 두 표면을 잇는 bridging flocculation(저피복률에서)은 **오히려 응집을 촉진** |
| 사슬 전하 없음 | 하전 고분자(polyelectrolyte)면 정전 + 입체 결합(electrosteric)이고 I 의존성이 부활 |
| 압축이 준정적(평형) | 고전단 CMP 접촉에서 사슬이 평형 배치를 유지할 시간이 있는지 미검증 |
| 흡착량 → 억제율이 단조 | 저장소 형제 노트가 **특정 첨가제 계열에서 이 상관이 문헌으로 반증됨**을 기록. 즉 흡착 등온식으로 MRR 억제를 모델링하는 것 자체가 계열에 따라 무효 |
| Derjaguin (h ≪ a) | L이 a와 겨루면(작은 입자 + 긴 사슬) 무효 |

| 무차원수 | 판정 |
|---|---|
| **2L/κ⁻¹** | ≫1: 입체가 정전보다 멀리 미침(입체 지배). ≪1: 정전 지배 |

## 7. 응집체의 유효 크기 — 1차 입자 vs 2차 입자

### 7.1 모델식과 기호표

```
질량-크기 프랙탈 관계:    N_p = k_f (d_agg / d_p)^{D_f}
  ⇒  d_agg = d_p · N_p^{1/D_f}                    (k_f ≈ 1 로 정규화)

응집체 내부 고형분율:      φ_int = N_p (d_p/d_agg)³ = N_p^{1 − 3/D_f}
유효(팽창) 부피분율:       φ_eff = φ · N_p^{3/D_f − 1} = φ / φ_int
2차 입자 개수 밀도:        n_agg = n_primary / N_p
응집체 유효 Hamaker:       A_eff ≈ φ_int² · A_bulk          (Vold 다공성 보정)
```

| 기호 | 의미 | 단위 |
|---|---|---|
| d_p | 1차 입자 직경 | m |
| d_agg | 응집체(2차 입자) 유효 직경 | m |
| N_p | 응집체당 1차 입자 수 | — |
| D_f | 질량 프랙탈 차원 (1 < D_f ≤ 3) | — |
| k_f | 프랙탈 접두인자 | — |
| φ_int | 응집체 내부 고형분율 | — |
| φ_eff | 유효 부피분율(고정 용매 포함) | — |

### 7.2 차원 검사

- d_agg = d_p·N_p^{1/D_f}: [m]·무차원 = **m** ✓
- φ_int = N_p^{1−3/D_f}: 무차원 ✓, 그리고 D_f=3에서 정확히 1 ✓ (스크립트 확인)
- A_eff = φ_int²·A_bulk: [—]·[J] = **J** ✓

### 7.3 수치 (스크립트 §7)

| D_f | N_p=5 | | N_p=10 | | N_p=100 | |
|---|---|---|---|---|---|---|
| | d_agg/d_p | φ_eff/φ | d_agg/d_p | φ_eff/φ | d_agg/d_p | φ_eff/φ |
| 1.8 (DLCA) | 2.445 | 2.924 | 3.594 | 4.642 | 12.915 | 21.544 |
| 2.1 (RLCA) | 2.152 | 1.993 | 2.994 | 2.683 | 8.962 | 7.197 |
| 2.5 | 1.904 | 1.380 | 2.512 | 1.585 | 6.310 | 2.512 |
| 3.0 (치밀) | 1.710 | 1.000 | 2.154 | 1.000 | 4.642 | 1.000 |

유효 Hamaker (N_p=10): D_f=1.8 → **A_eff ≈ 0.046·A_bulk**, D_f=2.5 → 0.398·A_bulk, D_f=3 → 1.000·A_bulk.

**읽는 법**: 성긴 응집체(낮은 D_f)는 크기는 크지만 **속이 비어 있어** 물리적으로 약하다 —
유효 Hamaker가 벌크의 5 %까지 떨어진다. 즉 "큰 응집체 = 강한 압입자"가 아니다.

### 7.4 어느 쪽이 MRR / 결함을 지배하는가 — 판정 규칙

> **R-A1. 개수 보존이 부호를 정한다.**
> 응집이 일어나도 **1차 입자 총수는 불변**이지만 **운반 단위(2차 입자) 개수는 1/N_p 배**로 줄고
> 각 단위의 크기는 N_p^{1/D_f} 배로 커진다. 따라서:
> - MRR이 **접촉 입자 개수** 지배(§5의 λ ≪ 1, 공급 율속) → **응집은 MRR을 낮춘다**
>   (자리에 도착하는 단위 수가 1/N_p로 감소)
> - MRR이 **입자당 압입** 지배(자리는 남아돌고 크기가 율속) → **응집이 MRR을 올릴 수 있다**
>   (d_agg 증가로 압입 단면 증가)
> **부호는 레짐이 정한다** — 응집이 MRR에 어느 방향으로 작용하는지는 재료가 아니라 §5의 λ, χ가 답한다.

> **R-A2. 결함(스크래치)은 항상 2차 입자가 지배한다 — 단, 파쇄를 통과한 경우에만.**
> 스크래치 임계 d_c는 통상 1차 입자 D50보다 훨씬 크므로(§4), 임계를 넘는 것은 응집체뿐이다.
> 그러나 응집체가 접촉 응력을 견디지 못하면 파쇄되어 1차 입자로 되돌아간다.
> **판정 기준**: 응집체 결합 강도 ≈ (A_H·d_p)/(12 h₀²)급 인력을 접촉 응력이 이기는가.
> D_f가 낮을수록 A_eff가 작고(위 표) 결합점 수가 적으므로 **성긴 응집체는 스크래치를 덜 만든다**.
> **치밀한 응집체(D_f→3)가 위험하다** — 이것이 "같은 응집 크기라도 위험도가 다르다"의 물리.

> **R-A3. 두 크기 축은 서로 다른 팩터에 들어가야 한다.**
> - **MRR 축(κ)**: 활성화·압입에 참여하는 유효 크기 = **d_agg**(파쇄 안 되면) 또는 d_p(파쇄되면)
> - **결함 축(Δ)**: **d_agg의 꼬리** — 응집체 크기 분포의 D99
> - **콜로이드 안정성 축(DLVO)**: **d_p**가 아니라 **d_agg와 A_eff** — 응집체끼리의 재응집은
>   다른 파라미터로 계산된다
> 하나의 `abrasive_size_nm` 스칼라로 세 축을 모두 대표하는 것은 구조적으로 불가능하다.

> **R-A4. φ_eff가 점도를 통해 되먹임한다.**
> 성긴 응집체는 용매를 가둬 유효 부피분율을 최대 20배 이상 부풀린다(위 표 D_f=1.8, N_p=100).
> 점도가 φ_eff에 급격히 의존하므로(Krieger–Dougherty류) **응집은 슬러리 점도를 올리고,
> 점도는 유막 두께 → 간극 g → §5의 활성화 조건을 바꾼다.**
> 즉 응집은 MRR에 직접 경로(크기·개수)와 간접 경로(점도→간극)로 **두 번** 작용한다.
> 이 되먹임은 이 감사 범위 밖이며 유체 축과 결합해야 한다.

### 7.5 유도 가정과 깨지는 조건

| 가정 | 깨지는 조건 |
|---|---|
| 단일 D_f (자기유사) | 작은 N_p(≲ 10)에서는 프랙탈 스케일링이 통계적으로 무의미 — "10개짜리 클러스터의 D_f"는 정의가 흐릿 |
| k_f = 1 | k_f는 실제로 D_f와 상관되고 1에서 벗어난다 → d_agg 절대값에 계통오차. **비율 축만 쓰라** |
| 응집체가 접촉 중 강체 | 파쇄·재배열(restructuring)로 D_f가 시간에 따라 증가(성긴 → 치밀) |
| N_p가 단일값 | 실제로는 응집수 분포가 있고, 그 분포의 꼬리가 §4의 결함 축을 지배 |
| Vold 보정 A_eff ≈ φ_int²A | 단순 유효매질 근사. 응집체 접촉이 국소적(점 접촉)이면 유효 A는 오히려 벌크에 가깝다 |
| 응집이 가역 | 1차 최소 응집은 비가역(§1.5) — 초음파 등 외부 에너지 없이는 안 풀림 |

### 7.6 무차원수

| 무차원수 | 판정 |
|---|---|
| **D_f** | ≈1.8 확산율속(DLCA, 장벽 없음, 급속) / ≈2.1 반응율속(RLCA, 장벽 있음, 느림) / →3 치밀(재배열 후) — **D_f 자체가 응집 기구의 진단값** |
| **N_p** | 응집도 |
| **d_agg/d_c** | 결함 임계 초과 여부(§4) |
| **d_agg/g** | 활성화 여부(§5.7 R-D2) |
| **φ_eff/φ** | 점도 되먹임 크기 |
| **접촉응력 / 응집체 강도** | ≳1이면 파쇄 → 1차 입자 축으로 회귀 |

### 7.7 극한 거동

| 극한 | 예측 | 타당성 |
|---|---|---|
| N_p → 1 | d_agg → d_p, φ_eff → φ | 타당(응집 없음) — 연속적으로 1차 입자 극한 회복 ✓ |
| N_p → ∞ | d_agg → ∞ | **비타당** — 실제로는 침강(중력 vs 브라운) 또는 전단 파쇄가 크기를 제한 |
| D_f → 3 | φ_eff → φ, A_eff → A_bulk | 타당(치밀 구) ✓ 스크립트 확인 |
| D_f → 1 | φ_eff → φ·N_p², A_eff → 0 | 수학적 극한. D_f=1은 직선 사슬 — 물리적으로 도달 불가하나 **A_eff→0의 방향은 옳다** |
| d_p → 0 (N_p 고정) | d_agg → 0 | 타당 |
| 접촉응력 → ∞ | 모델이 파쇄를 모름 | **비타당** — 파쇄 판정을 외부에서 넣어야 함 |

### 7.8 파라미터 분류

| 파라미터 | 분류 |
|---|---|
| d_p (1차 입자) | **독립 측정 가능** (SEM/BET 환산) |
| d_agg (2차 입자) | **독립 측정 가능** (DLS는 사실상 d_agg를 잰다 — SEM d_p와 DLS d의 차이가 곧 응집도 지표) |
| N_p | **유도값** (d_agg/d_p와 D_f로부터) |
| D_f | **독립 측정 가능** (정적 광산란 I(q) ∝ q^{−D_f}) — 그러나 CMP 실무에서 재는 일이 드묾 |
| k_f | **문헌값 차용** |
| φ_int, φ_eff, A_eff | **유도값** |
| 응집체 강도 / 파쇄 임계 | **피팅 필요** — 이 축의 가장 큰 공백 |

### 7.9 FabSim 현 구현과의 차이

| 항목 | 현 구현 | 차이 |
|---|---|---|
| 1차/2차 구분 | **없음** — `abrasive_size_nm` 스칼라 하나 | R-A3이 요구하는 세 축(κ의 유효 크기, Δ의 꼬리, DLVO의 d_agg) 분리 불가 |
| `aggregate_ratio` | Δ 팩터에 **키 자리만** 있고 팩에 선언되지 않음(선언 시에만 term 반영하도록 설계) | 자리를 만들어 둔 것은 옳다. 채울 물리가 이 §7이다: `aggregate_ratio = d_agg/d_p = N_p^{1/D_f}` |
| D_f / N_p | **없음** | 응집 기구(DLCA vs RLCA) 진단 불가 |
| φ_eff (점도 되먹임) | **없음** | R-A4의 이중 경로 미반영 |
| 파쇄 | **없음** | R-A2의 핵심 분기가 부재 |
| DLVO의 입력 크기 | `dlvo_colloid.py`가 반경 a를 받되 그것이 1차인지 2차인지 규약 없음 | 재응집 계산에는 d_agg + A_eff를 써야 하는데 이 구분이 문서화돼 있지 않다 |

## 8. 축 간 결합 — 이 문서가 발견한 5개의 미연결 고리

| # | 결합 | 현 상태 | 무엇이 빠졌나 |
|---|---|---|---|
| 1 | **이온강도 → 안정성 판정** | pH−IEP 거리만 봄 | 같은 pH에서 염을 넣으면 응집한다는 §1·§2의 물리가 판정에 없음 |
| 2 | **입자-웨이퍼 부호 반전 → 부착/MRR** | 웨이퍼 IEP를 받지만 "위험도에 반영 안 함"이라고 명시 | §3.3의 `min(IEP_p,IEP_w) < pH < max(...)` 규칙. **주의: 이 창에서 부착 위험과 접촉 확률(MRR)이 반대 방향**이라 단일 스칼라로 뭉개면 안 됨 |
| 3 | **하중 분배 χ → 지수의 부호** | 모델에 χ 개념 없음 | §5의 R-C5·R-D4. n_C, n_d의 **부호까지** χ가 정하는데 모델에 없다. 가장 큰 구조적 공백 |
| 4 | **간극 g → 정점 위치** | 정점을 팩 상수로 받음 | §5.7 R-D3: 정점 = 0.9·g. 압력·패드·점도가 바뀌면 정점도 움직여야 함 |
| 5 | **응집 → 점도 → 간극 → 활성화** | 없음 | §7 R-A4의 이중 경로. 유체 축과의 결합 필요 |

## 10. 이 감사가 제안하는 우선순위 (구현은 하지 않았다)

1. **χ(하중 분배 분율)를 모델에 도입** — §5의 R-C5·R-D4. 지수의 **부호**를 정하는 인자가
   모델에 없다. 그리고 R-D4가 이를 데이터에서 읽는 방법(대입경 가지 기울기)까지 준다.
   현재 팩이 지수를 상수로 박아 두는 것은 이 인자를 암묵적으로 고정하는 것과 같다.
2. **농도 함수형을 포화형으로 교체 + C_h ∝ P** — §5.4. 순수 멱함수는 포화를 담을 수 없고,
   코드 주석 자체가 이를 자인하고 있다.
3. **PSD 폭(CV/σ_ln)을 팩 스키마에 추가** — §4.3에서 꼬리 개수의 폭 민감도(+24.5)가
   D50 민감도(+18.1)를 넘는다. **가장 민감한 축이 스키마에 없다.**
4. **입자-웨이퍼 쌍의 IEP 곱 부호 판정** — §3.3. 웨이퍼 IEP를 이미 받고 있으면서

6. **이온강도를 팩 필드로** — §2.9. Debye 길이 코드는 정확한데 레시피 경로에 연결돼 있지 않다.
