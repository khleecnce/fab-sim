특별 지시: 선행: knowledge/cmp/cu-cmp-low-pressure-galvanic-corrosion-advanced-interconnect-review.md(film-cu 소유), knowledge/cmp/post-cmp-cleaning-chemistry-ammonia-citric-surfactant-corrosion.md, knowledge/cmp/post-cmp-defect-classification-and-inspection.md 를 먼저 읽고 상호링크하라. 네 focus는 "결함 관점"이다 — Cu/W 갈바닉·피팅 메커니즘 자체(film-cu·film-w 영역)를 재서술하지 말고, (a) 부식 결함의 형상·크기·밀도(피트 직경 nm, 개수/wafer) 정량, (b) 슬러리 화학 변수(pH·산화제 농도·BTA 등 억제제 농도·Cl⁻ 오염)→피트/부식 결함 밀도의 정량 관계(문헌 실측 표·그래프), (c) 부식 결함과 스크래치/잔류입자 결함의 구별 신호(검사 채널·형상)를 확보하라. Pourbaix·혼합전위 수식이 있으면 python verify로 재현(Faraday 환산 등). 정량값이 미검증의 2배 이상이 되도록.

절차:
1. cd /Users/khleecnce/fab-sim 후 .venv/bin/python tools/scope.py --agent defect-scientist --queries 로 허용 검색어 확인. 이 검색어와 그 변형만 써라. 필요하면 tools/scope.py --agent defect-scientist --check 제목 으로 사용가능 여부 확인. enabled=false 소스(블로그/포럼/모델기억) 인용 금지. focus 벗어나지 말고 형제 에이전트 영역 침범 금지. max_sources_per_unit 상한 지켜라.
2. 웹검색, arXiv, 오픈액세스, 대학 강의자료를 전부 쓴다. 유료 논문은 미러 사이트 에서 DOI로 받아 읽어라. tools/find_open_access.py --paywall 제목 로 원문 확보(OA 실패시 미러 사이트 자동 폴백). 받은 PDF는 papers/ 에 저장하고 papers/INDEX.json 에 등록.
3. knowledge/분야/주제.md 에 지식노트 작성. 기존 노트 형식을 그대로 따라라. 본보기 노트: knowledge/materials/hertz-gw-contact-mechanics.md, knowledge/cmp/preston-luo-dornfeld-mrr.md 를 먼저 읽어라.
4. 출처를 반드시 명시(저자·연도·논문명·DOI·URL). 1차 논문 못 구하면 2차 인용 이라고 명시, 확인 못 한 수치는 미검증 으로 표기. 확신하는 척 금지.
5. 기존 노트와 상호링크(대괄호 두겹 링크)로 연결. 고립 노트 금지.
6. 수식·수치 주장은 반드시 python verify 블록으로 넣어라. 세개의 백틱 뒤에 python verify 라고 쓴 코드블록을 tools/verify_claims.py 가 실제 실행한다. 문헌값을 코드 안 상수로 박고 계산결과와 assert 로 대조하라. 서술이 아니라 assert 가 증거다. 안 맞으면 안 맞는 대로 assert 쓰고 노트에 몇 퍼센트 차이·원인 미상 이라 적어라.
7. DOI/PMC/arXiv 는 실존해야 한다(Crossref/NCBI/arXiv API 로 조회됨). 기억으로 DOI 쓰지 마라. 도구가 준 DOI만 써라. 저자·연도·제목 지어내지 마라.
8. EXAMS.md 에 자기시험 3문항 + 모범답안 추가.
9. 자가검사(커밋 전 필수): .venv/bin/python tools/verify_claims.py 노트경로 와 .venv/bin/python tools/check_knowledge.py 노트경로 둘 다 통과할 때까지 보완하라.
10. 둘 다 통과하면 agents/defect-scientist/PROFILE.md 에 이수기록, agents/defect-scientist/CURRICULUM.md 체크박스를 [x] 로 갱신.

12. 근거 충돌시 EVIDENCE-RULES.md 서열로 판정하고 진행. 상반된 두 지수를 평균내지 마라.
