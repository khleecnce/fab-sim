# 완료 정의 (2026-09-15 개정)

## 무엇을 만들고 있는가

**어떤 슬러리든 넣으면 모델식이 나오는 절차.** 특정 슬러리의 모델이 아니다.

## 모델식이 책임지는 것 / 데이터가 책임지는 것

이 경계가 이 문서의 핵심이다. 섞으면 시뮬레이터가 회귀식이 된다.

### 모델식의 책임 — 구조(shape)

| 항목 | 예 | 어디서 나오는가 |
|---|---|---|
| 함수 형태 | 단봉형 / 로그선형 / 창(window) | 물리 유도 |
| 지수 | `n_C = p(1−αχ)` | 접촉역학에서 **계산** |
| 부호 | 농도↑ → 제거율↑ 인가 ↓ 인가 | 레짐 판정 |
| 게이트 | "이 조건에서는 이 항을 끈다" | 메커니즘의 적용 한계 |
| 정점 위치 | `C* = K_sat·(2/e_H − 1)` | 물성에서 **계산** |

**판정 기준: 이것들은 데이터로 맞추지 않는다.** 데이터가 안 맞으면
구조가 틀린 것이고, 구조를 고쳐야 한다 — 계수를 돌려 맞추면 안 된다.

### 데이터의 책임 — 축척(scale)과 국소 보정

| 항목 | 왜 데이터여야 하는가 |
|---|---|
| Kp (Preston 계수) | 장비·측정계마다 다르다. 원리적으로 그 계에서 역산하는 값이다 |
| 계열별 축척 | 같은 물리라도 장비가 다르면 배율이 다르다 (실측 0.004~53.8배) |
| 재료쌍 상수 | ΔG_ads 는 "억제제×기질 쌍"의 성질이다 |

## 완료 판정 (개정)

### ✅ 달성 기준 — 경향성

| 지표 | 기준 | 현재 |
|---|---|---|
| 순위상관 ρ (유의 데이터셋) | ≥ 0.90 | **+0.951** |
| 쌍별 적중률 | ≥ 90 % | **96.9 %** |
| clean held-out ρ | ≥ 0.90 | **+0.992** |
| 물리 위생 심각 위반 | 0 건 | 0 건 |

### ⚠ 달성하지 않기로 한 기준 — 절대값 3 %

**왜 내렸는가.** 절대 MRR 은 Kp 에 비례하고 Kp 는 그 계에서 역산되는 값이다.
고객 실측 없이 절대값을 3 % 로 맞추는 것은 원리적으로 불가능하며,
억지로 맞추면 (a) 계열마다 다른 보정항이 붙고 (b) 그 보정항은 물리가 아니라
그 데이터셋의 지문이 된다. 그 순간 시뮬레이터가 아니라 회귀식이다.

실측 근거: 계통편향이 데이터셋마다 **0.004 ~ 53.8 배**로 흩어진다.
이 폭은 모델 결함이 아니라 장비·측정계·시편 크기의 차이다.

### ✅ 대신 채택한 기준 — 데이터로 좁혀지는가

절대값은 **고객이 자기 데이터를 넣으면** 좁혀져야 한다. 그것이 제품 기능이다.

| 지표 | 기준 |
|---|---|
| 계열 축척 보정 후 형상오차 | 데이터 투입에 따라 **단조 감소** |
| 신규 계열 1점 투입 후 절대오차 | ≤ 30 % (1점으로 축척만 맞춤) |
| 신규 계열 5점 투입 후 | ≤ 15 % |
| 과적합 게이트 | 전 구간 통과 유지 |

**핵심: 성능이 아니라 "데이터를 넣으면 나아지는가"를 잰다.**

## 과적합 방지 — 데이터를 넣을수록 위험해진다

데이터가 늘면 맞추고 싶은 유혹도 는다. 다음을 강제한다.

1. **구조는 잠근다.** 캘리브레이션은 축척·재료쌍 상수만 건드린다.
   지수·함수형·게이트는 데이터로 바꾸지 않는다.
2. **자유도 예산.** 조건 수 ÷ 자유 파라미터 ≥ 10 을 유지한다.
3. **식별 가능성.** 미지수끼리 상관 ≥ 0.9 면 그 쌍은 분리 불가로 기록하고
   데이터로 풀지 않는다 (독립 측정을 요구한다).
4. **held-out 격리.** 캘리브레이션에 쓴 데이터는 성능 주장에서 제외한다.
5. **일반화 격차 감시.** 캘리브레이션 ρ 와 held-out ρ 의 차가 벌어지면
   지표가 올라도 실패로 판정한다.

## 이 문서를 고치는 조건

완료 정의를 바꾸는 것은 목표를 바꾸는 것이다. 다음일 때만 고친다.
- 사용자가 명시적으로 범위를 다시 지시했을 때
- 원리적 불가능성이 **측정으로** 밝혀졌을 때 (이번 절대값 3 % 가 그 경우)

지표가 안 나온다는 이유로 기준을 낮추는 것은 금지한다.
