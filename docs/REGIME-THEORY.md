# 연마입자 레짐 이론 — 지수를 고르지 않고 계산하는 법

이 문서는 FabSim 이 **연마입자 농도 지수 n_C 와 입경 지수 n_d 를 어떻게 계산하는지**
설명한다. 대상 독자는 새 슬러리를 시뮬레이터에 넣으려는 사용자다.

읽고 나면 다음을 할 수 있다.

- 내 계에서 n_C, n_d 가 얼마여야 하는지 **세 가지 물성 질문**으로 답한다.
- 계산된 지수가 이상할 때 **어느 입력이 틀렸는지** 역추적한다.
- 문헌에서 가져온 지수를 **인용해도 되는지** 판정한다.

> **이 문서의 서술 규약**
> 모든 판단 기준은 측정 가능한 물리량으로만 쓴다. 특정 연마입자·막질·제품·공정
> 조건은 등장하지 않는다. 어느 슬러리로 바꿔도 문장이 그대로 성립해야 하며,
> 성립하지 않으면 그 문장이 틀린 것이다.

---

## 1. 문제 — 지수는 왜 지금까지 사람이 적어 넣었나

제거율 모델에는 연마입자 농도 C 와 입경 d 의 의존성이 들어간다. 관행적인 형태는
순수 멱함수다.

```
MRR ∝ (C / C_ref)^n_C · (d / d_ref)^n_d
```

여기서 n_C, n_d 는 팩마다 사람이 숫자로 적어 넣는 값이었다. 그 숫자의 근거는
**그 슬러리에서 회귀한 결과**다. 즉:

| 항목 | 관행 | 문제 |
|---|---|---|
| 지수의 출처 | 해당 계의 실측 회귀 | 사후 설명이지 예측이 아니다 |
| 새 계로 이식 | 사람이 다시 정해야 함 | 데이터가 없으면 시작조차 못 한다 |
| 조건 외삽 | 같은 지수를 그대로 씀 | 레짐이 바뀌면 부호까지 틀린다 |

문헌도 갈린다. 농도 지수는 1/3(흔히 "표면적 지배"라 불림)과 4/3("압입 지배")로,
입경 지수는 0, 음수, 정점형으로 보고된다. 사용자 입장에서는 **어느 쪽을 쓸지
고를 근거가 없다.**

이 문서의 주장은 이렇다. **지수는 고르는 값이 아니라 계산되는 값이다.**
갈리는 답들은 서로 다른 이론이 아니라, 같은 분해 안의 서로 다른 레짐이다.

## 2. 분해 — 제거율을 두 인자로 쪼갠다

출발점은 하나의 항등식이다.

```
MRR ∝ N_a · Q₁
```

| 기호 | 의미 | 단위 |
|---|---|---|
| N_a | 실제로 접촉해 일하는 활성 입자의 면밀도 | m⁻² |
| Q₁ | 입자 하나가 단위 슬라이딩 거리당 제거하는 부피 | m³/m |
| F | 입자 하나가 받는 하중 | N |
| C | 입자 농도(질량분율 또는 부피분율) | — |
| d | 입자 직경 | m |
| P | 명목 압력 | Pa |
| A_r | 실접촉면적 | m² |

여기에 세 개의 구성식을 넣는다.

**(a) 공급 — 개수가 농도·입경을 어떻게 따라가는가**

```
N_a ∝ C^p / d^q
```

**(b) 단일입자 법칙 — 입자 하나의 제거가 하중·크기를 어떻게 따라가는가**

```
Q₁ ∝ F^α · d^β
```

**(c) 하중 경로 — 총 하중이 입자들에게 나뉘는가**

```
F = χ · (P / N_a) + (1 − χ) · F₀

  χ = 1 : 완전 하중분배 — 총 하중이 활성 입자 수로 나뉜다.
          입자가 늘면 입자당 하중이 줄어든다.
  χ = 0 : 지지체 부담 — 입자당 하중이 국소적으로 정해지고 개수와 무관하다.
```

세 식을 합쳐 log 미분하면 **닫힌 해석해**가 나온다. 근사도 피팅도 없다.

```
    n_C = p · (1 − α·χ)
    n_d = − q · (1 − α·χ) + β
```

이 두 줄이 이 문서의 전부다. 나머지는 오른쪽 항들을 물성에서 읽어내는 절차와,
그 결과를 해석하는 규칙이다.

**왜 (1 − αχ) 인가.** 농도를 올리면 입자 수가 p 만큼 늘지만(+p), 하중이 나뉘면
입자당 제거가 αχ 만큼 줄어든다(−p·αχ). 순증가는 그 차이다. χ=0 이면 상쇄가
없어 n_C = p 로 최대가 되고, χ=1 이고 α 가 클수록 상쇄가 커져 n_C 가 작아지거나
음수가 된다.

## 3. 절차 — 세 가지 질문

지수를 얻으려면 세 가지 물성 질문에 답한다. 각 질문은 **입력 → 판단 기준 → 출력**
형식이며, 판단 기준에 물질명이 없다.

구현: `sim/abrasive_mechanics.py` (절차) · `sim/regime_adapter.py` (팩 물성 → 자동 응답)

### 3.1 질문 ① — 하중을 누가 지는가 (χ)

| 항목 | 내용 |
|---|---|
| **입력** | 명목 압력, 실접촉면적의 압력 의존 지수 m (A_r ∝ P^m), 접촉 자리 밀도 |
| **판단 기준** | 압력을 올릴 때 접촉 자리 수가 함께 늘어나는가.<br>m → 1: 자리가 비례해 늘어난다 → 하중이 입자들에게 재분배된다 → **χ → 1**<br>m → 0: 자리 수가 고정이다 → 지지체 돌기가 하중을 지고 입자는 국소 하중만 받는다 → **χ → 0** |
| **출력** | χ ∈ [0, 1] |

**왜 이 진단인가.** 입자가 총 하중을 나눠 지는지는 직접 관측할 수 없다. 대신
압력을 올렸을 때 접촉 자리가 함께 늘어나는지를 본다 — 늘어난다면 하중이 입자들에게
재분배되고 있다는 뜻이다. χ 는 관측량 m 의 대리 추정이다.

**돌기 높이 분포가 m 을 정한다.** 돌기 높이가 지수분포로 근사되는 거친 표면에서는
실접촉면적이 하중에 정확히 선형이고 분리거리와 무관하다(Greenwood–Williamson 모델의
해석적 결과). FabSim 은 GW 수치적분으로 이를 독립 확인했다: **A_r ∝ P^1.0000 → χ = 1.000**.
가우시안 분포에서는 완전 선형이 아니며 m 이 1 보다 약간 작고 분리거리에 의존한다.

**모르면 판정하지 않는다.** m 이 없으면 χ 는 "미판정"으로 남고 근거 등급이 내려간다.
χ 는 n_C 와 n_d 의 **부호까지** 정하므로, 모르는 채 기본값을 놓으면 경향이 반대로 나온다.

### 3.2 질문 ② — 제거가 탄성인가 소성인가 (α, β)

| 항목 | 내용 |
|---|---|
| **입력** | 입자당 접촉 응력 σ, 제거되는 표면층의 유효 경도 H_s |
| **판단 기준** | 비 σ/H_s.<br>σ/H_s ≳ 1 → 소성 압입 레짐<br>σ/H_s ≪ 1 → 탄성 접촉 레짐<br>그 사이 → 전이 구간. 단일 법칙이 성립하지 않는다 |
| **출력** | (α, β) 한 쌍 |

**α 와 β 는 짝이다. 따로 고르면 물리가 깨진다.**

| 레짐 | 단일입자 법칙 | α | β |
|---|---|---|---|
| 소성 압입 | Q₁ ∝ F^1.5 / d | 3/2 | −1 |
| 탄성 접촉 | Q₁ ∝ F^(2/3) · d^(2/3) | 2/3 | +2/3 |
| 분자 스케일 | Q₁ ∝ d^0.5 (하중 무관) | 0 | +1/2 |

**면적 기준을 섞지 마라 — 이 계산이 틀리는 가장 흔한 방식이다.**
실접촉 압력은 실접촉면적 기준이고, 자리 밀도는 명목면적 기준이다. 둘을 그대로
나누면 단위는 맞지만 물리가 어긋나 자릿수가 크게 틀린 값이 나온다. 명목면적
1 m² 기준으로 통일해 따라간다.

```
총 하중            W_tot = P_nom
접촉 자리 수        N_c   = (자리 밀도)
자리당 하중        W_c   = W_tot / N_c
자리 하나의 실면적  A_c   = (실접촉면적비) / N_c
자리당 입자 수     k     = A_c / (입자 단면적)
입자당 하중        F_p   = W_c / k
입자 접촉응력      σ     = F_p / (입자 단면적) = W_c / A_c
```

마지막 등식이 말하는 바: **단층·완전피복 가정에서 입자가 받는 응력은 그 자리의
실접촉 압력과 같다.** 입자가 자리를 고르게 채우면 응력이 그대로 전달되기 때문이다.
피복률이 1 보다 작으면 응력은 그 비만큼 커진다.

**⚠ 표면층 유효 경도는 벌크 경도가 아니다.** 제거되는 것은 화학적으로 변질된 얇은
층이고, 그 층의 경도는 벌크보다 낮다. 이 값의 절대치는 공개 문헌에서 확보되지 않았으며,
FabSim 지식 감사가 지목한 최대 병목이다.

**절대값 없이도 한쪽 방향은 확정된다.** 필요한 것은 경도의 절대값이 아니라 접촉응력과의
대소 관계다. 변질층은 정의상 벌크보다 무르므로 H_s ≤ H_bulk 가 절대값 없이 성립한다.
따라서:

```
σ ≥ H_bulk        →  H_s 는 그보다 작으므로 **소성 확정**
σ ≪ H_bulk        →  확정 불가 (변질층이 얼마나 무른지 모른다)
```

이 부등식이 허용하는 만큼만 결론낸다. "벌크로 대체"가 아니라 **한 방향으로만
확정하고 반대쪽은 보류**하는 것이다.

### 3.3 질문 ③ — 공급이 단층인가 다층인가 (p, q)

| 항목 | 내용 |
|---|---|
| **입력** | 접촉 간극 g, 입자 직경 d |
| **판단 기준** | 비 g/d.<br>g/d ≈ 1 → 단층. 입자 한 겹이 간극을 채운다 → **p = 1, q = 2**<br>g/d ≫ 1 → 다층. 여러 겹 중 일부만 접촉에 참여한다 → **유효 p < 1**<br>간극이 입경과 무관하게 정해지는 계 → **q = 3** |
| **출력** | (p, q) |

세 가지 공급 가정이 경쟁하며, 어느 것이 맞는지가 지수를 정한다.

```
(S1) 단층      : 간극 ≈ d        ⇒  N_a ∝ C / d²          (p=1, q=2)
(S2) 투영면적  : 부피농도의 2/3승 ⇒  N_a ∝ C^(2/3) / d²    (p=2/3, q=2)
(S3) 고정간극  : g 가 d 와 무관   ⇒  N_a ∝ C / d³          (p=1, q=3)
```

**S1 과 S3 를 가르는 진단:** 입경을 바꿀 때 마찰계수나 유막 두께가 따라 변하는가.
변하면 입자가 간극을 정하는 것이므로 S1, 변하지 않으면 간극이 독립 결정되므로 S3.

다층에서 접촉 참여 분율이 겹 수에 반비례한다고 보면 p_eff = (g/d)^(−1/3) 꼴이 된다.
이 감쇠 형태는 **기하 논증이며 문헌 폐형식이 아니다** — 근거 등급을 낮춰 신고한다.

## 4. 검증된 결과

전수 탐색(공급 가정 × 단일입자 법칙 × χ 조합)과 수치 검증으로 확인된 사실들이다.
검증 코드: `tools/test_abrasive_mechanics.py`, `tools/test_new_slurry_intake.py`

### 4.1 n_C ≤ 1 은 구조적 상한이다

n_C = p(1 − αχ) 에서 p ≤ 1 이고 0 ≤ (1 − αχ) ≤ 1 이므로 **n_C 는 1 을 넘을 수 없다.**
전수 조합 검사로 확인했다.

**따라서 문헌의 "4/3"은 이 분해 안에서 도달 불가능하다.** 4/3 을 쓰려면 다음 셋 중
하나를 명시해야 한다.

1. 농도가 늘 때 접촉 자리 수 자체가 늘어난다(하중 재분배로 실접촉면적이 증가).
2. 농도를 대리변수로 쓰는 다른 축(점도, 화학종 농도 등)이 함께 변했다.
3. 원 도출이 질량분율과 부피분율을 다른 정의로 썼다.

**셋 중 하나를 명시하지 못하면 쓰지 마라.**

FabSim 은 계산된 n_C 가 1 을 넘으면 "입력이 모순"이라고 신고한다 — 조용히 클램프하지
않는다. 상한 위반은 결과가 아니라 **입력 오류의 신호**다.

### 4.2 1/3 은 "표면적 지배"가 아니다

지도에서 n_C = +1/3 을 내는 조합은 **오직 하나**다.

```
α = 2/3 (탄성 접촉)  AND  χ = 1 (완전 하중분배)  AND  p = 1 (단층 공급)
```

즉 n_C = 1/3 이 관측되면 그 뜻은 **"입자가 총 하중을 나눠 지고 있고, 제거가 탄성
접촉면적에 비례한다"**이지, 표면적과는 아무 관계가 없다. **관행적 이름이 물리를
오도해 왔다.**

실용적 함의: 1/3 을 관측했다면 그 계는 χ ≈ 1 이다. 따라서 같은 계의 **입경 지수는
0 에 가까워야 한다**(§4.4). 그렇지 않다면 둘 중 하나의 판정이 틀렸다.

### 4.3 음의 지수는 하중 경로가 만든다

C/C_h ∈ [2,20] 의 과밀 구간에서 겉보기 n_C 는 χ 에 따라 이렇게 움직인다.

| χ (입자 하중분율) | 겉보기 n_C |
|---|---|
| 0.0 | +1.018 |
| 0.2 | +0.951 |
| 0.5 | +0.788 |
| 0.8 | +0.410 |
| 1.0 | **−0.509** |

**n_C < 0 은 χ 가 1 에 매우 가까울 때만 나온다.** 고농도에서 음의 농도 의존이
관측되는 계는 "입자가 사실상 하중을 전부 지고 있는" 계다.

**판정 규칙: 음의 지수를 보면 화학이 아니라 하중 경로를 의심하라.**

### 4.4 입경 지수의 갈리는 답들은 모두 같은 지도 안에 있다

| 관측 지수 | 조합 | 해석 |
|---|---|---|
| **d⁰ (무반응)** | q=2 공급 + χ=1 (탄성이든 소성이든) | **구조적 완전 상쇄.** 개수 감소(−q)와 입자당 제거 증가(+αqχ+β)가 정확히 지워진다. 우연이 아니다 |
| **d^(−1.5)** | q=2 공급 + 분자 스케일(α=0) | 하중 분배가 제거에 영향을 주지 않는 계 |
| **d^(−3)** | q=2 공급 + 소성 + χ=0 | 지지체 부담, 하중 고정 |
| **d^(+0.5)** | q=3 고정간극 + 소성 + χ=1 | 간극이 입경과 무관하게 정해지는 계 |

**대입경 쪽 기울기가 χ 를 직접 읽어준다.** 큰 입자 가지에서 기울기가 0 에 가까우면
χ ≈ 1, −3 에 가까우면 χ ≈ 0. 이것이 χ 를 데이터에서 뽑는 가장 실용적인 진단이다.

**정점(peak)형은 어떤 순수 멱함수 조합으로도 나오지 않는다.** 정점을 만들려면
"간극을 넘는 입자만 하중을 받는다"는 **활성화 항**이 필요하다.

```
N_a = (공급 면밀도) · P(d > g)
```

이 항은 중앙 입경 ≪ g 에서 0 으로 급감하고 중앙 입경 ≫ g 에서 1 로 포화한다.
감소하는 공급항과 증가하는 활성화항의 곱이므로 **두 극한 사이에 반드시 정점이 생긴다.**

**정점 위치는 재료가 아니라 간극이 정한다.** 수치 검증에서 정점은 항상
**중앙 입경 ≈ 0.9·g** 에 섰고, 간극에 정확히 비례했다. 분포 폭이 넓을수록 정점은
작은 쪽으로 이동한다(꼬리가 먼저 활성화되므로).

**⇒ "정점 입경 = 슬러리 고유값"이라는 서술은 틀렸다.** 정점은 (간극, 분포 폭, 하중 경로)의
함수이며, 압력·지지체·분포가 바뀌면 정점도 움직인다.

### 4.5 지수는 물리 상수가 아니라 측정 창의 함수다

이것이 이 이론의 가장 중요한 한계이자, 이론이 스스로에게 가하는 제약이다.

자리 점유가 포화하면 겉보기 지수가 농도에 따라 움직인다.

```
N_a = n_s · (1 − exp(−λ)),        λ = C / C_h
n_loc(λ) = λ·exp(−λ) / (1 − exp(−λ))
```

| λ = C/C_h | 점유율 | 국소 지수 n_loc |
|---|---|---|
| 0.03 | 0.030 | 0.985 |
| 0.1 | 0.095 | 0.951 |
| 0.3 | 0.259 | 0.857 |
| 1.0 | 0.632 | 0.582 |
| 2.0 | 0.865 | 0.313 |
| 3.0 | 0.950 | 0.157 |
| 10 | 1.000 | 0.000 |

같은 포화 곡선을 다른 농도 창에서 회귀하면:

| 회귀 창 C/C_h | 겉보기 n |
|---|---|
| [0.01, 0.1] | +0.982 |
| [0.1, 1] | +0.833 |
| [0.3, 3] | +0.576 |
| [0.5, 5] | +0.404 |
| [1, 10] | +0.180 |
| [3, 30] | +0.013 |

**같은 물리에서 겉보기 지수가 0.98 → 0.01 로 움직인다.**

함의는 세 가지다.

1. **단일 지수를 쓰는 것 자체가 근사다.** 포화 농도를 아는 계에서는 점유 모델을
   직접 쓰는 편이 옳다. FabSim 은 둘 다 제공한다.
2. **지수를 인용할 때는 반드시 λ 범위를 함께 적어야 한다.** λ 없는 지수 인용은
   정보가 아니다.
3. n = 1/3 이 나오는 지점은 λ ≈ 1.9, 즉 **자리의 85 % 가 이미 찬 포화 진입부**다.
   "1/3"이 여러 보고에서 반복되는 이유는 물리 상수여서가 아니라, 실용 농도 창이
   흔히 포화 무릎에 걸치기 때문일 수 있다.

**포화는 입자가 부족해서가 아니라 자리가 부족해서 온다.** 따라서 포화 농도는 슬러리
상수가 아니라 압력(정확히는 실접촉면적)의 함수다: C_h ∝ P. 압력을 올리면 자리가 늘어
포화가 늦어진다. 한 압력에서 C_h 를 맞추면 다른 압력은 **예측된다.**

**순수 멱함수는 어떤 지수를 써도 포화를 표현할 수 없다.** (C/C_ref)^n 의 "농도 2배
이득"은 2^n 으로 농도와 무관하게 일정하며, 기울기가 0 으로 가지 않는다. 포화를
담으려면 함수형 자체를 바꿔야 한다.

## 5. 해보기 — 세 가지 계산 예

전부 일반 변수로만 쓴다. 어느 슬러리에도 그대로 적용된다.

### 예 1 — 거친 지지체 + 낮은 접촉응력 + 단층 공급

| 질문 | 입력 | 판정 | 출력 |
|---|---|---|---|
| ① 하중 경로 | 돌기 높이 분포 ≈ 지수분포 → A_r ∝ P^1.00 | 자리 지배 | χ = 1.0 |
| ② 제거 기구 | σ / H_bulk ≈ 0.05 ≪ 1 | 탄성 접촉 | α = 2/3, β = +2/3 |
| ③ 공급 형태 | g/d ≈ 1.1 ≤ 1.5 | 단층 | p = 1, q = 2 |

```
(1 − αχ) = 1 − (2/3)(1.0) = 1/3
n_C = p(1 − αχ)      = 1 · (1/3)          = +0.333
n_d = −q(1 − αχ) + β = −2·(1/3) + 2/3     =  0.000
```

**읽는 법:** 농도 지수 1/3 과 입경 무반응이 **함께** 나왔다. 둘은 독립 관측이 아니라
같은 (χ=1, α=2/3, p=1) 의 두 얼굴이다. 실측에서 한쪽만 맞고 다른 쪽이 어긋나면
판정 하나가 틀린 것이다.

### 예 2 — 접촉응력이 벌크 경도를 넘는 계

| 질문 | 입력 | 판정 | 출력 |
|---|---|---|---|
| ① 하중 경로 | A_r ∝ P^1.00 | 자리 지배 | χ = 1.0 |
| ② 제거 기구 | σ / H_bulk = 1.4 ≥ 1 | **소성 확정** (변질층은 벌크보다 무르다) | α = 3/2, β = −1 |
| ③ 공급 형태 | g/d ≈ 1.0 | 단층 | p = 1, q = 2 |

```
(1 − αχ) = 1 − (3/2)(1.0) = −0.5
n_C = 1 · (−0.5)              = −0.500
n_d = −2·(−0.5) + (−1)        =  0.000
```

**읽는 법:** 농도 지수가 **음수**다. 농도를 올리면 제거율이 떨어진다 — 입자가 늘어난
만큼 입자당 하중이 더 잘게 쪼개지기 때문이다(과밀 레짐). 이 예측이 실측과 어긋나면
의심할 곳은 화학이 아니라 χ 다.

주목: ②의 판정이 **표면층 경도의 절대값 없이** 확정됐다. σ ≥ H_bulk 이고 H_s ≤ H_bulk
이므로 σ ≥ H_s 가 자동으로 따라온다.

### 예 3 — 입력이 불완전할 때

| 질문 | 입력 | 판정 | 출력 |
|---|---|---|---|
| ① 하중 경로 | 돌기 높이 분포 미선언, m 미측정 | **미판정** | 등급 `unverified` |
| ② 제거 기구 | 실접촉면적비 미측정 → σ 산출 불가 | **미판정** | 등급 `unverified` |
| ③ 공급 형태 | 간극 미측정 | 단층 가정 | 등급 `estimated` |

```
전체 등급 = 가장 약한 고리 = unverified
→ 지수를 이론에서 유도하지 못했다.
→ 팩이 선언한 지수가 있으면 그것을 쓰되 derived = False 로 신고한다.
```

**읽는 법:** 이것이 정상 동작이다. FabSim 은 모르는 값에 기본값을 놓지 않는다.
기본값을 놓으면 **"모름"이 "판정됨"으로 둔갑**하고, 사용자는 유도된 값과 손으로 넣은
값을 구분할 수 없게 된다. 이 경우 결과에 붙는 경고는 명시적이다 — 선언 지수는
**그 조건에서 회귀된 값**이지 예측이 아니며, 다른 조건으로 외삽하면 틀릴 수 있다.

## 6. 결과 읽기

`exponents_for()` 가 돌려주는 항목이다.

| 필드 | 의미 | 어떻게 쓰나 |
|---|---|---|
| `n_conc`, `n_size` | 실제로 사용될 지수 | 모델식에 들어간다 |
| `derived` | True 면 이론 유도, False 면 팩 선언값 | **False 면 외삽 금지** |
| `confidence` | 근거 등급 | 아래 표 참조 |
| `notes` | 판정 과정 전체 | 이상할 때 여기부터 읽는다 |

**근거 등급** (약한 것부터): `unverified` → `estimated` → `literature` → `measured` → `verified`

전체 등급은 **가장 약한 고리**를 따른다. 세 질문 중 하나라도 미판정이면 전체가
미판정이다. 지수 두 개 중 하나만 믿는 것은 불가능하다 — 둘 다 같은 (χ, α, p, q) 에서
나오기 때문이다.

**선언값과 유도값이 어긋나면 신고한다.** 팩이 지수를 선언했고 이론 유도값과 0.05 넘게
차이나면 경고가 뜬다. 조용히 덮지 않는다. 어긋남은 다음 중 하나를 뜻한다.

1. 유도 입력(χ, α, 공급 형태) 중 하나가 틀렸다.
2. 선언값이 **다른 레짐에서** 회귀된 값이다.
3. 선언값의 측정 창이 유도가 가정한 λ 범위와 다르다(§4.5).

**부호가 반대인 두 실측이 나오면 지수를 평균하지 마라.** 로그축 기울기의 산술평균은
물리적 의미가 없고, 부호가 다르면 애초에 서로 다른 레짐이다. 각 데이터가 어느 레짐인지
먼저 판정하고, 레짐이 다르면 분기하라.

## 7. 한계 — 이 이론이 못 하는 것

정직하게 적는다. 이 목록을 모르고 쓰면 틀린 결과를 신뢰하게 된다.

| 가정 | 깨지는 조건 | 결과 |
|---|---|---|
| 자리마다 독립 도착 | 입자간 정전·유체역학 상호작용이 있으면 도착이 상관된다 | 포아송 대신 Langmuir 형이 나을 수 있고, 둘의 중간 곡률은 데이터로만 구분된다 |
| 자리 footprint ≈ d² | 응집체·비구형 입자 | 자리 수 추정이 무효 |
| 간극이 입자 한 겹 | 다층 공급 | S1 무효, 하중이 층간에 분배된다 |
| **χ 가 농도와 무관한 상수** | 실제로는 농도가 오르면 입자가 하중을 더 많이 짊어진다 | **χ = χ(C) 가 정직하다.** 이것이 저농도 선형 → 고농도 음지수 전이의 진짜 메커니즘일 수 있다 |
| 모든 활성 입자가 같은 F 를 받음 | 입도 분포 폭이 넓으면 큰 입자가 하중을 독점한다 | 유효 지수가 지도에서 벗어난다 |
| 질량분율 ∝ 부피분율 | 밀도가 다른 계를 비교할 때 | **지수를 다른 계로 옮길 때 반드시 어느 정의인지 확인하라** |
| MRR = N_a × Q₁ (선형 중첩) | 궤적이 겹치면 이중 제거 | 고농도에서 과대평가 |

**미해결 병목 (우선순위 순)**

1. **표면층 유효 경도의 절대값.** 공개 문헌에 없다. 부등식 방향으로만 판정을 확정할
   수 있어 탄성 쪽은 늘 확정 불가로 남는다. 이 값이 확보되면 α 판정 전체가 확정 등급으로
   올라간다.
2. **입자 피복률의 실측.** 없으면 접촉응력의 상계를 좁힐 수 없다.
3. **다층 공급의 감쇠 형태.** p_eff = (g/d)^(−1/3) 는 기하 논증이며 폐형식이 아니다.
4. **χ = χ(C) 의 함수형.** 현재는 상수로 다룬다.

**극한 거동에서 알아둘 것**

| 극한 | 포화형 예측 | 순수 멱함수 |
|---|---|---|
| C → 0 | N_a → 0, MRR → 0. 타당 | 0 으로 가지만 n<1 이면 **미분이 발산** — 저농도에서 비물리적으로 민감 |
| C → ∞ | 유한 상한. 타당 | MRR → ∞. **비타당** |
| C → ∞, χ=1 | MRR 감소(하중 분산). 타당 | 표현 불가 |
| P → 0 | C_h → 0, 어떤 농도도 포화. 동시에 MRR → 0. 타당 | 표현 불가 |
| d → 0 (C 고정) | 공급 면밀도 → ∞ | **비타당** — 입자가 간극에 못 끼거나 브라운 운동이 접촉을 못 유지한다 |

**저농도 극한과 고농도 극한이 한 식에서 나온다는 점이 포화형 모델의 가치다.**
λ ≪ 1 에서 N_a ∝ C 이고 압력 무관(자리가 남고 공급이 율속), λ ≫ 1 에서 N_a → n_s ∝ P
이고 농도 무관(Preston 의 P¹ 회복).

**진단 지표 하나:** 저농도에서 압력을 올렸는데 제거율이 오히려 떨어지면, 자리는 늘었는데
공급이 그대로라 자리당 점유율이 떨어진 상태다(λ = C/C_h(P) 에서 분모만 커진 경우).
이 이상점은 모델의 예측이자 입자 고갈의 신호다.

## 8. 요약 — 한 장

```
                       MRR ∝ N_a · Q₁
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
   ① 하중 경로          ② 제거 기구         ③ 공급 형태
   A_r ∝ P^m           σ / H_s             g / d
        │                   │                   │
        χ               (α, β)              (p, q)
        └───────────────────┼───────────────────┘
                            │
              n_C = p(1 − αχ)          ≤ 1  (구조적 상한)
              n_d = −q(1 − αχ) + β
```

| 기억할 것 | 내용 |
|---|---|
| 지수는 **계산된다** | 고르는 값이 아니다. 세 물성 질문이 정한다 |
| **n_C ≤ 1** | 구조적 상한. 넘으면 입력이 모순이다 |
| **1/3 = 탄성 + 완전 하중분배** | "표면적 지배"가 아니다 |
| **음의 n_C ⇒ χ ≈ 1** | 화학이 아니라 하중 경로를 의심하라 |
| **정점 입경은 간극이 정한다** | 슬러리 고유값이 아니다 |
| **지수는 측정 창의 함수** | λ 범위 없는 지수 인용은 정보가 아니다 |
| **모르면 판정하지 않는다** | 기본값은 "모름"을 "판정됨"으로 둔갑시킨다 |
