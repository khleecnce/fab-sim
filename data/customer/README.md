# 실측 데이터 — 검증용

## 출처
사용자 개인 소유 CMP 장비(자택 차고)에서 직접 실험한 데이터.
회사(동진) 자산·데이터와 무관하므로 ORG.md §7.5의 "재직사 데이터 금지" 제약 밖이다.
2026-09-06 사용자 확인: "내가 차고에 개인적으로 가지고있는 cmp 장비에서 실험한거니까
안심하고 사용해"

## 그래도 커밋하지 않는 이유
1. 사용자 개인 자산이다. 저장소가 나중에 공개되거나 투자자에게 열릴 때 딸려 나가면 안 된다.
2. 실측 데이터는 **제품의 검증 근거**이지 제품이 아니다. 배포본에도 들어가지 않는다.
3. 나중에 고객 데이터가 같은 경로로 들어온다 — 그때 규칙이 이미 서 있어야 한다.

`.gitignore`가 `data/customer/` 전체를 막는다. 이 README만 예외로 커밋된다.

## 파일 배치
```
data/customer/
  raw/          텔레그램·수동으로 받은 원본 (CSV/XLSX/사진)
  parsed/       스키마 검증을 통과한 표준 형식
  reports/      시뮬레이션 vs 실측 비교 리포트 (마크다운·PNG)
```

## 넣을 때
```bash
.venv/bin/python tools/ingest_measurement.py data/customer/raw/<파일> --run-id <이름>
.venv/bin/python tools/validate_model.py --run-id <이름>
```

## 스키마
`tools/ingest_measurement.py --schema` 로 확인. 최소 요구:
- 측정값: 반경별 또는 (x,y) 점별 두께 또는 제거율
- 조건: 압력, 회전수, 시간 (없으면 비교 불가)

없는 항목은 비워도 된다 — 도구가 "이건 없어서 비교 못 한다"고 말한다.
추정해서 채우지 않는다.
